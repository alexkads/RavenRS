Why RavenRS

A GUI framework that looks finished out of the box.

The pieces a modern interface needs, designed together: a renderer, a reactive core, layout, text and a design system.

One UI, every platform

The same Rust code renders in a desktop window and on a browser canvas. No webview and no DOM widgets, so it looks identical everywhere.

winitwasm32WebGPU

Reactive by design

State, Binding and Derived track who reads them. Change a value and only what depends on it redraws. No locks on the UI thread.

State<T>Binding<T>Derived<T>

GPU-drawn shapes

Rounded rectangles, borders, gradients and soft shadows come from one signed-distance shader. Crisp at any scale factor.

wgpuWGSLSDF

Real typography

Parley shapes and wraps text; glyphs come from a GPU atlas at your display's pixel density. Inter is built in, so text is the same on every platform.

ParleyswashInter

Three themes, one token set

Raven Dark, Raven Light and Raven Glass share semantic tokens. Text contrast is checked against WCAG AA in the test suite.

Raven DarkLightGlass

Extend everything

Your components use the same public API as the built-in ones: compose with Component, or take full control of layout, painting and input with View.

ComponentViewCanvas

Developer experience

Readable Rust that reads like the interface.

  • Typed builders, no magicEverything is plain Rust you can jump to. Macros come later as sugar, not as the API.
  • State that knows its readersThe UI redraws when state it read changes, and stays idle otherwise.
  • Accessible defaultsButtons are focusable, keyboard-operable and show a visible focus ring.
use raven::prelude::*;

fn app() -> impl View {
    let count = State::new(0);
    let inc = count.clone();

    VStack::new((
        Text::new("Welcome to RavenRS").style(TextStyle::Display),
        Card::new(Text::bound(&count, |n| format!("Clicks: {n}")))
            .corner_radius(24.0)
            .shadow(Shadow::soft()),
        Button::new("Get Started")
            .on_click(move || inc.update(|n| *n += 1)),
    ))
    .spacing(24.0)
    .padding(32.0)
}
// State lives in the struct; body() composes views.
struct Counter {
    count: State<i32>,
}

impl Component for Counter {
    fn body(&self) -> impl View {
        let count = self.count.clone();
        HStack::new((
            Text::bound(&self.count, |c| format!("{c}")),
            Button::new("+1")
                .on_click(move || count.update(|c| *c += 1)),
        ))
    }
}
