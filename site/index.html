Roadmap

Built in the open, one phase at a time.

Each phase is validated before the next begins. Details are tracked in docs/PARITY.md and docs/QUALITY.md.

Progress3 of 7 phases done
Phase 1

Foundation. Workspace, checks, wgpu on desktop and WebGPU, SDF shapes, text, first app.

Done
Phase 2

Components. 160+ components, a Ribbon, a command palette, a scheduler, docking panels, charts, and a virtualized 100k-row DataGrid with sorting, filtering, grouping, summaries, editing, pinned and reorderable columns and row details.

Done
Phase 3

Quality and release. Published to crates.io, WAI-ARIA keyboard patterns, golden images, property tests, performance budgets and yearly versioning.

Done
Phase 4

Accessibility and platform. Screen readers on desktop and web, clipboard, and IME composition on the web are done. Next: IME composition on the desktop and right-to-left layout.

In progress
Phase 5

Reporting. The engine, a web report designer, PDF, XLSX and CSV export, a server for scheduled delivery and a document viewer are here. Next: subreports and a table of contents.

In progress
Phase 6

Polish. Chart lines and areas drawn as vectors on screen, backdrop blur for Raven Glass, and rebuilding only the part of the screen that changed.

Planned
Phase 7

Applications. Business apps from a model: records, lists, forms and commands generated for you, with SQLite storage. Also here: local AI models, an MCP server that answers questions about RavenRS, a Lottie player of our own and training videos recorded from the app. Next: the rest of the application framework.

In progress
