pub fn new_issue_url(
    new_issue: &str,
    intro: &str,
    report: &str,
    truncated_note: &str,
) -> String
Expand description

The URL of a new issue with intro and then report in a code block as its body, for the person to review and send on the page it opens. It never passes MAX_ISSUE_URL: a report that would make it longer loses its last lines, whole where possible, and truncated_note says so after the block.

new_issue is the page for new issues and may already have a query, such as https://github.com/owner/repo/issues/new.

use ravenrs_core::new_issue_url;

let url = new_issue_url("https://example.com/new", "Steps:", "GPU: Intel\n", "");
assert_eq!(url, "https://example.com/new?body=Steps%3A%0A%0A%60%60%60text%0AGPU%3A%20Intel%0A%60%60%60%0A");
