Foundation types shared by every RavenRS crate.

ravenrs-core has no dependencies. It defines logical-pixel geometry, colors, platform-neutral input events, Scene (the display list that widgets produce and renderers consume) and AccessTree (what assistive technology sees). Keeping them here lets widgets stay independent of any GPU or operating-system API. csv is here because the grid and the report exporters share nothing else lower down.

Functions§

monotone_slopes
The slope at each of points (in order, with growing x) of a curve that never swings past them: Fritsch-Carlson, with a harmonic mean. Charts and curve editors share it so that a curve reads the same in both. Fewer than two points have no slope to speak of, so they get zeros.
new_issue_url
The URL of a new issue with intro and then report in a code block as its body, for the person to review and send on the page it opens. It never passes MAX_ISSUE_URL: a report that would make it longer loses its last lines, whole where possible, and truncated_note says so after the block.
redact_user_paths
text with every path inside a person’s own folder replaced, since those paths usually carry the person’s name. A path can have spaces, so what follows goes up to the end of the line or a quote or list separator: too much hidden is better than a surname left behind.
