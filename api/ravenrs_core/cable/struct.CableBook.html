Struct CableBook 

Source 
pub struct CableBook { /* private fields */ }
Expand description

Everything about the cables of a window except running their steps: which are held, which are on their way out, where they rest, how many steps are due. The CPU world and the GPU world keep the same book, so they follow the same rules.
