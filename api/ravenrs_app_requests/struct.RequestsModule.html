pub fn decide( &self, space: &mut dyn ObjectSpace, organization: &str, identity: &Identity, decision: &Decision, at: i64, ) -> Result<Decided, SpaceError>

Decides the step a request is on, as this person.

decision.id makes it idempotent: sending the same decision again changes nothing and says so. organization is whose event it is, until the organization comes from the context of the space (#225). decision.version is the version of the request the person saw; another one means someone decided in between, and the decision is refused as a conflict. The decision, the request moving on and its event are one commit.

Roles that let this person read the tasks of the roles lent to them and still running, to add to their identity when they sign in. Deciding checks the end of each delegation again, so a role kept past it reads nothing new and decides nothing.
