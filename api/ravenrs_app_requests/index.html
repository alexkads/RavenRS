Requests decided step by step, as an optional ravenrs-app package.

The application says which steps a request goes through and who may decide each one; the package keeps the request, every decision and an event for each decision. A decision is recorded once however many times it is sent, one taken on an old version of the request is refused, and its event is written in the same commit: when the decision is refused, no event exists to be sent.

Dispatcher hands the events to an EventSink and never sends blindly again: an event sent with no answer is checked with EventSink::status first, and stays to be reconciled when the sink cannot tell.

Nothing here belongs to a sector. Steps, roles and texts are the application’s, and two applications can install the same package with different ones.
