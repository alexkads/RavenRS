Module capacity

Expand description

How much the renderer can draw: each kind of work grows until a frame stops fitting.

The screens in scenes ask whether real screens are cheap; this asks where the renderer itself becomes the bottleneck for whoever uses it. The time counted runs from handing the scene over to the GPU having finished, because the GPU’s own clock is too coarse on short passes, and because this is what a frame really has to fit in.
