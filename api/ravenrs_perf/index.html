The performance gate of RavenRS.

A PerfScene is a screen and the interactions to try on it. Bench::measure drives it with a real Ui and a real Renderer on an offscreen texture, without a window, and counts the work: builds, layouts, paints, shaping, allocations, draw calls and bytes sent to the GPU. Those counts are exact, so gate can compare them with a baseline on every run, where a time measured on a laptop would only be noise.

Times are measured apart by time, before a release.
