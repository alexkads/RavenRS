Source

pub fn buscar_compras( &self, session: &Session, done: impl FnOnce(&Session, Result<Vec<String>, String>) + 'static, )

Asks the SEFAZ for the purchases addressed to the issuer since the last time, out of the way of the screens. A summary gets the acknowledgement it asks for, and then its full XML. What comes back is the full XML of each purchase, ready for the entry of goods.

Where the query stopped (ultNSU) and the hour the national environment asked to wait are kept on the issuer, so that neither a new search nor the program started again repeats a query too soon: that is rejection 656, and it blocks the CNPJ for one hour. A document that fails does not lose the others, nor the place where the query stopped.
