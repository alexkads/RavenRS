Text shaping and layout for RavenRS.

TextSystem owns Parley’s font database and scratch space. It ships with Inter (SIL Open Font License 1.1, see fonts/Inter-LICENSE.txt) embedded, because browsers expose no system fonts to WebAssembly; the same bytes are used on the desktop so text looks identical everywhere. System fonts are not loaded.

Layout happens in logical pixels. The renderer rasterizes glyphs at the device scale factor, so text stays sharp on HiDPI screens without re-shaping.
