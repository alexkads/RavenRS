RavenRS conversation and text: Chat and FloatingPanel, AttachmentStrip, AudioPlayerButton and SelectionBar, RichText, and CodeEditor and Playground (feature code).

Applications depend on ravenrs-widgets (or ravenrs), which re-exports all of this by the same names.

Structs§

Attachment
A file in an AttachmentStrip.
AttachmentStrip
The files about to go with a message: icon or thumbnail, name, size, how to send each one and a button to take it out. It keeps nothing: the app holds the list and changes it when told.
AudioPlayerButton
A button that plays a recording and stops it, with its progress and, when there is one, a transcript to open. Space and Enter work on the button, as on any.
Chat
A conversation over a field to write in. It fills what its parent gives it and follows the newest message.
ChatMedia
What a ChatMessage carries in its bubble, above its text: a photo, a document or a recording. The file stays with the app, which asks to open it from Self::on_open.
ChatMessage
One message of a Chat.
CodeCompletion
Something a CodeEditor offers to put at the caret, from completions.
CodeDiagnostic
Something found at a place in the code: what CodeEditor::diagnostics marks and what a Playground lists under its editor.
CodeEditor
A source code editor: monospaced, no wrapping, line numbers, colors for the language, Tab and Shift+Tab to indent, and Enter keeping the indentation. Ctrl or Cmd with Enter is left to shortcuts, so a surrounding Playground can run the code. Diagnostics mark their lines and underline what they cover. Cmd/Ctrl+Z undoes and Cmd+Shift+Z or Ctrl+Y redoes. Cmd/Ctrl+F opens a find bar over the code, and Ctrl+H the same bar with replacing: Enter and Shift+Enter walk the matches, which are marked in the code, and Escape closes it, back in the code at the match.
FloatingPanel
A round button in the corner of the window that opens a panel over the app. The app stays usable behind it, and Escape or the sphere closes it. Dragging it or pressing an arrow key sends it to another corner, and it stays there while the app runs.
Playground
A place to write code and see what it makes, for documentation, tutorials and tools.
RichText
Text with a little formatting, written the way chat apps write it: *bold*, _italic_, ~struck~, `code`, a fenced block of ```, lines that start with * , - or > , and web addresses, which become links.
RunOutput
What a Runner heard from the code since it was last asked.
SelectionBar
A bar for what to do with several things chosen at once: how many, a way out and the actions, which are disabled while nothing is chosen. Escape also leaves. It goes where the field to write in was, or over a list; the app decides when it shows.

offset_of
