Struct Frame 

Source 
pub struct Frame(/* private fields */);
Expand description

Where a view lives: it holds the view, the controllers that fit it, their actions and a unit of work. A handle, so controllers and actions can keep one.

Changing the view tells whoever watches, turns off the controllers that were on, changes the view, turns on those that fit the new one, and tells again.
