Struct Action 

Source 
pub struct Action(/* private fields */);
Expand description

Something people can do. A handle: the frame and its controller hold the same action, so a controller can turn it off by a reason of its own.

use ravenrs_app::{Action, ActionCategory, CriteriaMode, Selection};

let pay = Action::simple("Pay", "Pagar")
    .category(ActionCategory::Edit)
    .target_entity("Bill")
    .selection(Selection::RequireMultiple)
    .target_criteria("[Status] = 'Open'", CriteriaMode::TrueForAll)
    .on_execute(|cx| {
        for bill in &cx.selected {
            let mut bill = bill.clone();
            bill.set("Status", "Paid");
            cx.space.borrow_mut().save(bill).map_err(|e| e.to_string())?;
        }
        cx.space.borrow_mut().commit().map_err(|e| e.to_string())
    });
assert_eq!(pay.caption(), "Pagar");

pub fn background( id: impl Into<String>, caption: impl Into<String>, work: impl Fn(&JobContext) -> Result<(), String> + Send + Sync + 'static, ) -> Self

A button whose work runs away from the screen, on a thread of its own: it shows how far it got, can be stopped, and what it hands back is kept on the screen’s thread. While it runs, the action is off, so it never runs twice at once.

use ravenrs_app::{Action, Selection};

let archive = Action::background("Archive", "Arquivar", |job| {
    for record in job.selected() {
        let mut record = record.clone();
        record.set("Archived", true);
        job.save(record);
    }
    Ok(())
})
.selection(Selection::RequireMultiple);
assert!(archive.is_background());

pub fn assign(self, entity: &EntityInfo, set: &str) -> Self

Runs as an update: sets fields of every record selected of this entity, as field = expression; ..., each read from the record as it was; checks them against the rules of Save, and keeps them all or none. What does not parse, or names a field the entity has not, is found when the application is put together.

use ravenrs_app::{Action, EntityInfo, FieldInfo, FieldKind, Selection};

let task = EntityInfo::new("Task")
    .field(FieldInfo::new("id", FieldKind::Integer).key())
    .field(FieldInfo::new("state", FieldKind::Text));
let finish = Action::simple("Finish", "Concluir")
    .target_entity("Task")
    .selection(Selection::RequireMultiple)
    .assign(&task, "state = 'done'");
assert_eq!(finish.caption(), "Concluir");
