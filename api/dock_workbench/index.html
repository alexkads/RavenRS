Crate dock_workbench 

Source
Expand description

Three workbenches built on the DockArea, each a whole desktop app around it, to check that the dock holds one together:

  • editor: a code editor. A rail of views at the left switches the side bar, the code is in the middle split in two, the terminal and the problems are below, and the outline is hidden at the right edge.
  • ide: an IDE. A menu bar and a toolbar over the work, the toolbox hidden at the left edge, the project tree over the properties at the right, the list of errors and the output below, and a search window floating over the code.
  • chat: a chat app. The conversations in a side bar that collapses, the conversation in the middle, and what the assistant made in a panel at the right.

Every name, file and message in them is made up.

cargo run -p dock-workbench -- editor (or ide, or chat) opens one in a window.
