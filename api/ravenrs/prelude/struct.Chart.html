Struct Chart 

Source 
pub struct Chart { /* private fields */ }
Expand description

A chart of any ChartKind. Its shapes are drawn into a picture at the screen’s density, and its labels are real text. Over the picture it says what each value is, under the pointer or with the arrow keys. ChartKind::Scatter and the sparklines stay as plain pictures, which take no focus, until given a tooltip.

Available with the charts feature, on by default.

use ravenrs_widgets::{Chart, ChartKind};

let sales = Chart::new(ChartKind::Line)
    .title("Sales")
    .categories(["Jan", "Feb", "Mar"])
    .series("2025", [12.0, 18.0, 15.0])
    .series("2026", [14.0, 21.0, 26.0])
    .height(240.0);

pub fn animate_changes(self) -> Chart

When the data changes to as many series and categories as before, the chart goes from its old shape to the new one: lines and bars rise or fall to their new values, slices turn and grow, and the value axis slides along with them. A change in the middle starts from where the chart is. Under reduced motion it changes at once. For a filter over the same categories; data that scrolls along, as a live feed does, reads better without it.
