Struct DataGrid 

Source 
pub struct DataGrid { /* private fields */ }
Expand description

A virtualized data grid in the spirit of enterprise grids: sorting by one or several columns, a filter row with operators and filters by value, a search panel, grouping by dragging columns to the group panel, group summaries, footer totals, columns to resize, reorder, pin and hide, a menu on each column, single or multiple selection, keyboard navigation, in-place editing, cell templates, CSV export, pages, saved scenarios, and rows that stay on a server (DataGrid::remote). Only the visible rows are built, so 100,000+ rows stay smooth.

use ravenrs_widgets::{DataGrid, GridColumn, GridData, SortDirection, Summary, Ui};

let data = GridData::new(vec![
    vec!["Acme".into(), 1200.0.into()],
    vec!["Globex".into(), 860.5.into()],
]);
let grid = DataGrid::new(
    data,
    [GridColumn::text("Customer"), GridColumn::currency("MRR", "$", 2).summary(Summary::Sum)],
)
.sort_by(1, SortDirection::Descending)
.height(320.0);

let mut ui = Ui::new(grid, ravenrs_style::Theme::raven_dark());
ui.update();
