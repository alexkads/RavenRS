Module cable 

Source
Expand description

Cables that hang, swing and settle: the model behind CablePlug.

A cable is a rope of a few points joined by distance constraints, moved by Verlet integration under gravity, with its ends (and any points it must pass through) pinned. It knows nothing of nodes, ports or widgets: each end is a point and, optionally, the direction the cable leaves it in, so a flow diagram, a rack of jacks, a switchboard or a tooltip tied to a button all describe their cables the same way.

  • Cable describes one cable for a frame: ends, physics, look. Widgets put it in the scene as Primitive::Cable.
  • CableWorld simulates every cable of a window. CpuCables is the reference, run on the CPU; the renderer has the same algorithm on the GPU.
  • cable_rest is where a cable settles, the same for the same input: what exports draw and what reduced motion shows.
  • cable_primitives draws a cable as plain shapes, for every output that is not the GPU.

The step is fixed (CABLE_STEP), counted on the world’s own clock, so the same events give the same shape at any frame rate.

Constants§

CABLE_ITERATIONS

The most points a cable has; the GPU runs one thread per point.

Pieces each segment is drawn in, along a curve through the points: the GPU draws the same.

Seconds per simulation step.

Movement, in logical pixels per step, under which a cable counts as still.
