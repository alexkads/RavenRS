Module grid 

Source
Expand description

An enterprise-style data grid: DataGrid over GridData with GridColumns. The query pipeline in query is pure and usable on its own.

Modules§

query
The data grid query engine: filter → search → sort → group → summarize. Pure functions over rows, independent of the UI.

Structs§

DataGrid
A virtualized data grid in the spirit of enterprise grids: sorting by one or several columns, a filter row with operators, a search panel, grouping with group summaries, footer totals, column resizing and visibility, single or multiple selection, keyboard navigation, in-place editing, cell templates and CSV export. Only the visible rows are built, so 100,000+ rows stay smooth.
GridColumn
A data grid column: title, width, alignment, formatting and capabilities.
GridData
The rows behind a data grid. Cloning shares the same data; editing replaces the row list copy-on-write, so query caches stay valid until a change.
GridQuery
What the user asked the grid to show.
NumberFormat
How numbers are written: decimals, affixes and separators.
QueryResult
The output of run_query: what the grid shows.
