Asks the person for files. Platform layers install one with crate::Ui::set_file_picker.

Required Methods§

Source

fn pick(&self, request: &FileRequest, done: Box<dyn FnOnce(Vec<PickedFile>)>)

Shows the system’s chooser, and calls done with what was chosen, now or later on the UI thread. Canceling gives an empty list.

Source

fn save(&self, _name: &str, _bytes: &[u8])

Hands a file over to the person: the system’s dialog on a desktop, a download in a browser. Nothing happens where there is no system to ask.
