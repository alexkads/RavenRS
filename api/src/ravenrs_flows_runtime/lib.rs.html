1//! Durable runs of [`ravenrs_flows`] flows, kept in SQLite.
2//!
3//! A [`Runtime`] keeps a queue of runs in a SQLite file that several processes may share.
4//! [`Runtime::enqueue`] asks for a run with the flow as it is now and the items it starts
5//! with. A worker [`claim`](Runtime::claim)s the run due first with a lease, in one statement,
6//! so two workers never take the same run. It runs the run and writes a checkpoint at every
7//! node.
8//!
9//! When a worker dies, its lease runs out and another worker takes the run. That worker goes
10//! on from the checkpoint: the nodes that were over keep their part and do not run again, and
11//! a node that was running when the worker died is asked whether its call happened
12//! (`NodeKind::reconcile`) before it runs again.
13//!
14//! A node can wait for a time (`delay`) or an event (`wait_event`). The run stops there and is
15//! due again when the time comes or [`Runtime::signal`] says the event came. Runs can be run
16//! again on the flow as it was or as it is now ([`Runtime::rerun`]). Old runs are forgotten
17//! with their files ([`Runtime::prune`]).
18//!
19//! ```
20//! use ravenrs_flows::{Catalog, FlowDefinition, NodeDef};
21//! use ravenrs_flows_runtime::{Request, RunStatus, Runtime};
22//! use serde_json::json;
23//!
24//! let runtime = Runtime::in_memory(Catalog::builtin()).expect("a database in memory");
25//! let flow = FlowDefinition::new("hello", "Hello")
26//!     .node(NodeDef::new("start", "manual").parameter("items", json!([{ "name": "Ana" }])));
27//! let id = runtime.enqueue(Request::new(flow)).expect("asked for");
28//! assert_eq!(runtime.work_until_idle("worker-1").expect("ran"), 1);
29//! assert_eq!(runtime.get(&id).expect("kept").status, RunStatus::Finished);
30//! ```
31//!
32//! A loop is one checkpoint: a run stopped inside a loop goes round it again from the start
33//! when it resumes.
