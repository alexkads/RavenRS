1//! Clean-room Matroska (MKV) and WebM demuxer, written from RFC 8794 (EBML), RFC 9559 (Matroska)
2//! and the WebM container guidelines.
3//!
4//! - [`open`] / [`open_with`] parse the EBML header and the first Segment (Info, Tracks, SeekHead,
5//!   Cues, Chapters, Tags, Attachments) and, by default, scan every Cluster's block headers to build
6//!   per-track [`Sample`] tables — the same shape as [`isobmff`](crate::craft::media::isobmff), so callers can treat both
7//!   containers alike. Frame data is read on demand with [`MkvFile::read_sample`].
8//! - [`Demuxer`] iterates [`Packet`]s in file order (from any [`ByteSource`], `Read + Seek`, or a
9//!   byte slice) and seeks to the keyframe preceding a time, via the index, Cues, or a cluster scan.
10//!
11//! No dependencies beyond `std`, no `unsafe`, builds for `wasm32-unknown-unknown`.
