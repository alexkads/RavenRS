1//! Clean-room ISO Base Media File Format (MP4, ISO/IEC 14496-12/14/15) and QuickTime (MOV) support.
2//!
3//! - **Demux:** [`open`] parses box headers plus `moov` (and `moof` for fragmented files) from a
4//!   [`ByteSource`] and builds per-track [`Sample`] tables; media data is read on demand with
5//!   [`Mp4File::read_sample`].
6//! - **Mux:** [`Mp4Writer`] writes progressive MP4/MOV (optionally faststart);
7//!   [`FragmentedWriter`] writes fragmented MP4. Both can write a chapter list ([`chapters`]).
8//! - **Boxes:** [`boxes`] iterates the boxes in a byte slice and reads their payloads, for box
9//!   formats and boxes the demuxer does not model (`uuid` boxes, HEIF items, JPEG 2000, CR3).
10//!
11//! See the crate README for supported boxes and limitations.
