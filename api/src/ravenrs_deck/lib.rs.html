1//! Headless presentation engine for RavenRS.
2//!
3//! The layers, from the bottom up:
4//!
5//! - [`geom`] and [`color`]: lengths, points, transforms, colours and theme colour slots.
6//! - [`model`]: the presentation: slides, layouts and masters, shapes, text bodies, tables,
7//!   charts, media and notes, with cheap `Arc`-shared clones.
8//! - [`fonts`] and [`text`]: font lookup and shaping, line breaking, bidi and date fields.
9//! - [`anim`]: animations and slide transitions, evaluated at a point in time.
10//! - [`render`]: slides drawn to pixels on the CPU.
11//! - [`pptx`] and [`format`]: PowerPoint packages and the native format, read and written.
12//! - [`pdf`]: slides, notes pages and handouts exported to PDF.
13//! - [`media`]: embedded audio and video: probing and poster frames.
14//! - [`engine`]: the commands, selection and undo history an editor drives.
15//! - [`mcp`]: the engine's commands as tools for an agent.
16//!
17//! ```rust
18//! use ravenrs_deck::{model, pptx, render};
19//!
20//! // A new presentation, saved as PPTX, read back and its first slide drawn to a PNG.
21//! let deck = model::defaults::new_presentation(None);
22//! let bytes = pptx::export(&deck).unwrap();
23//! let again = pptx::import(&bytes).unwrap();
24//! assert_eq!(again.slides.len(), deck.slides.len());
25//! let opts = render::RenderOpts { scale: 0.25, ..Default::default() };
26//! let png = render::render_slide(&again, 0, &opts).to_png();
27//! assert!(png.starts_with(b"\x89PNG"));
28//! ```
29//!
30//! Nothing here depends on a window, so it also runs on servers and in WebAssembly. The engine
31//! comes from DeckCraft (MIT OR Apache-2.0), with the craft-libs crates it uses and krilla copied
32//! in as modules; see `NOTICE`.
