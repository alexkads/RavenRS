1//! The components of general use in RavenRS: navigation (`Tabs`, `Sidebar`), commands and toolbars,
2//! form editors and layouts, lookups, filters and expressions, status pieces, tiles, the theme
3//! editor, diagnostics and the counter's keys. The families of components (grid, lists, dock,
4//! scheduler, imaging, charts, chat) are built on them and on `ravenrs-widgets-base`.
5//!
6//! Applications depend on `ravenrs-widgets` (or `ravenrs`), which re-exports all of this by the
7//! same names. The modules are public only for the crates of the families; they are hidden from
8//! the documentation and are not a stable API.
9
