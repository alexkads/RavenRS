1//! Driving a window's interface from outside: what a test tool does when it runs a scenario on
2//! the app's real window (`--headed` in Raven Test Studio and `cargo ravenrs e2e run`).
3//!
4//! A platform that shows a window owns its [`Ui`], on the main thread. A [`UiDriver`] gets that
5//! same `Ui` lent to it on that thread whenever it asks for a turn, so the steps of a test act on
6//! the interface the person sees, and nothing is copied or run twice. Commands usually come from
7//! another thread (the test channel reads its input there): the driver keeps them, calls the wake
8//! function it was given, and runs them on its next turn.
9
10use crate::Ui;
11
12/// Who is in control of the window after a driver's turn.
13#[derive(Clone, Copy, Debug, PartialEq, Eq)]
14#[cfg_attr(feature = "live", ravenrs_live::expose(part = "variants"))]
15pub enum Driving {
16    /// The driver: the window still draws, resizes and animates, but the person's pointer and
17    /// keyboard do not reach the interface, so they cannot change the test halfway.
18    Driven,
19    /// The person: the driver let go (a test that ended and left its window to be looked at), and
20    /// the window is an ordinary one until the person closes it.
21    Released,
22    /// Nobody: the driver is done, and the window closes and the app ends.
23    Done,
24}
25
26/// Drives a window's [`Ui`] from outside, on the platform's thread. See the [module](self).
27pub trait UiDriver {
28    /// Called once, when the window is on screen: `wake` asks the platform for a turn, from any
29    /// thread, and a turn follows at once, so the driver may answer that it is ready here.
30    fn start(&mut self, wake: Box<dyn Fn() + Send + Sync>);
31
32    /// A turn: runs what the driver has waiting on `ui`, whose clock reads `now` seconds, and says
33    /// who is in control next. The platform draws the frame after it.
34    fn drive(&mut self, ui: &mut Ui, now: f64) -> Driving;
35
36    /// The interface's clock while the driver is in control, given the real one (`now`, seconds
37    /// since the app started): the real one by default. A test tool holds it between its steps,
38    /// so a pause to watch the test does not let a notice expire that the next step checks.
39    fn time(&mut self, now: f64) -> f64 {
40        now
41    }
42
43    /// The person closed the window while the driver was in control; the app ends after this
44    /// returns. A test tool says so to whoever is waiting for a step.
45    fn window_closed(&mut self) {}
46}
