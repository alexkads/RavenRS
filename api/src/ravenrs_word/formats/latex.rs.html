1//! LaTeX (`.tex`) import and export.
2//!
3//! **Export** writes a standalone LaTeX 2ε `article` that compiles with pdfLaTeX, XeLaTeX or
4//! LuaLaTeX using only packages every TeX distribution ships (`fontenc`, `ulem`, `xcolor`,
5//! `multirow`, `amsmath`, `hyperref`). Headings become unnumbered sectioning commands (Word headings
6//! carry no numbers), lists `itemize`/`enumerate`, tables `tabular` with the document's column
7//! widths, equations `$…$` / `\[…\]`, and character formatting the matching text commands. Pictures
8//! can't live inside a single `.tex` file, so each is replaced by its alternative text.
9//!
10//! **Import** reads the everyday subset of LaTeX that documents are written in: the preamble's
11//! `\title`/`\author`, sectioning commands, paragraphs, lists, `quote`, `center`/`flush…`,
12//! `verbatim`-like environments, `tabular` (with `\multicolumn`/`\multirow`), inline and display math
13//! (kept as equations), text formatting commands and declarations, colours, links, accents and
14//! TeX's special characters and ligatures. It is not a TeX engine: macros aren't expanded. Unknown
15//! commands are dropped while their braced arguments are kept as text, so no words are lost; layout
16//! commands (`\vspace`, `\setlength`, `\usepackage`…) are dropped with their arguments.
17//!
18//! Like the other text formats, the parser is lenient and never panics on hostile input: group and
19//! environment nesting is depth-limited and the input size is capped.
