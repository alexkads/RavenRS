1//! Markdown: a CommonMark subset plus GitHub tables and strikethrough.
2//!
3//! Import: ATX and setext headings, paragraphs with soft/hard breaks, block quotes (→ Quote
4//! style), fenced and indented code (→ one Code paragraph per line), thematic breaks (→ a
5//! bottom-border paragraph), bullet and ordered lists (nested by indentation), GFM pipe tables,
6//! and inlines: emphasis/strong (the CommonMark delimiter algorithm), `~~strike~~`, code spans,
7//! inline links, autolinks, images (`data:` URIs become pictures, others their alt text),
8//! backslash escapes, entities, HTML comments (`<!-- ... -->`), `<br>` and `<a id>` anchors.
9//!
10//! Export writes the same constructs; pictures become `![alt](media-name)` placeholders.
