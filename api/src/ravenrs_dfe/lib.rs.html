1//! **BETA, proof of concept.** What every Brazilian electronic fiscal document shares, for the
2//! engines of RavenRS (`ravenrs-nfe`, `ravenrs-nfse`) and whatever comes next: a small XML tree,
3//! inclusive C14N, enveloped XMLDSig with SHA-1 or SHA-256, the [`Transport`] every request goes
4//! through, the MSW-style chain of handlers of the sandboxes, gzip and Base64, reading and issuing
5//! test ICP-Brasil certificates (A1 and a simulated A3 token) and, with the `http` feature on native
6//! targets, mutual TLS with an A1 certificate.
7//!
8//! Nothing here knows a layout: each engine says which element is signed, with which hash, and what
9//! a rejection means. Not homologated by any authority; see the README of each engine.
