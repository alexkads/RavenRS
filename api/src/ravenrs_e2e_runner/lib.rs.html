1//! Runs end-to-end scenarios of RavenRS apps and reports them: the engine shared by Raven Test
2//! Studio (RTS) and `cargo ravenrs e2e`.
3//!
4//! - [`project`] reads a Rust project without building it: its RavenRS packages, which are apps,
5//!   whether each speaks the test channel (`ravenrs-e2e-wire`), its `.raventest` scenarios and
6//!   the screens it builds.
7//! - [`app`] opens an app apart, in a child process with no window: its code compiled by [`build`], a
8//!   copy the installer put on the computer, or a binary a variable names.
9//! - [`session`] is what a run drives and how each step goes: the step a block stands for, and
10//!   why it failed, by its stable code, with the meaning and the fix in Portuguese.
11//! - [`window`] runs with the app's real window on screen (`--headed`): the pace a person can
12//!   follow, pause, one more block, stop, and the window kept open to look at a failure.
13//! - [`run`] runs `.raventest` files straight from their blocks, and [`report`] says how it went
14//!   as text, JSON, JSON lines or JUnit, and keeps it in a folder (`relatorio.json`,
15//!   `trace.jsonl`, `arvore.txt`).
16//!
17//! ```no_run
18//! use ravenrs_e2e_runner::{app, project, run};
19//!
20//! let project = project::read(std::path::Path::new(".")).unwrap();
21//! project.learn_apps();
22//! for folder in project.scenario_folders() {
23//!     let report = run::run_files(&folder, app::open).unwrap();
24//!     println!("{}", report.text());
25//! }
26//! ```
