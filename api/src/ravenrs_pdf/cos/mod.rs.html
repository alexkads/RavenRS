1//! pdfcraft-cos — the PDF object layer (L1, standalone with `pdfcraft-filters`).
2//!
3//! Parses the COS object graph lazily and tolerantly, keeps edits in a copy-on-write overlay
4//! (cheap snapshots for undo), and writes documents back either incrementally (original bytes
5//! untouched) or as a full, garbage-collected rewrite. The PDF object graph *is* PdfCraft's
6//! document model (plan/architecture.md §5, ADR-0010).
7//!
8//! Done: every cross-reference form (tables, streams, hybrid `/XRefStm`), object streams, repair
9//! by scanning, encryption on load and save (R2–R6, crypt filters, `/EFF`), incremental writing,
10//! and full saves that pack objects into compressed object streams with a cross-reference stream.
11//! Not yet: streaming very large files within a memory budget (`ByteSource`,
12//! `core.lazy-loading`), and linearized output (`core.linearization`, M11). See the README.
13
