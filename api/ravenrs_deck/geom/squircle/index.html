Module squircle 

Source
Expand description

Rectangles with smoothed (“squircle”) corners, as design tools offer next to the corner radius (#286). A plain rounded corner joins the straight edge with a sudden change of curvature; a smoothed corner starts curving earlier, along a cubic Bézier, and keeps a shorter circular arc in the middle, so the outline flows into the edge.

For a corner of radius r and smoothing s (0 = circular, 1 = no arc left), the corner takes p = (1 + s) · r of each edge. The arc keeps 90° · (1 − s) around the corner’s diagonal and each side of it is a cubic whose handles lie on the edge, so the curve is tangent to the edge where it starts and to the arc where it meets it. When p would exceed half the shorter side, the smoothing is reduced first, then the radius. The construction is our own derivation from these constraints.
