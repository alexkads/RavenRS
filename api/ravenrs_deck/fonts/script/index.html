Script and font-slot classification.

DrawingML gives every run three typefaces: a:latin, a:ea (East Asian) and a:cs (complex script: Arabic, Hebrew, Thai, Indic…). Which one a character uses follows its Unicode script (UAX #24). Characters with no script of their own (Common and Inherited: spaces, digits, punctuation, combining marks) take the script and slot of the text around them, so a space or a parenthesis between two Arabic words is shaped with them.

Functions§

default_language
A default BCP 47 language for a script (shaping picks locl forms by language).
joins_following
Arabic letters that join to the following letter (joining type D, dual-joining): a kashida (tatweel) may be inserted after them. Right-joining (alef, dal, reh, waw…) and non-joining (hamza) letters are excluded.
joins_preceding
An Arabic letter that joins to the preceding letter (joining type D or R).
resolve
Resolve every character’s script and slot, giving Common/Inherited characters the value of the preceding character with one (or, at the start, the following one; Latin when there is none).
script_of
The script of c, or None for Common and Inherited characters (spaces, digits, punctuation, combining marks), which take the script of their neighbours.
slot_of
The slot of c on its own: None for characters that take their neighbours’ slot. CJK punctuation and full-width forms are East Asian although their script is Common.
slot_of_script
The slot a script is drawn with.
