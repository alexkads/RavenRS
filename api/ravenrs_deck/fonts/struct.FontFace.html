Expand description

One loaded font face.

Fields§

§family: String

Typographic family name (e.g. “Source Sans 3”).

§style: String

Typographic style name (e.g. “Semibold”, “Italic”).

§legacy: Option<(String, String)>

The Windows (GDI) family and style names (name IDs 1 and 2) when the family differs from the typographic one: “Segoe UI Semibold” / “Regular” for Segoe UI Semibold. Documents name fonts this way.

§weight: f32

usWeightClass-style weight (400 = regular).

§italic: bool§upem: f64§ascent: f64

Ascender in font units (positive = up).

§descent: f64

Descender in font units (positive = down).

§cap_height: f64

Cap height and x height in font units (estimated from the ascent when the font has no OS/2 values).

§x_height: f64§line_split: f64

Where the baseline sits in a line, as a share of the line’s height from its top: the Windows ascent over the Windows ascent plus descent (OS/2 usWinAscent/usWinDescent), the split PowerPoint uses (computed by line_split).

§underline: (f64, f64)

Underline position (top edge, below the baseline) and thickness in font units (post table; 0.1 and 0.05 em when the font has none). PowerPoint draws single underlines there.

§strikeout: (f64, f64)

Strikethrough position (top edge, above the baseline) and thickness in font units (OS/2; 0.26 and 0.05 em when the font has none). PowerPoint draws single strikethroughs there.

§shaper: ShaperData§coords: Vec<([u8; 4], f32)>

Variable fonts: the named instance’s axis settings (user units; empty = default instance), the normalised location and the shaper’s view of it.

§instance: Option<ShaperInstance>
