Struct ShowState

pub struct ShowState {
    pub slide: usize,
    pub step: usize,

    pub ended: bool,
    pub backward: bool,
    pub zoom: Option<(usize, usize)>,
    /* private fields */
}
Expand description

Where a slide show is. Besides the current position it remembers what was played on every slide the show has visited (main steps, triggered sequences), so a slide reached again by a link or the arrow keys looks the way it was left, as in PowerPoint.

Fields§

§slide: usize

Index into presentation.slides.

§step: usize

Main step that plays next or is playing; == steps when the slide is fully built.

§playing: bool

Step step is playing (its clock runs). With step, gives Timeline::state(.., step, t).

§ended: bool

On the end screen.

§backward: bool

The current slide was reached by going back (← / Backspace), so the show plays the transition of the slide it left, in reverse, as PowerPoint does (#1531).

§zoom: Option<(usize, usize)>

Return to Zoom: (zoom slide, last zoomed slide). Advancing past the last zoomed slide goes back to the zoom slide, fully built.
