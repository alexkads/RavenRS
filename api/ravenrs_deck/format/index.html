Module format 

Source
Expand description

The native .deckcraft format: a zip holding presentation.json (the model, minus media bytes), media/<id> and chart-parts/<index> binary entries, and mimetype. Readers ignore unknown fields, so newer files open in older builds with what those builds understand.

Functions§

load
Read a presentation. Missing media/chart parts are left empty; use load_checked to learn which. A damaged chart member refuses the file before further chart inflation.
load_checked
Read a presentation and list media that couldn’t be read, plus missing chart members. A chart member that is present but fails decoding, CRC or its entry limit refuses the file. Linked media saved without its bytes isn’t damage.
markdown_to_slides
Markdown outline text (.md): each heading starts a slide with its text as the title; list items under it become bullets nested by their indentation, other lines body paragraphs. Text before the first heading is skipped, as indented lines before the first title are in the plain format. A file without headings is read as a plain outline (outline_to_slides).
outline_to_slides
Outline text: one slide per unindented line; tab-indented lines become body bullets at their level (Insert ▸ Slides from Outline, View ▸ Outline copy).
repair
Make a loaded presentation safe to edit: a master exists, every slide’s layout exists, tables are rectangular, and duplicate ids are re-id’d — unless the deck has used every id, in which case a duplicate stays (growth is refused; see the comment in the loop).
sane_numbers
[sane_shapes] over every slide, layout and master; slides are only copied when they change.
sane_slide_size
A slide size the views and renderer can always lay out: a missing, zero, negative or non-finite side gives the 16:9 default, and each side is brought into SLIDE_SIDE.
save
Serialize a presentation.
slides_to_outline
The deck as outline text (titles unindented, body paragraphs tab-indented by level).
sniff
