ravenrs_deck::text

Module datetime 

Source
Expand description

Date and time fields (a:fld type="datetime…"): the text each field type shows for a moment, and the local clock.

The field types and their formats follow ECMA-376 Part 1, §21.1.2.2.4 (fld): datetime1 to datetime13, written as in PowerPoint’s English (United States) Date and Time list. datetime and datetimeFigureOut show the language’s short date. Numeric dates follow the run’s language; formats with month or day names, or AM/PM, are only computed for English, so other languages keep the text the file was saved with.
