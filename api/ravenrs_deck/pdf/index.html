Expand description

PDF export.

Each slide is drawn by the DeckCraft renderer at print resolution (so the PDF looks exactly like the slide, effects included) and overlaid with an invisible layer of real text from the text layout engine with embedded font subsets, so the text can be searched, selected and copied. Hyperlinks and shape actions become link annotations, slide titles become bookmarks.

Layouts: one slide per page, notes pages (slide above its speaker notes) and handouts (1, 2, 3, 4, 6 or 9 slides per page).
