Headless presentation engine for RavenRS.

The layers, from the bottom up:

  • geom and color: lengths, points, transforms, colours and theme colour slots.
  • model: the presentation: slides, layouts and masters, shapes, text bodies, tables, charts, media and notes, with cheap Arc-shared clones.
  • fonts and text: font lookup and shaping, line breaking, bidi and date fields.
  • anim: animations and slide transitions, evaluated at a point in time.
  • render: slides drawn to pixels on the CPU.
  • pptx and [format]: PowerPoint packages and the native format, read and written.
  • pdf: slides, notes pages and handouts exported to PDF.
  • media: embedded audio and video: probing and poster frames.
  • engine: the commands, selection and undo history an editor drives.
  • mcp: the engine’s commands as tools for an agent.
use ravenrs_deck::{model, pptx, render};

// A new presentation, saved as PPTX, read back and its first slide drawn to a PNG.
let deck = model::defaults::new_presentation(None);
let bytes = pptx::export(&deck).unwrap();
let again = pptx::import(&bytes).unwrap();
assert_eq!(again.slides.len(), deck.slides.len());
let opts = render::RenderOpts { scale: 0.25, ..Default::default() };
let png = render::render_slide(&again, 0, &opts).to_png();
assert!(png.starts_with(b"\x89PNG"));

Nothing here depends on a window, so it also runs on servers and in WebAssembly. The engine comes from DeckCraft (MIT OR Apache-2.0), with the craft-libs crates it uses and krilla copied in as modules; see NOTICE.

Modules§

anim
Slide show timing for DeckCraft.
color
DeckCraft colour: sRGB colours, theme colour slots and DrawingML-style colour transforms (tint, shade, luminance modulation/offset, alpha…), so theme-relative colours resolve the way presentation files expect.
craft
The craft-libs crates the engine uses, copied in as modules.
engine
The DeckCraft engine façade.
fonts
DeckCraft fonts: the font database (craft-fonts families, user and system fonts, and open substitutes for the Office fonts presentations ask for), vertical metrics, glyph outlines and OpenType shaping, script/slot classification and per-cluster fallback.
format
The native .deckcraft format: a zip holding presentation.json (the model, minus media bytes), media/<id> and chart-parts/<index> binary entries, and mimetype. Readers ignore unknown fields, so newer files open in older builds with what those builds understand.
geom
DeckCraft geometry: units, shape transforms and preset shape generators.
mcp
DeckCraft’s MCP server.
media
DeckCraft media: everything between embedded media bytes and the speakers / the screen.
model
The DeckCraft document model.
pdf
PDF export.
pptx
PPTX import and export: Office Open XML PresentationML / DrawingML, written from the public ECMA-376 standard.
render
The DeckCraft renderer: draws slides, layouts and masters with vello_cpu.
text
Text layout for slide text bodies.
third_party
Third-party code the engine carries patched: krilla 0.8.2 (MIT OR Apache-2.0), the PDF writer behind craft::pdf, with the patches craft-libs lists in its README.craft.md. It is here for pdf and is not an API of this crate.
