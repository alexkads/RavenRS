Slide transitions and object animations.

Animations are kept as the flat, ordered list the Animation Pane shows; the PPTX writer builds the nested timing tree from it and the reader flattens files back into it.

transition_option_label
The Effect Options label PowerPoint shows for a transition option. Options are stored as the file format’s values: for moving transitions (Push, Wipe, Cover, Pan, Cube…) the direction things move, so “l” is the effect coming “From Right”; Glitter and the preset effects (Fall Over, Wind…) name the side itself; Ripple names where the wave heads.
