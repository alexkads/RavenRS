Module drawtable 

Source
Expand description

Draw Table: the pencil splits cells along the line you draw, the table eraser merges the two cells on either side of the border you click. Pure operations on a Table in its own coordinates (points from its top-left corner), unit-tested without a session.

Both work on the table’s anchors (each visible cell with its row and column span), edit that list, then lay the grid back out, so merges anywhere in the table survive.

Functions§

draw_line
Draw a line from a to b (table points). Mostly-horizontal lines split rows, mostly-vertical ones split columns; only the cells the line crosses are divided. Returns whether anything changed.
erase_at
Erase the border nearest p (within tol points): the two cells it separates merge, when together they make a rectangle. Returns whether a border was erased.
