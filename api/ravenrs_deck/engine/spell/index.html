Module spell 

Source
Expand description

Spell checking with Hunspell-format dictionaries (xx_YY.aff + xx_YY.dic).

A subset of Hunspell: SET (UTF-8 and ISO-8859-1), FLAG (default, long, num, UTF-8), PFX/SFX with strip, conditions and cross products, continuation flags on affixes (one level: a suffix that allows a further suffix), NEEDAFFIX, FORBIDDENWORD, NOSUGGEST, KEEPCASE, TRY, REP and WORDCHARS. Compounding, ICONV/OCONV and morphology are not read; words they would accept are reported as misspelt.

No dictionary ships with DeckCraft. They are looked up in the folders the system’s own spell checkers use (and DECKCRAFT_DICTIONARIES), so whatever the user installed is used.
