Module compare 

Source
Expand description

Review › Compare: the differences between the open presentation and a revised copy of it, slide by slide, and accepting a revised slide into the open one or rejecting it.

Slides match by id (a revised copy of the same deck keeps them); when the two decks share no slide id at all, by position. Shapes match by id, then by name.

The revised slide made to live in doc: its media copied over (remapped on an id clash), shape ids kept unless another slide of doc uses them (then fresh, animations following), and its layout matched by id, then by name, then the first layout.
