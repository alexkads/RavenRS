pub fn delete_surrounding( &mut self, before: usize, after: usize, bytes: bool, ) -> Result<Value>

Remove text around the composition caret or selection, as an input method asks (ImeEvent::DeleteSurrounding/DeleteSurroundingBytes). Counts are characters or UTF-8 bytes of the logical text the surrounding query publishes, so a range may cross a paragraph mark (read as one \n byte) and whole scalars only are removed; out-of-range counts are clamped. A deletion while composing stays inside the composition’s single undo step.

pub fn end_composition(&mut self)

Keep an input method’s composition as it stands (#101): its text stays and the whole composition becomes one undo step. Nothing happens without one.

This is also how the input method’s own commit ends a composition: the platform has already finished that one, so it must not ask for an interrupt.

Source

pub fn settle_composition(&mut self)

Settle a composition because the application did something else (a click, a key, a command, a target change) rather than because the input method committed it.

The platform still holds its own copy of that composition, so a host must publish one should_interrupt_composition for each increment of Self::composition_settles: the backend then cancels it instead of committing its text into whatever is selected next.

Source

pub fn composition_settles(&self) -> u64

How many compositions the application settled itself (clicks, keys, other commands).

A host compares this with the value it last published; every increment is one platform composition that must be interrupted. The input method’s own commits do not count.
