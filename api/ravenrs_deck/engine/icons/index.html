Insert › Icons: Lucide stroke icons as custom geometry.

The paths in icon_data.rs are Lucide 1.56.0 centerlines (24×24, fill none). They are converted to DeckCraft’s M/L/C/Q/Z syntax when inserted, so the shape is a stroked outline rather than a filled silhouette or an SVG picture.

Constants§

Design size of every icon, in path units. Lucide’s viewBox is 0 0 24 24.

outline

path_data
DeckCraft path syntax for name, in the 24×24 viewBox.
stroke_width
Stroke width in points for a shape w×h points. Lucide’s stroke is stroke units on a 24-unit box, so a 72 pt icon is a 6 pt line. Resizing the shape later does not change it.
