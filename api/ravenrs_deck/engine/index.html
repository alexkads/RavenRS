Module engine 

Source
Expand description

The DeckCraft engine façade.

Every user-visible action is a command with a stable id (slide.new, shape.insert, text.insert, format.bold…) and JSON parameters. The egui UI, the CLI, the control channel and MCP all go through Session::execute. Pointer tools reduce to commands too, so every gesture is journaled, undoable and replayable.
