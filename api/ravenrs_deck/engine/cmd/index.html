background
Picture Format ▸ Remove Background: a classical matte, no model. The background is what the picture’s edges reach through similar colours: a flood fill from every edge pixel, each step close to the pixel before it (gradients and soft shadows) and to the edge colour it started from (so it can’t leak into the subject). It turns transparent, with a one-pixel soft edge.

Design Ideas: arrangements of what is on the current slide (picture full-bleed with the title on a band, picture on one half, a framed picture, text-only layouts). An idea moves and resizes the slide’s own shapes and crops pictures to their new box; it changes only that slide. Everything is computed here, offline.

The command palette runs a command with {}. True when the params doc names a value that call would have to supply (path, rows, path? | data), so the palette must not offer it. A name ending in ? is optional. Text after → is the result, not an input.
parse_params
The top-level parameters of a params doc: {preset, rect?: [x,y,w,h] pt} | {id} gives preset, rect (optional, [x,y,w,h] pt) and id (in the second object). Text after → is the result and is skipped. Errs where the doc strays from that grammar.
