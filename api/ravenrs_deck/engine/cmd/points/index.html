Module points 

Source
Expand description

Edit Points (Shape Format ▸ Edit Shape ▸ Edit Points): turn a shape into a freeform and move, add or delete the vertices of its outline.

While points are edited every custom path of the shape is kept in shape-local points (its w/h equal the shape’s size), so a vertex’s path coordinates are its offset in the shape. After each change the shape’s box is fitted around the outline again, keeping it in place on the slide (rotation and flips included).
