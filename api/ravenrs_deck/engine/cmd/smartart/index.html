Module smartart

Expand description

SmartArt: a diagram’s outline (the Text Pane) and the shapes generated from it.

A SmartArt graphic is a group whose diagram holds its layout and its nodes (text + outline level). Every edit changes the nodes and regenerates the group’s children inside the group’s child rectangle, so the diagram keeps its size and place. Text typed straight into a diagram shape is read back into the nodes before each regeneration.
