§kind: ToolKind§sticky: bool

Keep the tool after one use (double-click on a shape in the gallery: lock drawing mode).

§marquee: Option<Rect>§preview: Option<Xfrm>§guides: Vec<Guide>§hover: Option<Hit>§ink_preview: Vec<(f64, f64, f32)>§sites: Vec<Point>

Connection sites to show (slide coordinates) while drawing or dragging a line end, and the site the end would glue to.

§glue: Option<Point>§path_preview: Vec<Point>

Freeform being drawn: points so far (plus the rubber-band point), smoothed, and whether the pointer is over the start (closing the shape).

§path_smooth: bool§path_closing: bool§press_added_vertex: bool

Whether the last freeform press added a vertex (it adds none at the point cap).

§edit_points: Option<ShapeId>

The shape in Edit Points: its vertices are handles instead of the box’s.

§edit_vertex: Option<(usize, usize)>

The vertex (path, index) whose control handles show in Edit Points.

§edit_segment: Option<(usize, usize)>

The segment (path, index of the vertex ending it) last right-clicked in Edit Points, for the segment menu.

§edit_segment_t: Option<f64>

Where on that segment the right click was (0..1), where Add Point puts the new point.

§vertex_kind: Option<(ShapeId, usize, usize, String)>

The point type last chosen for a vertex (shape, path, index, type): handle drags follow it.

§guides_visible: bool

Drawing guides are shown (View › Guides): they can be dragged and shapes snap to them.

§guide_drag: Option<(usize, f64)>

The guide being dragged and where it is now (slide points); None once dropped.

§guide_hover: Option<usize>

The drawing guide under the pointer, for the cursor.
