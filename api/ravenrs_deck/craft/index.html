The craft-libs crates the engine uses, copied in as modules.

Modules§

audio
Audio file I/O and codecs for the Craft apps. Input and output are byte slices or a crate::craft::media::ByteSource (no filesystem access of its own); builds for wasm32-unknown-unknown.
media
Media containers and bit-level I/O for the Craft apps. Codecs are in other crates (craft-audio; video later), which depend on this one.
metafile
Windows metafiles: reads Windows Metafiles (WMF), Enhanced Metafiles (EMF) and EMF+ into a neutral vector model, and (feature write) writes EMF and WMF.
pdf
Shared optional PDF reading, rendering and writing for Craft applications.
video
Clean-room pure-Rust video codecs for the Craft apps, one feature per codec. Input and output are byte slices and planar sample buffers (no filesystem access of its own); builds for wasm32-unknown-unknown.
