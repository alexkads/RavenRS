PDF authoring shared by Craft apps, using Krilla’s drawing primitives.

Applications supply already laid-out pages and retain their document models, font licensing and fallback policy, export presets, tagging semantics and postprocessing. backend exposes Krilla explicitly; this is not an independent graphics model.

font
Copy and prepare an already selected, licensed font for Krilla’s subset embedding. None retains static-font construction; Some retains variable-font construction, including an empty coordinate list. Selection, caching, shaping and fallback belong to the app. An error never substitutes another font or drops text silently.

uri_target
The link target that opens url, or None when safe_url refuses it. Build URI links with this instead of backend::action::LinkAction so a refused target writes no link annotation; the page content stays as drawn. The URI is written trimmed.
