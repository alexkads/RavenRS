pub fn read_id(data: &[u8]) -> Option<(u32, usize)>
Expand description

Decode an element ID (marker bits kept, 1..=4 bytes). Rejects all-ones value bits (reserved). All-zero value bits are accepted, because Matroska’s ChapterDisplay uses ID 0x80.
