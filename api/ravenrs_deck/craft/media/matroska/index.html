Module matroska 

Source
Expand description

Clean-room Matroska (MKV) and WebM demuxer, written from RFC 8794 (EBML), RFC 9559 (Matroska) and the WebM container guidelines.

  • open / open_with parse the EBML header and the first Segment (Info, Tracks, SeekHead, Cues, Chapters, Tags, Attachments) and, by default, scan every Cluster’s block headers to build per-track Sample tables — the same shape as isobmff, so callers can treat both containers alike. Frame data is read on demand with MkvFile::read_sample.
  • Demuxer iterates Packets in file order (from any ByteSource, Read + Seek, or a byte slice) and seeks to the keyframe preceding a time, via the index, Cues, or a cluster scan.

No dependencies beyond std, no unsafe, builds for wasm32-unknown-unknown.
