Module media 

Source
Expand description

Media containers and bit-level I/O for the Craft apps. Codecs are in other crates (craft-audio; video later), which depend on this one.

  • bitstream (feature bitstream): MSB-first bit reader and writer, Exp-Golomb codes, emulation-prevention escaping and NAL unit splitting.
  • isobmff (feature isobmff, enables bitstream): a clean-room ISO BMFF (MP4) and QuickTime (MOV) demuxer and muxer, and a box reader for other ISO BMFF formats.
  • matroska (feature matroska): a clean-room Matroska (MKV) and WebM demuxer and muxer.
  • ogg (feature ogg): a clean-room Ogg demuxer with Ogg Opus and Ogg Vorbis stream mapping.
  • avi (feature avi): a clean-room AVI (RIFF) and OpenDML demuxer.
  • mxf (feature mxf, enables chrono): a clean-room MXF demuxer and writer (OP1a, OP-Atom).
  • mpegts (feature mpegts): a clean-room MPEG-2 Systems demuxer (transport streams and program streams).
  • Container and CodecId (no feature): the identifiers the codec crates report a file’s container and codec with.

bitstream and isobmff are on by default; matroska, ogg, avi, mxf and mpegts are opt-in. A crate that needs only bit I/O uses default-features = false, features = ["bitstream"].

source
Random-access byte sources: what the demuxers read from. One trait for every container, so a file, buffer or custom source implements it once.
