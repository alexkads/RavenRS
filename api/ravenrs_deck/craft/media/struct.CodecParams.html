Expand description

What a decoder needs to know about a track, whatever container it came from.

extradata is the codec configuration in Matroska’s CodecPrivate form, which ffmpeg’s extradata also follows:

Codecextradata
AACAudioSpecificConfig
Opusthe OpusHead identification header (RFC 7845 §5.1)
Vorbis, Theorathe three headers, Xiph-laced
Speexthe Speex header
FLACfLaC followed by the metadata blocks (STREAMINFO first)
ALACthe magic cookie (ALACSpecificConfig)
AC-3 / E-AC-3the MP4 dac3 / dec3 payload, or empty
MP1/MP2/MP3, PCMempty
H.264 / HEVC / AV1the avcC / hvcC / av1C record
VP9the MP4 vpcC payload, or Matroska’s codec feature metadata
APVthe apvC record

sample_rate and channels are what the container declares (for HE-AAC with implicit signalling, usually the core rate), except that Opus is always 48 kHz, the rate it decodes at; width and height are the coded picture size of a video track. tag is the container’s four-character code for the codec when it has one (the MP4 sample entry format, Matroska’s ProRes or VfW FourCC), which is how a ProRes profile (apcn, ap4h, …) or a DNx variant is told apart.

#[non_exhaustive]: build it with CodecParams::new and the with_* methods.
