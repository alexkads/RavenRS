Mp3

MPEG-1/2 audio (esds object type 0x69/0x6B, or QuickTime .mp3 / .mp2). Usually layer III, but these name no layer: ffmpeg stores MP2 as mp4a + 0x6B. Each frame header has it, and crate::craft::media::isobmff::Track::codec_params reports the layer the first frame names.

impl CodecConfig

Source

pub fn codec_id(&self) -> CodecId

The codec this configuration is for. Mp3 covers every MPEG audio layer: these entries name none, and each frame header has it (ffmpeg stores MP2 as mp4a + 0x6B); crate::craft::media::isobmff::Track::codec_params reads it from the first frame.

Source

pub fn extradata(&self) -> Vec<u8> ⓘ

The codec configuration in Matroska’s CodecPrivate form (see crate::craft::media::CodecParams): the OpusHead built from dOps, fLaC + the dfLa metadata blocks, the other records as stored.
