Expand description

Random-access, read-only byte source (file, in-memory buffer, web Blob…).

Implementations serve reads at arbitrary offsets through &self. isobmff::ByteSource, matroska::ByteSource and ogg::ByteSource are this trait.

impl ByteSource for File

Available on non-WebAssembly only.

A file read in place. len asks the file system each time, and a failure there reads as an empty file; ReadSeekSource takes the length once and reports a failure when it is made.
