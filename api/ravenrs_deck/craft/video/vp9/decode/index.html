Module decode 

Source
Expand description

Clean-room pure-Rust VP9 decoder, implemented from the public VP9 Bitstream & Decoding Process Specification (v0.6, WebM project).

Supported: profiles 0-3 (8 / 10 / 12-bit; 4:2:0, 4:2:2, 4:4:0, 4:4:4), all coding tools: boolean decoder, forward and backward probability adaptation, segmentation, loop filter with deltas, all intra modes, inter prediction (8-tap regular / smooth / sharp and bilinear, scaled references), compound prediction, motion vector prediction, DCT / ADST 4..32 and the Walsh-Hadamard lossless transform, tiles (tile columns decode in parallel), superframes, hidden frames, show_existing_frame, intra-only frames, reference frame resizing and error resilient / frame parallel modes.

ⓘ
let mut dec = ravenrs_deck::craft::video::vp9::decode::Decoder::new();
let chunk: Vec<u8> = Vec::new(); // one IVF / WebM frame
for pic in dec.decode(&chunk, 0).unwrap() {
    println!("{}x{} {}-bit", pic.width, pic.height, pic.bit_depth);
}
