Clean-room pure-Rust Opus (RFC 6716, updated by RFC 8251; RFC 7845 OpusHead).

Decoding (feature opus-decode): Decoder (multistream, surround), StreamDecoder (one elementary stream), OpusHead and the packet parser packet. From FilmCraft’s filmcraft-opus (storytold/filmcraft@8fda2f2).

Public items keep their names, so FilmCraft can re-export this module.
