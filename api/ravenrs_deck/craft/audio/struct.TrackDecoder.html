Struct TrackDecoder 

Source 
pub struct TrackDecoder { /* private fields */ }
Expand description

Decodes the packets of one audio track to planar f32, in WAV channel order when TrackDecoder::layout is ordered.

It takes the track’s CodecParams (from isobmff::Track::codec_params, matroska::Track::codec_params, ogg::Stream::codec_params, or built by hand for another container) and decodes AAC (LC; HE-AAC as its upsampled LC core), ALAC, Opus, AC-3/E-AC-3, MP1/MP2, MP3 and PCM. Container timing (AAC priming, Opus pre-skip, end trimming) is the caller’s: every decoded sample is returned.

ⓘ
use ravenrs_deck::craft::audio::TrackDecoder;

let lookahead: Vec<&[u8]> = packets.iter().take(8).map(Vec::as_slice).collect();
let mut dec = TrackDecoder::new(params, &lookahead)?;
println!("{} at {} Hz, {}", dec.codec().name(), dec.sample_rate(), dec.layout());
for p in packets {
    let block = match dec.decode(p) {
        Ok(block) => block,
        Err(_) => dec.conceal(Some(p))?, // keep the timing across a damaged packet
    };
    // block.channels: one Vec<f32> per channel
}

impl TrackDecoder

Source

pub fn new(params: &CodecParams, lookahead: &[&[u8]]) -> Result<TrackDecoder>

A decoder for the track params describes. lookahead holds the track’s first packets (up to LOOKAHEAD_PACKETS; empty when they are not at hand): HE-AAC signalled only inside the stream is found in them, and AC-3 and MPEG audio take their rate and channel layout (MPEG audio its layer too) from the first frame. Without them those are taken from params and set from the first decoded packet.

Streams without codec configuration are accepted where the packets carry it: AAC with empty extradata takes its configuration from the ADTS headers of the lookahead (MPEG-TS, raw .aac), the one most of them share, and ADTS headers are stripped from every packet; Opus with empty extradata and 1 or 2 channels (RTP, MPEG-TS) needs no OpusHead. Other missing configuration is AudioError::Malformed.

ALAC needs its magic cookie in extradata.

Codecs without a native packet decoder yet (FLAC, Vorbis) are AudioError::Unsupported; crate::craft::audio::decode decodes them through symphonia when the symphonia feature is on.

The codec, refined from the stream: CodecId::HeAac for AAC with spectral band replication, Eac3 for Dolby Digital Plus, Mp1/Mp2 by layer.

The rate of the decoded audio (for HE-AAC, twice the AAC-LC core rate).

The speakers of the decoded channels; ordered layouts come in WAV order.

The number of decoded channels.

The stored sample format: the PCM depth, or SampleFormat::Compressed.

Source

pub fn decode(&mut self, packet: &[u8]) -> Result<AudioBuffer>

Decode one packet. An MP4 or Matroska packet may hold several AC-3 or MPEG audio frames; an E-AC-3 dependent substream decodes to no frames. A packet that fails is an error for every codec: call TrackDecoder::conceal for audio of its length, so what follows keeps its timing.

Source

pub fn conceal(&mut self, packet: Option<&[u8]>) -> Result<AudioBuffer>

What stands in for a lost or undecodable packet (packet when its bytes are at hand): Opus’s loss concealment, or silence, as long as the packet would have been (from its TOC or frame header, the codec’s frame length, or the last packet). Empty when the length is unknown. Fails with AudioError::TooLarge when that silence would pass the decode limit (2^30 samples, as decode has) or cannot be allocated, rather than return less than the packet’s length.

Source

pub fn frames_per_packet(&self) -> Option<usize>

The frames every packet decodes to, for codecs whose packets all have one length: AAC (1024, 2048 for HE-AAC; a packet of several ADTS frames decodes to that many times this) and AC-3 / E-AC-3 (the frames of the last decoded packet, else of the first packet’s primary syncframes, else 1536) and MP1/MP2/MP3 (one frame per packet; 576 for MP3 at the lower sampling frequencies); None for Opus, PCM and ALAC (whose last packet is shorter; the container’s timing says), for AC-3 / E-AC-3 whose packets read so far differ in length, and for MPEG audio once a packet (in the lookahead or decoded) has held several frames.

Source

pub fn preroll(&self) -> usize

Frames to decode before a seek target and drop, so the decoder has settled when the target is reached: two AAC frames, 80 ms of Opus (RFC 7845 §4.6), one AC-3 or MP1/MP2 frame (their filter banks overlap one frame), for MP3 the frames its bit reservoir can reach back over and two more, none for ALAC (its packets decode independently) and PCM. E-AC-3 syncframes of fewer than six blocks may reuse exponents from any syncframe before them, so once one has been read the stream decodes from its start (usize::MAX).

Source

pub fn reset(&mut self)

Forget the decoder state, for a seek: the next packet decodes as if it were the first (codecs with overlap, such as AAC and Opus, need TrackDecoder::preroll frames to settle).
