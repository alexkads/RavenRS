Module audio 

Source
Expand description

Audio file I/O and codecs for the Craft apps. Input and output are byte slices or a crate::craft::media::ByteSource (no filesystem access of its own); builds for wasm32-unknown-unknown.

  • [decode], [probe], [Decoder] (streaming, seekable), [tracks], [detect_container] (feature decode): WAV and AIFF are read natively; AAC, ALAC, Opus, AC-3/E-AC-3, MP1/MP2/MP3 and PCM in MP4/MOV, Matroska/WebM, Ogg or raw streams go through craft-media’s demuxers and TrackDecoder; everything else (FLAC, Vorbis, CAF, ADPCM, A-law, µ-law) through symphonia, which is to be replaced by native decoders. Feature decode-native is the same without symphonia.
  • TrackDecoder (any decoder feature): one track’s packets from any demuxer to planar f32 in WAV channel order.
  • [encode], [FileEncoder]: WAV/BWF/RF64 and AIFF/AIFF-C (feature pcm-encode, which also gives [wav_float_header]) and FLAC (feature flac-encode), whole-buffer or incremental into any Write + Seek. Feature lossless-encode turns on both; feature encode turns on lossless-encode and every codec’s encoder.
  • [wav_pcm], [aiff_pcm] (feature decode-native) and [pcm_wav_file], [pcm_wav_header], [pcm_aiff_file], [pcm_aiff_header] (feature pcm-encode): the integer PCM of a WAV or AIFF file bit for bit, and minimal files around such PCM, for essence embedded in other containers.
  • [peaks] (feature peaks): min/max/RMS pyramid for waveform drawing.
  • Codec modules for packet-level use, each with its own features: [aac] (aac-decode, aac-encode), [alac] (alac-decode, alac-encode), opus (opus-decode), [ac3] (ac3-decode), [mpa] (mpa-decode), [mp3] (mp3-decode, mp3-encode), [flac] (flac-encode: the packet encoder).

The shared types below build with no features.
