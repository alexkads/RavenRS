Expand description

The DeckCraft renderer: draws slides, layouts and masters with vello_cpu.

One code path serves the editor canvas, thumbnails, image/PDF-raster export and the slide show: render_slide draws the background, the master and layout graphics, then the slide’s shapes (fills with theme shading, gradients, pictures, outlines with dashes and arrowheads, shadows, glow and soft edges, text, tables, charts, groups), optionally with per-shape animation state.
