Crate ravenrs_platform_native 

Source
Expand description

Desktop backend for RavenRS: one winit window per app, rendered with wgpu (Metal on macOS, DX12/Vulkan on Windows, Vulkan/GL on Linux).

Frames are produced on demand: the event loop sleeps until input arrives or reactive state changes, so an idle app uses no CPU or GPU time.

Screen readers see the UI through AccessKit: the accessibility tree is built only while one is running.

diagnose
Finds the GPU the way a window would and describes it, along with the machine and the build, without showing anything. For a command line option such as --diagnostics, which still answers when a window would not open or would be too slow to use. Printing the result gives text to paste into a bug report.
open_url
Opens a web page in the browser. Only http and https are accepted, so a bad URL cannot end up running a program or opening a file instead.
open_with_system
Opens a file with the program the system uses for it: a PDF in its viewer, a web page in the browser. The program runs on its own, so this does not wait for it.
run
Opens a window showing root and runs until it is closed.
run_as
Like run, for an app the system should recognize as itself.
run_with_icon
Like run, with an icon for the window’s title bar and the task bar on Windows and Linux. macOS takes an app’s icon from its bundle instead.
