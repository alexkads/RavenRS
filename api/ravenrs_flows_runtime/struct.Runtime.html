Struct Runtime 

Source 
pub struct Runtime { /* private fields */ }
Expand description

Durable runs of flows, kept in a SQLite file that several processes may share: each claims a run with a lease, runs it writing a checkpoint after every node, and a run left by a worker that died goes back to the queue when its lease runs out.
