Expand description

A kind of node: what it says about itself and the code that runs it.

It is Send + Sync so that a run may happen on a worker thread.

Required Methods§

Source

fn spec(&self) -> NodeSpec

Its ports and how a run treats it.

Source

fn execute(&self, cx: &NodeContext<'_>) -> Result<Ports, NodeError>

Runs one node of this kind: from what reached its inputs, the items of each output port. A port it leaves out gives no items. Items that failed one by one go to ERROR_PORT (see Item::failed); a failure of the whole node is the Err.

Provided Methods§

Source

fn outputs(&self, node: &NodeDef) -> Vec<String>

The output ports of node, a node of this kind: its spec’s, unless they depend on how the node is set up (a switch with one output per case).

Source

fn reconcile(&self, cx: &NodeContext<'_>) -> Reconciled

After execute failed with Failure::Unknown, finds out whether the call happened (looking it up in the service, by a key the node sent). A kind that cannot tell leaves the default, and the node stays uncertain rather than be repeated.

Dyn Compatibility§

This trait is dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
