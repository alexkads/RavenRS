Struct NodeContext 

Source 
pub struct NodeContext<'a> { /* private fields */ }
Expand description

What a node has while it runs: its setup, the items that reached each input, the time and the mode.

The context of node, with inputs, at now_ms milliseconds since 1970, in mode, on the machine’s clock, with nothing to cancel it and no time limit.

pub fn iteration(&self) -> usize

Which turn of its loop this is, from 0. A loop node runs once per turn, and what came back to it in every earlier turn reaches its input from the back connections; any other node is at 0, or at the turn of the loop it is inside.

Source

pub fn attempt(&self) -> u32

What says the run, or this node, should stop. A node that calls something slow gives it on, or a child of it, so the call can stop too.

Source

Source

pub fn time_left_ms(&self) -> Option<i64>

How long the node has left, in milliseconds on its clock, when it has a time limit.

Source

pub fn check(&self) -> Result<(), NodeError>

Ok while the node may go on; the error to return when it was cancelled or its time is up. A long node calls it between steps.

Source

pub fn sleep(&self, ms: u64) -> Result<(), NodeError>

Waits ms milliseconds on the run’s clock, a little at a time, and stops early when the node is cancelled or its time is up.
