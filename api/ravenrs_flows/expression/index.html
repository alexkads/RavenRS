Module expression 

Source
Expand description

What an expression of a flow can read, and how a parameter written as text with expressions inside it (Olá {{ nome }}) is checked, previewed and worked out.

The expressions are of the criteria language (ravenrs-criteria). An item’s own fields read as they are ([nome] or {{ nome }}), and four names reach further: item (the item), nodes.<id> (the first item a node that already ran gave), vars (the app’s variables) and run (the run: its started, in milliseconds since 1970). Each evaluation gets its own environment, so runs on different threads never share one.
