pub fn cancel_with(self, token: CancelToken) -> Self

Cancelled by token: keep a clone and call CancelToken::cancel from any thread. Each node then runs on a thread of its own, so a node that does not look at its token is still left behind when the run is cancelled.

Source

pub fn run(&self) -> Run

Runs the whole flow: triggers first, then each node as the plan orders them, each loop going round its body.

Source

pub fn resume(&self, checkpoint: &Run, in_progress: &BTreeSet<String>) -> Run

Goes on with a run that stopped: the nodes whose part is in checkpoint keep it and do not run again (a waiting node runs again, to see whether its wait is over), the nodes in in_progress were running when it stopped and are asked to reconcile first (NodeKind::reconcile), and the rest run. The run keeps the time it first started.

Source

pub fn run_from(&self, node: &str, previous: &Run) -> Result<Run, RunError>

Runs node and every node it leads to; the nodes upstream do not run again, and what they gave is taken from previous. A node inside a loop’s body runs that turn once.

Source

pub fn run_node(&self, node: &str, previous: &Run) -> Result<Run, RunError>

Runs node alone, with what reached it in previous; nothing after it runs, and a loop node takes one turn.
