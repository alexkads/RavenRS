Crate bpmn_editor 

Source
Expand description

A BPMN 2.0 editor made only of RavenRS components: FlowLibrary, FlowToolbox, FlowCanvas and FlowInspector take BPMN from ravenrs_flow_bpmn::notation(), Chat talks to a model running on this machine through ravenrs-ai, and ModelManager gets one. Nothing on the screen is drawn here: the app only joins the parts.

  • The palette has the elements of BPMN; connections take the right kind as they are made.
  • Check, in the canvas’s controls, says what is wrong and outlines where.
  • Processes are kept by name, and open and save as BPMN 2.0 XML with their drawing, which other BPMN tools read.
  • The assistant drafts a process from a description, or reviews the one open.
