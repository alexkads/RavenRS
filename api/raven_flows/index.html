Raven Flows: an automation app where flows of nodes are drawn on a FlowCanvas, run for real by ravenrs-flows and kept by ravenrs-flows-runtime.

It is made only of RavenRS components and is here to test them: it creates no component and wraps none. What a screen needs that no component does is a gap of the library, with an issue under #523, and stays out until the component has it.

Modules§

casa
Where the app keeps what it has, with no screen: the flows as JSON files, one per flow, and the runs in the SQLite file of ravenrs-flows-runtime. The screens ask this module and never touch the files or the database themselves.
marcas
A run of the runtime as the canvas is told it: each node’s part becomes a FlowNodeRun, with its status and how many items left by each port, and the canvas draws it with FlowCanvas::execution, on a copy, never touching the flow.
nos
The kinds of node of Catalog::builtin, as the app shows them: a name in Portuguese, an icon and a group, and the FlowToolbox they are dragged from, whose cards are the bridge’s (ravenrs_flows::card), so a node dragged in has the ports to_graph would give it.
versao
Who the app is to the installer and the updater of ravenrs-app-update, the same that install and update Raven Finanças: its name, folders and addresses.
