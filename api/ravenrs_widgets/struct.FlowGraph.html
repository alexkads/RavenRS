pub fn set_parent(&mut self, id: &str, parent: Option<&str>) -> bool

Puts id in the group parent (or in none). Refused, saying false, when parent is not a group or is id or inside it. The node and what it holds move after the group in the diagram’s order, so the group is drawn behind them.

Source

pub fn group(&mut self, members: &[String], group: FlowNode) -> bool

Puts these nodes in a new group group, sized to hold them with FlowNode::GROUP_PADDING around, and in the group they shared, if they all shared one. The group goes behind the first of them. Returns false, changing nothing, when there are no such nodes or the id is taken.

Source

pub fn bring_to_front(&mut self, ids: &[String]) -> bool

Brings these nodes, with what the groups among them hold, in front of every other node, keeping their order among themselves. A node in a group stays after its group, so the group is still drawn behind it. Says whether the order changed.

Source

pub fn send_to_back(&mut self, ids: &[String]) -> bool

Sends these nodes, with what the groups among them hold, behind every other node: to the very back, or, for a node in a group, to just after its group. Says whether the order changed.

Source

pub fn ungroup(&mut self, id: &str) -> bool

Takes out the group id, leaving what it held in the group it was in. Says whether it was a group.

Source

pub fn insert( &mut self, piece: &FlowGraph, dx: f32, dy: f32, ) -> (Vec<String>, Vec<String>)

Adds a copy of piece moved by (dx, dy), on top of the other nodes. Nodes and connections whose ids are taken get new ones, and the connections follow their nodes; a connection whose ends are not both in piece stays out. Returns the ids the copies got, nodes first.

Source

pub fn insert_with( &mut self, piece: &FlowGraph, dx: f32, dy: f32, remap: impl FnMut(&mut FlowNode, &dyn Fn(&str) -> Option<String>), ) -> (Vec<String>, Vec<String>)

As insert, and then remap is called on each node put in, with a function from an id of piece to the id its copy was given: the app renames there what the node’s data says of other nodes that NODE_REFS does not list.

Source

pub fn to_json(&self) -> String

The diagram as JSON, indented, at the version FLOW_FORMAT, which Self::from_json reads back.

Source

pub fn from_json(text: &str) -> Result<FlowGraph, FlowJsonError>

Reads a diagram written by Self::to_json (or by hand), moving JSON of an earlier version to this one, and checks that it holds together: ids are not repeated and every connection joins ports that exist. JSON of a newer version is refused, so an older build never drops what it does not know; the app’s data is kept as it came.

Source

pub fn check(&self) -> Result<(), FlowJsonError>

The first thing that keeps the diagram from holding together, if any: a repeated node, port or connection id, a connection to a node or port that is not there, or a node in a group that is not there, is not a group or holds it.
