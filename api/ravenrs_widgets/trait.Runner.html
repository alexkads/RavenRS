Expand description

What turns the code of a Playground into something to show.

It runs when the person asks, never on every frame, so it may take its time and build whatever it needs anew.

Provided Methods§

Source

fn take_output(&self) -> RunOutput

What the code printed, and the problems of what it runs later, such as a closure on a click, since the last time this was asked. Nothing, unless the runner keeps them.

Source

fn watch(&self, wake: Rc<dyn Fn()>)

Calls wake whenever there is something new for Self::take_output, so the playground shows it as it comes. Nothing, unless the runner can tell.
