Struct SplashScreen 

Source 
pub struct SplashScreen { /* private fields */ }
Expand description

The opening screen that covers the window while the app loads: a logo or icon, the app’s name, a status message and its progress.

It takes no input and has nothing to focus, so the page behind it stays out of reach until the app sets visible to false and the screen fades out. It is on screen from the very first frame, with no fade in. Without Self::progress it shows a Spinner.

Status and progress are plain values, so build it where they are read, such as in a Component body or a view_fn.

use ravenrs_reactive::State;
use ravenrs_widgets::{IconName, SplashScreen, View, view_fn};

let loading = State::new(true);
let progress = State::new(0.25);
let splash = view_fn(move || {
    SplashScreen::new(loading.binding(), "Raven Finance")
        .icon(IconName::Wallet)
        .status("Opening the database")
        .progress(progress.get())
});
