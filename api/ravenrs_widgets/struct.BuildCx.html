Struct BuildCx 

Source 
pub struct BuildCx<'a> { /* private fields */ }
Expand description

What a View uses to describe itself during a build: theme access, interaction state, child building, layout boxes, painting and behavior.

pub fn observe_activity(&mut self, observer: ActivityObserver)

Watches the whole UI while this view is built: each painted frame, the pointer and clicks. For recording what happens, as a flight recorder does. It runs on every frame, so it has to be quick. The last call of a build wins.

Source

pub fn wake_at(&mut self, time: f64)

Asks for a rebuild at time (seconds, the same clock as Self::now): toasts that expire, carousels that advance, spinners that turn.

Source

pub fn motion(&mut self, node: NodeId, motion: Motion)

Declares how node animates; see Motion. Call it in the same order on every build, or give the motion a Motion::key.

Source

pub fn animated<T: Animatable + 'static>( &mut self, target: T, transition: Transition, ) -> T

A value that eases toward target, for what Motion does not cover: numbers that feed layout or custom drawing. Call it in the same order on every build. It rebuilds the UI on each frame while it moves, so prefer Motion when you can.

Source

pub fn reduced_motion(&self) -> bool

The user asked for less motion, in the system settings or in the theme. Motion already respects this; check it for motion you draw yourself.

Registers an app-wide keyboard shortcut for as long as this view is built. With command, it needs Cmd (macOS) or Ctrl held, e.g. Cmd/Ctrl+K.

pub fn translate(&mut self, node: NodeId, offset: Point)

Source

pub fn on_pinch(&mut self, node: NodeId, handler: Rc<dyn Fn(f32)>)

Calls handler on a zoom gesture over the node, with how much larger was asked for relative to now: 0.02 is 2% larger, and a negative value is smaller.

Source

pub fn on_double_click(&mut self, node: NodeId, handler: Rc<dyn Fn()>)

Calls handler on a double click on the node.

Source

pub fn scrollable(&mut self, node: NodeId)

Makes the node a vertical scroll container: its children scroll with the wheel or trackpad, are clipped, and a scrollbar is drawn when they overflow. Give the node LayoutStyle::overflow_hidden so it does not grow to fit.

Source

pub fn overlay( &mut self, anchor: NodeId, placement: Placement, view: &dyn View, on_dismiss: Option<Rc<dyn Fn()>>, )

Builds view as a floating layer above the rest of the UI, placed relative to anchor. on_dismiss is called on a click outside the layer and its anchor, or on Escape.
