Trait View

pub trait View {
    // Required method
    fn build(&self, cx: &mut BuildCx<'_>) -> NodeId;
}
Expand description

Anything that can appear in the UI.

build runs whenever the UI rebuilds. It must be cheap and side-effect free: read state, create layout boxes and paint instructions through cx, and return the node that represents this view.
