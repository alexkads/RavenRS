Struct Ui 

Source 
pub struct Ui { /* private fields */ }
Expand description

The platform-independent UI runtime: owns the root view, reacts to input and state changes, and produces a Scene for the renderer.

Platform layers drive it with Ui::set_viewport, Ui::handle_event and Ui::update, and register a waker with Ui::set_waker to schedule a frame when state changes outside of event handling (timers, async tasks).

pub fn access_tree(&mut self) -> AccessTree

The accessibility tree of the latest frame: roles, names, states and frames of everything on screen, for screen readers. Call it after Ui::update; platform layers send it to the operating system when it changes. While a modal layer is open, only that layer is exposed.

pub fn set_time(&mut self, seconds: f64)

Sets the clock (seconds since the app started). Platforms call it before handling events and before each frame. Animations start only once a platform drives this clock.

Animations follow their own clock, which skips stalls: after a long pause (a hidden window, a slow frame) they continue about where they were instead of jumping to the end.

Source

pub fn set_reduced_motion(&mut self, reduced: bool)

Tells the runtime that the system asks for reduced motion. Things stop traveling and springing; colors and opacity may still fade. A theme can ask for the same through its reduced_motion token.

Source

pub fn next_wake(&self) -> Option<f64>

When the UI wants its next frame even without input (seconds, same clock as Ui::set_time). Platforms schedule a timer for it.

pub fn is_dragging(&self) -> bool

True while a pointer drag that started on a draggable element (a slider, a splitter) is in progress. Touch platforms use it to tell drags from scrolls.
