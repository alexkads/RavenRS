Crate ravenrs_app_postgrest 

Source
Expand description

Records in PostgreSQL through PostgREST, as an ObjectSpace: the server of your own, the one in Supabase, or Neon’s Data API. The station holds the token of the person signed in, never the database’s password, and the database’s grants and row level security decide what it sees.

  • Reads go as GET /{resource} with the filter in PostgREST’s words (see the filter module), page after page until an empty one, so the server’s max-rows cuts nothing. What its words cannot say is read and filtered in memory, as the SQL spaces do.
  • A commit is one call, POST /rpc/ravenrs_commit, of a function that applies every change in one transaction as whoever called it. Install it with SERVER_SQL.
  • What waits for a commit, the rules, state machines and calculated fields work as in the SQL spaces, through the same pieces of ravenrs-app.

Only for the desktop for now: a space answers at once, and a browser cannot wait.
