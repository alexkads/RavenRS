Module plot 

Source
Expand description

The charts of a dashboard: the same numbers as crate::chart, laid out for a screen. Besides what to draw, it says where each thing landed, so that whoever shows it can tell what is under the pointer without asking for another picture.

crate::chart stays as it is, so documents already printed keep their looks.
