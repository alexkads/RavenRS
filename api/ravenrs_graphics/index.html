Crate ravenrs_graphics 

Source
Expand description

Drawing logic shared across RavenRS. It depends on no engine, so reports, the UI and any later module draw the same charts and the same barcodes.

  • vector holds shapes that PDF and SVG can write as they are, and a rasterizer for the outputs that need pictures.
  • chart lays numbers out as shapes and labels.
  • barcode turns text into the modules a scanner reads.

Modules§

barcode
Barcodes: turns text into the modules a scanner reads. Pure logic, so every output draws the same code and it can be tested without drawing.
chart
Chart layout: turns aggregated numbers into shapes and labels. Pure logic, kept apart from the engine so it can be tested without rendering a report.
vector
Vector shapes: curves and polygons that PDF and SVG write as they are, and that the screen and spreadsheets get as a picture.
