Crate ravenrs_app_pos 

Source
Expand description

BETA, proof of concept. A point of sale as an application module: products, a checkout used from the keyboard and a scanner, sales kept to pick up later, services sold with an NFS-e, shelf labels and receipts made in the standard report designer. The rules are in ravenrs-pos, and issuing in ravenrs-app-nfe.
