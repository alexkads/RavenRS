The models that can be offered, smallest first. Only their files are listed: a model comes to the machine only when someone asks for it.

Memory was measured at its peak on an Apple M2 Pro for Qwen3 1.7B, Qwen 2.5 0.5B and Llama 3.2 1B; the others are scaled from their family, and ModelManager’s speed test lets each machine check them. Gemma 3 270M is not here on purpose: it ran, and understood none of the requests.
