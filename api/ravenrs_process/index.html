Running a child program and watching it: the arguments apart (no shell), the folder, an environment of only the variables let through, lines written to its input, each line of its output and of its errors as an event as it comes, a time limit, and stopping it with every process it started.

use std::time::Duration;
use ravenrs_process::{Event, Spec};

let running = Spec::new("cargo").arg("--version").timeout(Duration::from_secs(10)).spawn()?;
for event in running.events() {
    match event {
        Event::Out(line) => println!("{line}"),
        Event::Err(line) => eprintln!("{line}"),
        Event::Ended(end) => println!("ended: {end:?}"),
    }
}

On Linux and macOS the child leads a process group of its own, so stopping it reaches what it started: first a polite stop (TERM), then, after GRACE, a forced one (KILL). On Windows the child runs with no console window and taskkill /T stops the tree.
