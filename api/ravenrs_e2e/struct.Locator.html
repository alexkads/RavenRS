Struct Locator 

Source 
pub struct Locator<'a> { /* private fields */ }
Expand description

What a Query finds in a session, to act on or check. Made by E2e::locate and its shorthands; each action finds the node again, on the screen as it is at that moment.

pub fn fill(self, text: &str) -> E2eResult

Puts text in the field in place of what it has: a text field is cleared and typed into, a number (slider, spin button) is moved with the arrow keys until it shows the value. A cell of a grid is opened with a double click, as a person edits it, and the new text is confirmed with Enter; a cell marked read only fails with E2E_DISABLED.

Source

pub fn select(self, option: &str) -> E2eResult

Picks option: in a list, a tab list or a group shown in place, it clicks the option inside it; in a combo box or a button that opens a menu, it opens it first.

pub fn drag_to(self, to: &Query) -> E2eResult

Drags the node to the middle of the one to finds, with the primary button held.

to is looked for once the drag has started, as a person looks for where to drop: what shows only during a drag, such as the free ports of a diagram, can be the target. When it is not there, the button is let go where it was pressed and the step fails.
