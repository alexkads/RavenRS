Source
Expand description

A web API over an application’s model: the same entities, rules, permissions, states and audit trail as its screens, for clients that do not use RavenRS.

ApiService answers requests with no HTTP around it, and serve and router put HTTP around one. Every write goes through a SecuredObjectSpace, so what a person cannot do on the screens they cannot do here, and every read leaves as that person can see it.

Tokens live in memory: restarting the service asks everyone to sign in again. It speaks plain HTTP, so anything beyond the machine it runs on belongs behind something that does TLS.
