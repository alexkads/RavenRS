Crate ravenrs_widgets_kit 

Source
Expand description

The components of general use in RavenRS: navigation (Tabs, Sidebar), commands and toolbars, form editors and layouts, lookups, filters and expressions, status pieces, tiles, the theme editor, diagnostics and the counter’s keys. The families of components (grid, lists, dock, scheduler, imaging, charts, chat) are built on them and on ravenrs-widgets-base.

Applications depend on ravenrs-widgets (or ravenrs), which re-exports all of this by the same names. The modules are public only for the crates of the families; they are hidden from the documentation and are not a stable API.
