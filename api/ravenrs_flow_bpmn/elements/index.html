Module elements 

Source
Expand description

The elements of BPMN 2.0 as nodes and connections of a FlowGraph: each node’s kind is the element’s name in the XML (task, exclusiveGateway), each connection’s kind is empty for a sequence flow, or association or messageFlow.

The elements offered, by their XML name, with the words shown for each.
LANE
A lane, a group of the steps someone does.
MESSAGE
A message between participants.
PARTICIPANT
A participant (a pool): a company, a system or a customer with a process of its own; what passes between participants is a message.
SEQUENCE
A sequence flow’s kind: none.
