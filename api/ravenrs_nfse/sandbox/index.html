Module sandbox 

Source
Expand description

A sandbox of the Sefin Nacional, in the style of MSW: it implements [Transport], so the emitter builds the same bytes and calls the same addresses, and nothing leaves the computer.

MSWHere
http.post('/nfse', resolver)post, get, head with a [Rota]
server.use(handler)SefinSandbox::use_handler
{ once: true }SefinSandbox::use_once
server.resetHandlers()SefinSandbox::reset_handlers
onUnhandledRequestSefinSandbox::on_unhandled

With no handler, it answers as the Sefin would, after checking for real: GZip and Base64, the namespace and version, the Id against the fields it is made of, tpAmb=2, the signature with the hash it was made with, a DPS already used, and the agreement of the city. Each refusal comes with its code, where the code came from and how sure that is (regra).

The NFS-e it gives back is a reduced one: infNFSe with the Id, the number, the date of processing and the DPS received. It does not follow the whole TCInfNFSe.
