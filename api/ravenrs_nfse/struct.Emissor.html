pub fn emitir(&self, dps: &Dps) -> Result<Emitida, NfseError>

Sends the DPS and returns the NFS-e.

If the answer is lost (time out, connection cut, 5xx) or the Sefin says the DPS already exists, it looks for the NFS-e by the Id of the DPS before saying anything. When it is not found either, the error is NfseError::NaoConfirmada: send the same DPS again, never with another number, or the same service gets two NFS-e.

Source

pub fn recuperar(&self, id_dps: &str) -> Result<Option<Emitida>, NfseError>

Looks for the NFS-e of a DPS by its Id: HEAD /dps/{id}, then the key in GET /dps/{id}, then the document in GET /nfse/{chave}. None means the DPS did not become an NFS-e.
