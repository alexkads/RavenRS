Module flow 

Source
Expand description

Diagrams of nodes joined by connections: the model and the geometry, with no engine.

A FlowGraph holds nodes placed in content units and the edges between their ports. route turns an edge into the outline of its line, and the helpers after it flatten that outline, measure how near a point is to it, find its middle for a label and cut it into dashes. The UI draws and hit-tests with them, and an exporter can draw the same lines.
