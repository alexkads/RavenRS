Module c14n 

Expand description

Inclusive Canonical XML 1.0 without comments (REC-xml-c14n-20010315).

The rules implemented, in the order of the recommendation: line ends and references come resolved from crate::xml, empty elements are expanded, namespace declarations are written first and sorted by prefix, attributes are sorted by namespace URI and local name, declarations the output parent already made are dropped, and an apex below the root inherits the namespaces and xml:* attributes of its ancestors.
