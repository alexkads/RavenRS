Expand description

Whatever holds a signing key. The default is RsaSigner; a token reader could be another.

Required Methods§

fn certificate_der(&self) -> &[u8] ⓘ

The DER of the certificate that goes in X509Certificate.

fn sign_rsa_sha1(&self, message: &[u8]) -> Result<Vec<u8>, DfeError>

Signs message with RSA PKCS#1 v1.5 over SHA-1.

Provided Methods§

fn sign_rsa( &self, hash: HashAssinatura, message: &[u8], ) -> Result<Vec<u8>, DfeError>

Signs message with RSA PKCS#1 v1.5 over this hash. The NF-e only uses SHA-1; SHA-256 is here for the NFS-e, and a signer that does not offer it says so.
