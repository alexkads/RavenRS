Module assinatura 

Expand description

XMLDSig with RSA-SHA1 and SHA1, the signature the NF-e layout requires, behind Signer.

The private key is only used to sign locally. Nothing here decrypts data, which is why the timing advisory of the rsa crate does not reach this use; see REGRAS.md.
