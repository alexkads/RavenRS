Function verify_enveloped 

pub fn verify_enveloped(
    parent: &Element,
    id_esperado: &str,
) -> Result<(), FalhaAssinatura>
Expand description

Checks the Signature child of parent against the certificate inside it, accepting only what the NF-e asks (Algoritmo::NFE).

parent must be the document as sent, with itself as the root of canonicalization. id_esperado is the Id the reference has to point at. The trust chain is not looked at.
