pub struct Emissor { /* private fields */ }

The fiscal emitter of the POC. Thread-safe; its sends block, so call them off the screen thread.

Fetches the documents after this NSU from the national environment.

Holds the query back, with NfeError::ConsultaAdiantada, if the last answer asked to wait one hour; that avoids rejection 656, which blocks the CNPJ. A resNFe is only a summary: register TipoManifestacao::Ciencia with Self::manifestar and fetch again.
