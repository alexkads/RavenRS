Struct TokenSimulado 

pub struct TokenSimulado(/* private fields */);
Expand description

An A3 simulated in memory: slot, PIN, lock after wrong attempts, and a key that never leaves.

Cloning gives another handle to the same token. Nothing here returns the key, and Debug hides the PIN and the key.
