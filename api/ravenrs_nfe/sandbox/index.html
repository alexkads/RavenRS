Module sandbox 

Source
Expand description

A local SEFAZ in the style of MSW, which also explains what went wrong.

The emitter builds the same bytes and calls the same addresses; only the Transport changes. With no handler of yours, the sandbox checks each message for real and answers in the real SOAP format, always with verAplic=RAVENRS-SANDBOX and with xMotivo starting [SANDBOX] .

§A diagnosis tool

  • diagnosticar lists everything wrong in a message, from the one catalogo the sandbox answers from, each finding with its source and how far it can be trusted.
  • autopsia::autopsia_assinatura says why a signature does not match.
  • Incidente::de_producao compares the answer the SEFAZ gave with what the catalog predicts, and says when it does not reproduce.
  • Gravador and Reprodutor take a field problem to the laboratory, masked.
  • SefazSandbox::injetar and Falha make failures happen on demand, repeatably.
  • SefazSandbox::linha_do_tempo tells the story of each key.
  • certificados issues A1 and simulated A3 test certificates that cannot leave the laboratory.
  • SefazSandbox::colocar_nota_recebida feeds the national distribution with test purchases.
