Reproduces a field problem offline, from the XML and the answer the SEFAZ really gave.

It compares what the server said with what the catalog predicts, and says when it does not reproduce. Everything this exports is masked. It sends nothing and signs nothing, so reading a production document here does not give the POC any way of issuing one.
