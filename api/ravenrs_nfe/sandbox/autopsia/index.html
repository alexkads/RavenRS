Module autopsia 

Source
Expand description

Says why a signature does not match, as far as the message itself can prove.

A digest cannot be undone, so the original is not recoverable. What can be done is to rebuild the versions a known mistake would have signed and see whether one of them gives the digest informed. When one does, the cause is proved and the first differing byte is known; when none does, the answer says so and offers only signs.
