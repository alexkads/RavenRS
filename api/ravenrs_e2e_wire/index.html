The test channel of RavenRS apps.

A tool, such as Raven Test Studio, opens the app under test in a child process with no window and drives it through this channel. The app answers with an ravenrs_e2e::E2e session over its own view, so a step runs exactly as it runs in process:

  • The app turns on the serve feature and, when it is opened with --e2e-serve, calls serve instead of opening its window. It decides what data the session sees: Raven Finanças opens its sample family in memory, never the database of the person using it.
  • The tool opens it with Client::spawn and sends Commands; each answer is a Reply, and a failed step comes back as a Failure with the stable code, the hint, what came close and the screen of the app as it was.

The channel is the child’s standard input and output, one JSON object per line: no port, no network, and it ends with the child. The app first says Hello, then answers each command in order.

The hello may also carry scenarios the app keeps in its own tests/e2e/ folder, as .raventest text (Scenario), so a tool can run the tests an app brings with it, installed or not, without the app’s source. Scenarios kept apart, in a folder of the QA team, use the same format and are run by path.

A step is written the way a person writes a block of a scenario: the target is #id for a test id or the text shown, as target reads it. Command::apply runs a command on a session in this process too, so a tool runs a scenario the same way whether the app is compiled in or opened apart.

§With the window

Opened with --e2e-serve --e2e-window (WINDOW_FLAG), an app that supports it shows its real window and answers the same commands on the interface the window shows (--headed in the tools): it builds its view as usual, keeps its test data, and hands ravenrs_platform_native::run_driven a Headed driver. Its hello says window: true; a tool that asked for the window and hears no such hello refuses with codes::NO_WINDOW. When the person closes the window during a test, the step waiting fails with codes::WINDOW_CLOSED. Command::Release ends the test and leaves the window to the person, to look at where a scenario failed.
