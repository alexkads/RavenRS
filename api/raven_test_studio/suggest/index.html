Module suggest 

Source
Expand description

Scenarios written by an AI for an app of a project the Studio was pointed at: when the app has none, and to suggest others it does not have yet.

The Studio opens the app on the test channel and reads its first screen as text, takes the views and test ids crate::project found in its sources and the names of the scenarios it already has, and asks an AI for .raventest files. The AI is local by default (a text model of ravenrs-ai already downloaded on this computer); Codex or Claude, with their cheapest model and reading only, when the person asks for them. The Studio does not trust what comes back: it reads each scenario and runs it on the app, and says which passed.
