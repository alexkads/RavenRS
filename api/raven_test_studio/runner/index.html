What each block of a scenario does, and running it with ravenrs-e2e.

A block’s kind says the action and its subtitle says the target and the text, as a person writes them: #valor = 152,40 types into the field tagged valor, Salvar clicks what shows “Salvar”. Each block becomes a command of the test channel (ravenrs-e2e-wire), run on an app compiled into the Studio or on one opened apart in a child process.
