Set the colour of a bookmark’s title (/C, ISO 32000-2 §12.3.3, Table 151: “An array of three numbers in the range 0.0 to 1.0, representing the components in the DeviceRGB colour space”). Black, the default, and None remove /C; a component outside 0–1 is refused.
