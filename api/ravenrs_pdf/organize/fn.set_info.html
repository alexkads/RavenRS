Set (or clear, with an empty value) a document-information entry.

Documents with XMP metadata also carry Title, Author, Subject, Keywords, Creator and Producer in the XMP packet, and viewers that read XMP first show its value: the packet’s property is changed (or removed) to match, and a custom property is kept there as pdfx:<key> as Acrobat keeps it (see xmp).
