Struct ShapedFonts 

Source 
pub struct ShapedFonts { /* private fields */ }
Expand description

The Type 3 fonts that draw a set of shaped clusters, one glyph per distinct cluster. The default has none (for text with nothing shaped).

pub fn new<'a>( clusters: impl IntoIterator<Item = &'a ShapedCluster>, outline: impl Fn(ShapedScript, u32) -> Result<GlyphOutline, GlyphError>, taken: &Dict, fonts: &mut Dict, prefix: &str, store: &mut dyn FnMut(Object) -> Object, ) -> Result<Self, (GlyphError, &'a ShapedCluster)>

Build the fonts for clusters into fonts, under names starting prefix that neither taken (the page’s fonts) nor fonts already has. outline gives a glyph’s outline in its script’s face (the craft-fonts faces, or a stand-in in tests). store keeps each new object and returns what refers to it: doc.add as a reference, or the object itself for an appearance that isn’t in a document yet, whose streams store_streams then moves in.

Every outline is read before anything is stored, so a failure (and the cluster it came from) leaves the document as it was.

Show clusters inside BT … ET from pen on baseline y at size, each placed with its own Tm, spacing after each and word_spacing more after a space. current is the shaped font the text state has selected (None after another font); returns the pen after the clusters.

pub fn show_line( &self, out: &mut Vec<u8>, pieces: &[Piece], x: f64, y: f64, size: f64, latin: &str, encode: impl Fn(&str) -> Vec<u8>, measure: impl Fn(&str) -> f64, current: &mut Option<usize>, )

Show a line’s pieces inside BT … ET from x on baseline y at size: shaped clusters in their Type 3 fonts, the rest in the font latin (which the text state has selected when current is None), written by encode and measured. current is as for Self::show.
