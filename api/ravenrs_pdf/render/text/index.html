Module text 

Source
Expand description

Text extraction (bootstrap for pdfcraft-text, architecture §8).

A hayro Device that ignores paint and records every glyph: its Unicode value (ToUnicode → encoding → glyph name fallbacks, handled by hayro) and its box in page view space, i.e. points with the origin at the top-left of the displayed page, rotation applied, y down. The UI maps view space to the screen with a single scale.

On top of the glyph list: line grouping (baseline clustering), word gaps, plain-text output, case-insensitive search and reading-order selection.

At most limit ranges, in order and not overlapping. Find and replace matches a paragraph’s text with it, so what the find bar highlights is what gets replaced.
