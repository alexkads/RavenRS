pub fn find_in_text(
    text: &str,
    needle: &str,
    case_sensitive: bool,
    whole_words: bool,
    limit: usize,
) -> Vec<Range<usize>>
Expand description

Byte ranges in text where needle occurs, with the find bar’s rules (PageText::find_opts): case folded unless case_sensitive, any run of whitespace matching one space, and with whole_words only where no letter or digit adjoins the match. At most limit ranges, in order and not overlapping. Find and replace matches a paragraph’s text with it, so what the find bar highlights is what gets replaced.
