pub fn resolve_uri(base: Option<&str>, raw: &str) -> Option<String>
Expand description

The address a URI action goes to when the document’s catalog gives base (/URI /Base): a relative reference (page.html, ../a/, ?q=1, //host/x) resolved against it by RFC 3986 §5 (the WHATWG URL rules, which the browser applies too). None when the address is used as written: it already has a scheme (https:, mailto:, javascript:…), there is no usable base, or the result wouldn’t be a web address.

Only a web (http, https) base is used, and the result must keep the base’s scheme, so a base never turns a relative link into a file:, javascript: or other address. An address with control characters or whitespace other than a plain space is left as written, since the URL rules would drop them and read what is left (java\nscript:) differently. Either way the address still goes through the same check and confirmation as any other link.
