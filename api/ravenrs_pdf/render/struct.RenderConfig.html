Expand description

Per-document rendering configuration.

Fields§

§password: Option<Arc<str>>

User or owner password for encrypted documents.

§layers: Arc<Vec<(i32, i32, bool)>>

Layer (optional content group) visibility overrides: (object number, generation, visible).

§hide_comments: bool

View ▸ Hide all comments: markup annotations aren’t drawn (fields and links still are).

§annotations: Arc<Vec<(i32, i32, bool)>>

Annotations shown or hidden for viewing in place of their Hidden and NoView flags (object number, generation, shown): fields a document’s page actions and timers showed or hid (an animation’s frames). Display only; the document never changes.

§appearances: Arc<Vec<(i32, i32, i32, i32)>>

Annotations drawn with a form XObject as their normal appearance (object number and generation of the annotation, then of the form): push buttons a document’s page actions and timers gave another icon (buttonSetIcon, an animation’s frames). Display only; the document never changes.

§reject_oversize: bool

Refuse a whole-page raster that would be reduced by the renderer’s hard size caps. Tiled requests remain available for pages that exceed those caps. Both modes refuse a raster whose rounded integer dimensions exceed the final pixel-allocation budget.

§reading_colors: ReadingColors

View ▸ Reading colours: solid text and line-art paints are remapped for readability and the page clears to the setting’s background. Display only; the document never changes.

§transparent: bool

The page clears to transparent instead of white (or the reading background): for a page holding only what is laid over another raster, such as a comment while it is dragged.

§system_fonts: bool

Draw a CID font of an Adobe CJK collection that the PDF does not embed with one face already installed on this machine (see system_font). Off by default and on only for on-screen viewer and preview rasters: exports, printing and OCR render without it, so nothing drawn with an installed font is saved or printed (AGENTS.md §1.2, §1.4).

§for_print: bool

The render is output for printing (print as image): the configuration’s auto state for the View event (ISO 32000-2 §8.11.4.4) is not applied, since printing is not viewing.

§jbig2_work: Option<u64>

Steps of JBIG2 decoding a render may take across the page’s images, instead of the usual crate::third_party::hayro_syntax::MAX_PAGE_JBIG2_WORK. Those past it aren’t drawn, like an image that can’t be decoded.

§print_layers: Option<Arc<Vec<(i32, i32, bool)>>>

Layer visibility overrides for print-preview rasters (PRINT_TAG), when the document prints its layers differently from how they are shown (the Print event’s auto state, ISO 32000-2 §8.11.4.4): the preview shows the page as it prints. None: previews use layers.

This configuration for a raster that is only shown on screen (the viewer, Combine thumbnails, figure previews): installed CJK faces may draw fonts the PDF doesn’t embed. Never use it for anything that can be saved, printed, recognised or returned to an agent (AGENTS.md §1.2, §1.4).
