Expand description

A page transition as it is played: the style with the entries that style reads. Directions are degrees as /Di gives them: 0 left to right, 90 bottom to top, 180 right to left, 270 top to bottom, 315 top-left to bottom-right (Glitter; Wipe treats it the same way).

Dissolve

Random squares of the new page appear until it is whole.

Like Dissolve, but the squares appear in a band that sweeps in direction.

Replace

No effect: the new page replaces the old one.

§

Fly

The new page flies in from off-screen in direction (or from the centre, None), growing from scale; outward flies the old page off instead. With opaque the moving page hides what is under it (it always does here: the pieces overlap in paint order).

pub fn from_parts( style: &str, horizontal: bool, inward: bool, direction: Option<u16>, scale: f32, ) -> Self

The effect for a /Trans dictionary read as its parts: the /S name, /Dm as horizontal, /M as inward, /Di as direction (None for /None), /SS and /B. An unknown style is Replace, as the spec’s default; an entry a style does not read is ignored.
