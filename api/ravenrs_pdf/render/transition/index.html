ravenrs_pdf::render

Module transition 

Source
Expand description

The geometry of a page transition (ISO 32000-2 §12.4.4, table 164) part-way through its run: which parts of the outgoing and the incoming page a presentation paints, where, and how opaque. Pure functions in page fractions (0 to 1 across and down the page box on screen), so the painter only scales them; nothing here touches pixels or time.

Effect is the transition as a presentation plays it (the /Trans entries that matter for each style, with the spec’s defaults), frame the picture at progress t. Every frame starts with the outgoing page alone (t = 0) and ends with the incoming page alone (t = 1); the pieces of a frame never leave the page box.

Structs§

Frame
One moment of a transition: the pieces of the outgoing page, then of the incoming page, in paint order (later pieces over earlier ones).
Piece
A part of a page to paint: src is the part of that page, dst where it goes, both as fractions [x0, y0, x1, y1] of the page box (y down), alpha its opacity.

Enums§

Effect
A page transition as it is played: the style with the entries that style reads. Directions are degrees as /Di gives them: 0 left to right, 90 bottom to top, 180 right to left, 270 top to bottom, 315 top-left to bottom-right (Glitter; Wipe treats it the same way).

Functions§

frame
The picture of effect at progress t (0: the outgoing page alone; 1: the incoming page alone; anything else clamped). Pieces are in paint order and never leave the page box.
