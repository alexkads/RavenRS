Fields§

§page: usize§subtype: String§author: Option<String>§contents: Option<String>§modified: Option<String>§name: Option<String>

/NM of this annotation, and of the one it replies to (/IRT).

§in_reply_to: Option<String>§parent: Option<(usize, usize)>

The page and /Annots position of the comment /IRT points at, found by object reference. Threads follow this rather than /NM, which need not be unique: PyMuPDF names the first comment on every page fitz-A0. None when /IRT leads to no listed comment (link_replies).

§grouped: bool

/RT /Group (ISO 32000-2 §12.5.6.2, Table 172): with a parent, a subordinate of the group whose primary /IRT points at, not a reply (Self::is_group_member). Its own text, author, colour and dates are ignored; see group_primaries.

§rect: [f32; 4]

Rect in PDF user space: [x0, y0, x1, y1].

§color: Option<[f32; 3]>§index: usize

Position in the page’s /Annots (how edits address the comment).

§state: Option<String>

For a status reply (/State, Acrobat’s “Set status”): the state it sets.

§quads: Vec<[f32; 8]>

Text markup quadrilaterals (/QuadPoints), 8 numbers each.

§locked: bool

The Locked flag (/F bit 8): the comment can’t be moved, resized, restyled or deleted.

§intent: Option<String>

/IT, the intent: FreeTextCallout, PolygonCloud, FreeTextTypeWriter…

§fill_sign: bool

A Fill & Sign mark: typed text, a check, cross, dot or line, or a typed, drawn or picture signature or initials (the rules of pdfcraft_annot::is_fill_sign).

§no_rotate: bool

The NoRotate flag (/F bit 5), set on sticky notes and attachments: on a turned page the appearance stays upright, turned about the upper-left corner of rect (Self::shown_rect).

§points: Vec<[f32; 2]>

The points that shape a line (its two ends, /L), connected lines, a polygon or a cloud (their corners, /Vertices), or a callout (its arrow point and knee: /CL without its end, which follows the text box), in user space; empty for other comments.

§text_box: Option<[f32; 4]>

A callout’s text box (/Rect inset by /RD), in user space; None for other comments.

§popup: Option<Popup>

The comment’s pop-up window (/Popup): where it sits and whether it is open.

impl Annotation

Source

pub fn is_mark(&self) -> bool

A checkmark reply (/StateModel /Marked): “Marked” or “Unmarked” rather than a review status.

Source

pub fn is_reply(&self) -> bool

A reply (or status reply) to another comment rather than a comment of its own.

Source

pub fn is_comment(&self) -> bool

A comment of its own: not a reply, and not a status or checkmark. One whose comment can’t be found (deleted from another page, or never listed) has nothing to show, so it is listed nowhere: not as a card, on the page or in a count.

Source

pub fn is_group_member(&self) -> bool

A subordinate of a group (/RT /Group with an /IRT that leads to a listed comment, ISO 32000-2 §12.5.6.2): part of its primary’s comment (group_primaries), neither a comment of its own nor one of its replies. Expects links link_replies settled.

Source

pub fn replies_to(&self, other: &Annotation) -> bool

Whether this annotation’s /IRT points at other.

Source

pub fn shown_rect(&self, rotation: u16) -> [f32; 4]

Where the comment is drawn on a page turned by rotation (PageInfo::rotation), in user space: rect, or for a NoRotate comment rect turned upright about its upper-left corner (see Self::no_rotate). Hit-testing, selection and anything placed beside the comment use this, so they match the drawing.

Source

pub fn shown(&self, rect: [f64; 4], rotation: u16) -> [f64; 4]

Self::shown_rect for this comment with its /Rect at rect (one being moved or resized).

Source

pub fn rect_for_shown(&self, shown: [f64; 4], rotation: u16) -> [f64; 4]

The /Rect that shows this comment in the user-space box shown: the inverse of Self::shown, for a box resized as drawn.
