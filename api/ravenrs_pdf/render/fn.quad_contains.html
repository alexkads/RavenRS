pub fn quad_contains(q: &[f32; 8], x: f32, y: f32) -> bool
Expand description

Whether the point (x, y) lies in the quadrilateral q (x1 y1 … x4 y4), edges included. Writers disagree on the corners’ order (the specification says counterclockwise, text-markup writers often go top-left, top-right, bottom-left, bottom-right), so the quadrilateral is taken as the area its four corners enclose: the union of the four triangles they make.
