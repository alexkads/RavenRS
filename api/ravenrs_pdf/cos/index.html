pdfcraft-cos — the PDF object layer (L1, standalone with pdfcraft-filters).

Parses the COS object graph lazily and tolerantly, keeps edits in a copy-on-write overlay (cheap snapshots for undo), and writes documents back either incrementally (original bytes untouched) or as a full, garbage-collected rewrite. The PDF object graph is PdfCraft’s document model (plan/architecture.md §5, ADR-0010).

Done: every cross-reference form (tables, streams, hybrid /XRefStm), object streams, repair by scanning, encryption on load and save (R2–R6, crypt filters, /EFF), incremental writing, and full saves that pack objects into compressed object streams with a cross-reference stream. Not yet: streaming very large files within a memory budget (ByteSource, core.lazy-loading), and linearized output (core.linearization, M11). See the README.

DECODE_PARMS_KEYS
The /DecodeParms entries the decoders read (ISO 32000-2 Tables 8, 11 and 13: the Flate and LZW predictors, CCITT, DCT’s colour transform): numbers and flags a file may give by reference, which Dict::int doesn’t follow.
MAX_DECODED
Upper bound for a single decoded stream (decompression-bomb defence).
MAX_JBIG2_GLOBALS
The most an image’s /JBIG2Globals stream may decode to: the symbol and pattern dictionaries an encoder shares between pages, themselves coded, so far less than any stream may decode to (MAX_DECODED). They are decoded before the image’s JBIG2 page is read, so the page’s size can’t bound them: they have a limit of their own.
MAX_PAGE_DECODED
Decoded bytes one page’s content walk may produce in all: its /Contents streams and every form XObject it enters, each occurrence counted again.
MAX_PAGE_FORMS
Form XObjects one page’s content walk may enter, each entry counted again.
MAX_REDACTED_IMAGE_PIXELS
The most pixels an image redaction decodes, to clear the ones under a mark or to store again without the /JBIG2Globals it shares with a redacted image (pdfcraft_redact). Optimize has JBIG2 images share a dictionary only within it (pdfcraft_optimize), so that redaction can store each of them again: one it couldn’t would refuse the redaction.
