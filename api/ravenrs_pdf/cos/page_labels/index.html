Bounded numbering for page labels (ISO 32000-2 §12.4.2). Pure helpers shared by inspection and editing; no object graph or renderer dependency.

Constants§

MAX_LABEL_BYTES
A complete custom label, including its prefix, may contain this many UTF-8 bytes.
MAX_LABEL_TOTAL_BYTES
Sum of the UTF-8 bytes of custom labels for one document.
MAX_LABEL_TREE_DEPTH
Maximum nesting of a label number tree.
MAX_LABEL_TREE_WORK
The most number-tree entries (nodes, kids and range pairs) read from one /PageLabels tree. Scaled for real documents: one range per page on a ten-thousand-page PDF happens (prefix labels; #307’s file has 9,156 pages), so the cap is twenty times that while still bounding hostile trees.
MAX_PREFIX_BYTES
Raw prefixes are bounded before decoding; this admits a full UTF-16BE ASCII label.
MAX_PREFIX_TOTAL_BYTES
Sum of the UTF-8 bytes of the decoded prefixes of one /PageLabels tree. Each range decodes its own prefix, and ranges may share one prefix object, so without this a small file could ask for a copy per range: MAX_LABEL_TREE_WORK ranges naming one 1,024-byte prefix would hold about 200 MiB. Real documents stay far below it.

Functions§

alpha
a..z, aa..zz, aaa.. (the repeated-letter numbering specified by PDF). Returns None instead of truncating a label that exceeds the remaining byte budget.
roman
Lowercase Roman numerals, or None if the output exceeds the remaining label budget. The budget is capped at MAX_LABEL_BYTES, including when n is hostile.
