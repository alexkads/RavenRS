The apps a scenario opens apart, in a child process with no window, over the test channel.

Shared by Raven Test Studio and cargo ravenrs e2e. The runner keeps no list of apps of its own. An app declares itself in its Cargo.toml, in [package.metadata.ravenrs.e2e]: the name its scenarios open (app), the binary, the first version that speaks the channel (since), a variable that points at another copy, and where its installer puts it. The Studio learns an app from that declaration when a project is opened with --project (crate::project), and knows Raven Finanças by the declaration in its own Cargo.toml, read when the Studio is built, so the installed Studio can open the installed app with no checkout.

An app is found the way a person has it: a path in its variable; for an app of the project the Studio was pointed at, its code built with Cargo in that project; then the copy the installer put on this computer; then, inside the RavenRS checkout, its code. An installed copy from before the test channel is never opened with --e2e-serve: it would read the option as the path of a database and open its window.
