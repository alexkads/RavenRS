Module report 

Source
Expand description

What a run tells whoever asked for it: a person in a terminal, a build server, or the coding agent that called the tool.

The text is a few lines an agent can quote as is. The JSON carries every block with its result, the stable code of a failure and the screen of the app at that moment, so the agent can explain or fix the failure without running it again.

Constants§

FORMATS
The formats a report prints in, as --format names them.
NOT_VERIFIED
What a run of an app compiled into the tool could not check, said in its report.
NOT_VERIFIED_APART
What a run of an app opened apart could not check, said in its report.
NOT_VERIFIED_HEADED
What a run with the app’s real window on screen could not check, said in its report; the systems it did not run on come from crate::window::other_systems.

Functions§

deliver
Keeps each report in out, when given, and gives them all in format (one of FORMATS; anything else is text). The JSON is a list when list, else the one report. Where they were kept goes to stderr, so the JSON, JSON lines or XML on stdout stays only that.
folder_name
A scenario’s name as one folder: letters, digits, - and _ stay, a run of anything else becomes one -, so a / or .. in a name never leaves the folder given.
render
reports in format, as deliver prints them.
schema
The JSON Schema (2020-12) of Report::json, for a tool or an AI that reads it.
