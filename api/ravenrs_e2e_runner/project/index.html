ravenrs_e2e_runner

Module project 

Source
Expand description

A Rust project the Studio is pointed at: which of its packages are made with RavenRS, which of them are apps, whether each speaks the test channel, which scenarios it keeps, and which screens it builds, so a person knows what can be tested there without knowing the project.

The project is read, never built: cargo metadata --no-deps says the packages, and their sources are searched for the views they build (impl View for, impl Component for, functions that return impl View) and the test ids they declare (.test_id("…")).
