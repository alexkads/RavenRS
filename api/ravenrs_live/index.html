Crate ravenrs_live 

Source
Expand description

An interpreter of the Rust that small RavenRS examples are written in, so they run in a playground without a compiler: let and let .. else, closures, calls and chains of builders, tuples, vec!, ranges and iterators, format!, if, match, Option, Result and ?, State and Binding::map, and the program’s own functions, constants, structs and impl blocks. The host program’s types are reached through a Registry, which #[ravenrs_live::expose] fills from the host’s own impl blocks, structs, enums and modules.

What it does not read is an error with its line and column, never a guess.

Attribute Macros§

expose
Registers the public functions and constants of an inherent impl block, the public fields of a struct, the variants of an enum or the public functions of an inline module, behind the live feature of the crate it is used in. It generates __live_expose (or __live_expose_<part> with part = "...") on the type, or inside the module, which the crate calls when it builds its registry. skip = "a, b" leaves functions out.
