Layout for RavenRS, built on Taffy.

Widgets describe boxes with LayoutStyle (a deliberately small subset of flexbox: stacks, gaps, padding, alignment, sizes and growth). Leaves that size themselves, such as text, carry a context C and are measured through a callback, so this crate does not depend on the text engine.
