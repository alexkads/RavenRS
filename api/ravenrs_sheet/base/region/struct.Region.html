The currency format with the currency’s usual decimals (two, or none for the yen and the won), as a canonical code. Where it starts with a quote the symbol comes before the number, otherwise after.

The same with no decimals (for a typed whole amount).

pub fn is_group(&self, c: char) -> bool

True for the characters that separate groups of digits in this region. A region that groups with a space also accepts the other space-like characters (NBSP, narrow NBSP, thin space), as people type and paste any of them; one that groups with an apostrophe accepts both ' and ’.

Source

pub fn currency_first(&self) -> bool

True when the currency symbol comes before the number.

Source

pub fn month_from_name(&self, word: &str) -> Option<u32>

Month number (1–12) for a month name as typed: the full name, the abbreviation (with or without its period) or any prefix of the full name of three or more letters (Sept), ignoring case. word is one word: the genitive form used after a day (января in 1 января) matches too, and the caller reads the day itself.

Source

pub fn month_name(&self, month: u32, with_day: bool) -> &'static str

The name of month month (1–12) for mmmm; with_day selects the genitive form where the region has one.

Source

pub fn is_12_hour(&self) -> bool

True when the short time uses a 12-hour clock.
