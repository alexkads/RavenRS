Module date 

Source
Expand description

Date serial numbers.

The 1900 system counts days from 1899-12-31 (serial 1 = 1900-01-01) and, like Lotus 1-2-3 and Excel, treats 1900 as a leap year: serial 60 is the fictitious 1900-02-29. The 1904 system counts from 1904-01-01 (serial 0). Times are fractions of a day.
