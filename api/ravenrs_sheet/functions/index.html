GridCraft worksheet function library.

Every function is described by a FnSpec (name, arity, category, which parameters take scalars, a signature and a one-line description) and implemented as a plain Rust function over already-evaluated arguments. The calculation engine looks functions up by name with lookup and invokes them through call, which applies Excel’s automatic array lifting: passing an array where a scalar is expected evaluates the function once per element.

Special forms that need references, laziness or hidden-row information (ROW, OFFSET, INDIRECT, LET, LAMBDA, SUBTOTAL, AGGREGATE, TEXT…) are evaluated by the host; this crate exports aggregate_values for SUBTOTAL/AGGREGATE.
