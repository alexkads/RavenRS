Reference adjustment: copying formulas, inserting/deleting rows and columns, moving cells, renaming and deleting sheets.

Functions§

adjust
Adjusts a formula living on sheet host after edit on sheet target.
delete_sheet
References to a deleted sheet become #REF!. order lists the sheet names (before the deletion) in tab order: a 3-D span that loses an end sheet shrinks to the neighbouring surviving sheet, as in Excel.
has_relative_refs
Whether the formula has a relative (no $) row or column anywhere.
rename_sheet
Renames sheet references old → new.
shift_relative
Copy/fill: relative parts move by (dr, dc). References pushed off the sheet become #REF!.
shift_relative_wrapping
Defined names: relative parts move by (dr, dc), wrapping around the sheet’s edges. Files store a name’s relative references as seen from A1 (a name for “the cell to the left” defined in B1 is Sheet1!XFD1), and a use in another cell moves them by that cell’s offset from A1.
