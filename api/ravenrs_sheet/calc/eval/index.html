The formula evaluator.

Expressions evaluate to Ev: a value, a reference (one or more areas, kept unresolved so ROW, OFFSET, INDEX, : and friends can work on references) or a lambda. Cell reads go through Host, which lets the recalculation engine evaluate dirty precedents on demand.
