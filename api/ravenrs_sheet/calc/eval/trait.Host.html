fn used_range(&mut self, sheet: usize) -> Option<RangeRef>

The sheet’s used range (Sheet::used_range, which walks every stored row). Hosts that keep the workbook unchanged while evaluating can remember it.

Source

fn visit_range( &mut self, _sheet: usize, _range: RangeRef, _f: &mut dyn FnMut(&Value) -> bool, ) -> bool

Calls f on each stored value of a block, row-major (formula cells evaluated first), until f returns false. false when this host can’t (callers use range_values).

Source

fn stack_top(&self) -> Option<usize>

While a formula is calculated on demand inside another one: stack_position() where the outermost one started, which the stack budget is counted from.
