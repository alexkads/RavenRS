Struct DisplayedPrecision 

Source 
pub struct DisplayedPrecision { /* private fields */ }
Expand description

Rounds values to their cell’s displayed precision, remembering each style’s parsed format. Styles don’t change while it is used (one recalculation pass, one sweep of a workbook).
