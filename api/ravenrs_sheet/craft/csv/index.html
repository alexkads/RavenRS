Delimited text (CSV, TSV and their relatives) and SYLK.

  • decode_text turns a file’s bytes into a string: byte order marks, UTF-8, else Windows-1256 when the bytes read as Arabic and Windows-1252 otherwise.
  • sniff_delimiter picks comma, semicolon or tab.
  • parse_records splits text into records of fields (RFC 4180 with the usual leniency), handing each record to a callback, with a cap on the fields kept per record. records collects them.
  • push_field and field_len write one field, quoted when it has to be.
  • sylk reads SYLK (.slk) files.

Fields are text. Reading a field as a number or a date, and deciding how a value is written, belong to the caller.

let text = ravenrs_sheet::craft::csv::decode_text(b"name;note\r\nAda;\"said \"\"hi\"\"\"\r\n");
let delimiter = char::from(ravenrs_sheet::craft::csv::sniff_delimiter(&text, '"'));
let rows = ravenrs_sheet::craft::csv::records(&text, delimiter, '"', 1000, 1000);
assert_eq!(rows, [["name", "note"], ["Ada", "said \"hi\""]]);

let mut line = String::new();
ravenrs_sheet::craft::csv::push_field(&mut line, "a;b", ';');
assert_eq!(line, "\"a;b\"");

Functions§

decode_text
Decodes the bytes of a text file with BOM-aware UTF-8 and UTF-16 handling. Without a BOM, valid UTF-8 is kept. Other bytes decode as Windows-1256 when they read as Arabic (see [Cp1256Evidence]), else as Windows-1252.
field_len
The bytes push_field appends for field, so a writer can enforce a size cap before it writes (no quoted copy of the text is built).
parse_records
Splits delimited text into records of fields and hands each to on_record, which returns whether to go on. A record ends at CR, LF or CRLF; a blank line is a record with one empty field. A field that starts with quote runs to the closing quote (a doubled quote is one quote character, and line ends inside are text); a quote elsewhere in a field is text, and an unterminated quoted field runs to the end of the text.
push_field
Appends one field to out: as it is, or in double quotes with its quotes doubled when it holds the delimiter, a quote or a line break. Delimiters between fields and the line end (CRLF in RFC 4180) are the caller’s.
records
The first max_records records of parse_records, each with at most max_fields fields.
sniff_delimiter
Picks comma, semicolon or tab: the candidate with the most consistent count per line (outside quotes) over the first non-blank lines. A candidate must appear on every such line, otherwise comma wins.
