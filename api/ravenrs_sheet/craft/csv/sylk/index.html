Module sylk 

Source
Expand description

SYLK (.slk): the symbolic link text format older spreadsheets and some legacy systems export. One record per line, fields separated by ; (;; is a literal semicolon):

  • ID starts the file; E ends it.
  • C;Y<row>;X<col>;K<value>;E<formula> is a cell. Y and X may be left out to stay on the current row or column. K is a number, "text", TRUE/FALSE or an error; E is a formula in R1C1 notation; S;R<row>;C<col> shares the formula of another cell.
  • P;P<code> adds a number format to the file’s list; F;P<n>;Y<row>;X<col> gives a cell the n-th format (0-based), and F;W<first> <last> <width> sets column widths in characters.

Other records (fonts, options, window settings) are skipped. Formulas are converted to A1 with the same relative and absolute references, as Excel does when it opens the file.

Functions§

r1c1_formula_to_a1
Rewrites the R1C1 references in a SYLK formula as A1 references for the cell at at (zero-based row and column): RC[-1] → B2, R1C1 → $A$1, R[-2]C:R[-1]C → D2:D3, a whole column C4 → $D:$D and a whole row R3 → $3:$3. Text in quotes and quoted sheet names are left alone; a reference off the sheet becomes #REF!.
