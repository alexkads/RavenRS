pub fn check_entry_count(bytes: &[u8], max_entries: u64) -> Result<(), Error>
Expand description

Refuse bytes when the end record zip would use declares more than max_entries entries.

zip searches the file backwards for an end of central directory record. A ZIP64 one points through its locator at the ZIP64 end record, which zip looks for from the locator’s offset on: every such record there is checked, and as zip may fall back to an earlier end record when one doesn’t parse, the search goes on. A plain one is used when it declares no entries, or a central directory header lies between its directory offset and itself: it is the last one looked at.
