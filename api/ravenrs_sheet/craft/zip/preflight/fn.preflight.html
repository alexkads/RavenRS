pub fn preflight(bytes: &[u8], limits: Limits) -> Result<Directory, Error>
Expand description

Validate the end records and walk the declared central directory without allocating.

Checks, in order:

  • the end-of-central-directory record: exactly one candidate must span the end of the file, so an archive that hides a second plausible record is refused rather than guessed at;
  • the ZIP64 pair when the classic record uses a sentinel or a locator is present: a single disk, a locator immediately before the end record, the ZIP64 record ending at that locator, and no disagreement between the classic and ZIP64 fields;
  • the declared entry count, directory size and entry-name lengths against limits;
  • the directory arithmetic: its offset and size must not overflow and must reach the end records, so a lying offset or size cannot point the reader elsewhere;
  • every entry header in the directory: its signature, its disk number, its variable-length fields, and that the entries exactly fill the declared directory, allowing one optional central-directory digital signature at its end.

Returns the declared entry count and directory size. Malformed input is an error, never a panic.
