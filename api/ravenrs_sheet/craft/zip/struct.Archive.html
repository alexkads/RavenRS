Struct Archive 

Source 
pub struct Archive<'a> { /* private fields */ }
Expand description

A ZIP archive in memory. Nothing is decompressed until an entry is read.

A clone shares the parsed directory and the bytes, and carries a copy of the budget: a caller that reads through a clone keeps its own count.

pub fn read_head( &mut self, name: &str, n: usize, ) -> Result<Option<Vec<u8>>, Error>

The first n bytes of entry name (all of it when it is shorter), or None when there is no such entry: for telling a file by its signature without inflating it. The bytes are charged to the total; a total with less left than the bytes wanted refuses before reading.

The entry’s checksum is not checked: it covers the whole entry.

Source

pub fn read(&mut self, name: &str, max: u64) -> Result<Option<Vec<u8>>, Error>

The bytes of entry name, or None when there is no such entry.

The entry may declare, and expand to, at most max bytes, and at most what is left of Limits::max_total_bytes. An entry that expands past the size it declares is refused. Only the bytes of a read that succeeds are charged to the total.

The total budget, for a caller with its own charging rule (charging a failed read, say).
