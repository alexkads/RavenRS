The crates of craft-libs that GridCraft’s file formats use, as modules (see NOTICE).

Modules§

cfb
Clean-room Compound File Binary format reader and writer (“OLE structured storage”: the container of legacy Office files, Outlook .msg messages, encrypted OOXML packages and AAF), written from the public Microsoft Open Specification [MS-CFB]: Compound File Binary File Format (protocol revision 10.0 and earlier editions; the on-disk format has not changed since 1.0).
csv
Delimited text (CSV, TSV and their relatives) and SYLK.
offcrypto
Clean-room Office document cryptography, written from Microsoft’s public Open Specification [MS-OFFCRYPTO]: Office Document Cryptography Structure and ECMA-376.
opc
Open Packaging Conventions (ECMA-376 Part 2): the ZIP container that DOCX, XLSX and PPTX files share.
sheet
Spreadsheet vocabulary shared by the spreadsheet format crates (craft-xls, craft-xlsx, craft-ods): cell positions and their A1 text, cell values and error values, sheet-name quoting, the cell formatting enumerations, Excel’s built-in number formats and its indexed colour palette.
xls
Clean-room reader for Excel 97-2003 workbooks (.xls, BIFF8), written from Microsoft’s public specifications [MS-XLS]: Excel Binary File Format (.xls) Structure (the Workbook stream) and [MS-CFB] (the compound file around it, read by craft-cfb).
xml
Bounded XML for hostile input.
zip
ZIP archives from untrusted files, read within limits and written.
