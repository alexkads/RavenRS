Struct LazyPackage 

Source 
pub struct LazyPackage<'a> { /* private fields */ }
Expand description

A package whose parts are inflated when they are asked for, against a running total: for a reader that needs a few parts of a large file, or one part at a time.

pub fn read_optional_limited( &mut self, part: &str, maximum: u64, ) -> Result<Option<Vec<u8>>, Error>

A part the reader can do without (the caller warns and goes on when it fails). A read that fails part-way is charged this part’s whole allowance (maximum, and the byte that detects an overrun) instead of ending the package’s: the decompression work stays bounded, and the parts read after it still open.

Source

pub fn read_limited( &mut self, part: &str, maximum: u64, ) -> Result<Option<Vec<u8>>, Error>

A part’s bytes, up to maximum (and Limits::max_part): for a small metadata part that must not expand to the general limit.

A read that fails or overruns spends the whole of Limits::max_total: it has already cost decompression work the total never saw, and a loop over many broken parts must not pay it again and again. Every later read is then a cheap error.
