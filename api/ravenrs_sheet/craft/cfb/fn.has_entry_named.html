pub fn has_entry_named(bytes: &[u8], name: &str, limits: &Limits) -> bool
Expand description

Whether the compound file bytes holds a directory entry called name (compared as sibling names are, so case-insensitively), at any depth. false when bytes does not start with the compound file signature.

When the directory cannot be followed (a truncated or damaged file), falls back to searching the bytes for the name in UTF-16LE, so a damaged file still answers. That fallback is case-sensitive and can match stream contents: use it to choose an error message, not to make a security decision.
