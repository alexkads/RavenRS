Module cfb 

Source
Expand description

Clean-room Compound File Binary format reader and writer (“OLE structured storage”: the container of legacy Office files, Outlook .msg messages, encrypted OOXML packages and AAF), written from the public Microsoft Open Specification [MS-CFB]: Compound File Binary File Format (protocol revision 10.0 and earlier editions; the on-disk format has not changed since 1.0).

A compound file is a small FAT file system inside one file: fixed-size sectors (512 bytes in version 3, 4096 bytes in version 4) chained by a file allocation table, a directory of 128-byte entries arranged as one red-black tree of siblings per storage, and a “mini stream” with a mini FAT for streams smaller than 4096 bytes.

  • CompoundFile::open parses a file held in memory (no copies of large streams; every chain is bounds- and cycle-checked, so damaged files give errors, never panics or endless loops). Limits caps the stream size and the number of directory entries.
  • Writer builds a tree of storages and streams and lays it out in one pass (Writer::finish): stream sectors, mini stream, mini FAT, directory, FAT and DIFAT. write_streams is the one-call form for a list of (path, bytes).
  • directory_names and has_entry_named answer “does this file hold an entry called X” for files too damaged to open.

No dependencies beyond std, no unsafe, nothing platform-specific.
