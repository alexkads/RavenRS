Expand description

A parsed compound file over borrowed bytes.

Fields§

§version: u16

Major version: 3 (512-byte sectors) or 4 (4096-byte sectors).

§header_clsid: [u8; 16]

Header CLSID (normally zero).

§entries: Vec<Entry>

The directory entries. Read-only after open (see Entry::children): the by-name index behind CompoundFile::child is built once when the file is parsed.

The /-separated path of entry id below the root ("" for the root itself), or None for an id that does not exist or an entry the root does not reach. Names are joined as they are: a damaged file may hold a name with a / in it, which find will not resolve.
