ravenrs_sheet::craft

Module xls 

Source
Expand description

Clean-room reader for Excel 97-2003 workbooks (.xls, BIFF8), written from Microsoft’s public specifications [MS-XLS]: Excel Binary File Format (.xls) Structure (the Workbook stream) and [MS-CFB] (the compound file around it, read by craft-cfb).

read gives a Workbook: the worksheets with their cells (values, cached formula results, and formulas as A1 text, including shared and array formulas), the cell formats (number formats, fonts, fills, borders, alignment, protection, with palette colours resolved), user-defined cell styles, merged cells, column and row records, sheet display flags, calculation settings, defined names, print areas and print titles, data validation rules, cell comments, conditional formats (“cell value is” and “formula is”), pictures with their cell anchors, the AutoFilter range, and the 1904 date flag. Widths, heights and anchors stay in the file’s units.

Everything else (charts, other shapes, newer conditional formats, hyperlinks, PivotTables, macros) is skipped and named in Read::warnings. A workbook encrypted with RC4 or RC4 CryptoAPI is read with its password (read_with_password; without one, Excel’s default password is tried and Error::Encrypted says one is needed). Other encryption and versions before BIFF8 are refused (Error::UnsupportedEncryption, Error::Biff5). A formula that cannot be put back into text (links to other workbooks, macro commands, unknown tokens) leaves its cell with the saved result and a Warning::FormulaKept.

Input is hostile: Limits caps records, cells and text, the remaining counts have fixed caps, formula nesting is bounded, and nothing indexes by a number from the file.

let read = ravenrs_sheet::craft::xls::read(&bytes)?;
let sheet = &read.workbook.sheets[0];
assert_eq!(sheet.name, "Sheet1");
assert_eq!(sheet.cells[&ravenrs_sheet::craft::xls::CellRef::new(0, 1)].value, ravenrs_sheet::craft::xls::Value::Number(2.5));
