Expand description

An element: its name, its attributes in document order and its children in document order.

What name and the attribute names hold depends on crate::craft::xml::Names: the qualified name as written (p:sp), the local name (sp), or a canonical prefix and the local name (w:p).

A tree the reader built is never deeper than crate::craft::xml::Limits::max_depth. A tree built by hand is as deep as its builder made it; the methods here do not recurse, but dropping a tree does, once per level.

pub fn to_xml(&self) -> String

Source

pub fn write_xml(&self, out: &mut String)

Appends the element as XML. Text is escaped with esc and attribute values with esc_attr; an element without children is written <a/>. An element or attribute whose name is not an XML name (is_name) is left out with everything inside it, so a name can never inject markup. Reading the result back gives an equal tree, apart from such names and characters XML cannot carry.

Source

pub fn to_xml_pretty(&self, indent: &str) -> String

The element as indented XML, ending with a newline. See El::write_xml_pretty.

Source

pub fn write_xml_pretty(&self, out: &mut String, indent: &str)

Appends the element as indented XML: an element whose children are all elements has them one per line, indent deeper each level, and any other element is written on one line exactly as El::write_xml writes it. Character data is therefore never changed, but whitespace-only text between the children of an element-only element is not kept.
