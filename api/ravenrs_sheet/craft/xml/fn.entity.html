pub fn entity(name: &str) -> Option<char>
Expand description

The character a reference names, without its & and ;: one of the five predefined entities (amp, lt, gt, quot, apos) or a numeric character reference (#65, #x41, zero-padded or not). None for anything else, for a number that is not a character XML can carry, and for a number with a sign.
