ravenrs_sheet::craft

Module xml 

Source
Expand description

Bounded XML for hostile input.

  • parse and Options::parse read bytes into an owned tree of El and Node, with limits on input size, nesting, node count and attributes per element (Limits).
  • Options::parse_streaming hands repeated elements to a callback, so a large part never becomes a whole tree. Options::events is the pull reader underneath.
  • Names chooses how names are read: as written, by local name, or rewritten to the caller’s canonical prefixes by namespace URI.
  • esc, esc_attr, El::to_xml, El::to_xml_pretty and Writer write XML.

No document type definition is processed, and no entity is expanded except the five predefined ones (&amp; &lt; &gt; &quot; &apos;) and numeric character references. The text the reader produces is therefore never more than three times its input.

let root = ravenrs_sheet::craft::xml::parse(b"<a x='1'><b>one &amp; two</b><b/></a>")?;
assert_eq!(root.attr_u32("x"), Some(1));
assert_eq!(root.child("b").map(|b| b.text().into_owned()).as_deref(), Some("one & two"));
assert_eq!(root.to_xml(), r#"<a x="1"><b>one &amp; two</b><b/></a>"#);

entity
The character a reference names, without its & and ;: one of the five predefined entities (amp, lt, gt, quot, apos) or a numeric character reference (#65, #x41, zero-padded or not). None for anything else, for a number that is not a character XML can carry, and for a number with a sign.
esc

esc_attr

to_utf8
The input as UTF-8 text for the reader: a UTF-8 byte-order mark is removed, and UTF-16 (with a byte-order mark, or recognisable without one by the zero bytes of its first two characters) is transcoded. An unpaired surrogate becomes U+FFFD and a trailing odd byte is dropped. The result is at most 1.5 times the input. Any other input is returned as it is; the encoding an XML declaration names is not consulted.
