Expand description

How to read a document. Options::default() keeps names as written and is lenient.

Fields§

§limits: Limits§names: Names<'a>§ns_decls: bool

Keep namespace declarations (xmlns, xmlns:p) as attributes, as written. On by default; Options::local and Options::canonical turn it off.

§strict: bool

Refuse what a lenient read repairs. Lenient: an end tag closes the innermost open element whatever its name, an end tag with nothing open is skipped, elements still open at the end of the input are closed, reading stops when the root element ends, a malformed attribute is skipped, and bytes that are not UTF-8 become U+FFFD. Strict: each of those is an error, as are a second root element and text outside the root.

§unknown_entity: UnknownEntity§doctype: Doctype§cdata: bool

Keep CDATA sections as Node::CData instead of joining them to the text around them.

§pis: bool

Keep processing instructions inside the root element as Node::Pi.

§comments: bool

Keep comments inside the root element as Node::Comment.

§drop_blank_text: bool

Drop the text of an element that has child elements when all of it is whitespace: the indentation of an indented document.

§split_depth: usize

For Options::parse_streaming: how far below the root an element may be and still be handed out. 2 by default: children and grandchildren of the root.

pub fn parse_streaming<E: From<Error>>( &self, bytes: &[u8], split: &[&str], each: impl FnMut(El) -> Result<(), E>, ) -> Result<El, E>

Reads a document, handing each complete element whose name is in split to each instead of keeping it in the tree: worksheet rows, shared strings. Only elements at most Options::split_depth levels below the root are handed out; a deeper element of the same name stays in the tree. split names are matched against names as this reader produces them. Elements handed out do not count toward Limits::max_nodes once they are gone, so a part of any length can be read; each one is itself held to the limit.

An error from each stops the read and is returned.

Source

pub fn parse_streaming_partial<E: From<Error>>( &self, bytes: &[u8], split: &[&str], each: impl FnMut(El) -> Result<(), E>, ) -> (Option<El>, Option<E>)

Options::parse_streaming that also returns what it had read when it failed: the root with the children that were complete (and not handed out) before the error, and the elements still open at that point with what they held. A worksheet whose rows cannot all be read still gives its properties and merged cells. (None, Some(_)) when nothing was read; (Some(_), None) is a whole document.

The partial tree is not a document: it stops where the error was, and an open element named in split is attached to it instead of being handed to each.

Source

pub fn first_start(&self, bytes: &[u8], pat: impl Pat) -> Option<El>

The first element that matches, from its start tag alone: its name and attributes, no children. Nothing after the tag is read, so unbalanced markup around it neither hides nor moves it. None when there is none or the markup before it cannot be read.

Source

pub fn events<'i>(&self, utf8: &'i [u8]) -> Events<'a, 'i>

A pull reader over utf8, which is UTF-8 text: pass other input through to_utf8 first. No tree is built, so Limits::max_nodes and Limits::max_input do not apply; depth and attribute limits do.
