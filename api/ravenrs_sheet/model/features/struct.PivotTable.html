Expand description

A PivotTable: its definition plus where its output was last written. The output itself is static cell values and styles on the sheet, rewritten on every refresh.

Fields§

§id: u32§name: String§source: String

Source: range formula text (Sheet1!$A$1:$E$200), a table name or a defined name.

§anchor: CellRef

Top-left of the output body on the pivot’s sheet.

§rows: Vec<PivotField>§columns: Vec<PivotField>§values: Vec<PivotValue>§filters: Vec<PivotFilter>§layout: PivotLayout§enable_show_details: bool

PivotTable Options › Data › Enable show details: Show Details lists a value cell’s source records only while this is on.

§grand_totals_rows: bool

Grand total for each row (the “Grand Total” column), like Excel’s “On for Rows”.

§grand_totals_cols: bool

Grand total for each column (the “Grand Total” row), like Excel’s “On for Columns”.

§subtotals: bool§subtotals_top: bool

Subtotals at the top of each group (Compact/Outline); otherwise below it.

§style: String§show_headers: bool§last_range: Option<RangeRef>

Area written by the last refresh.

§calculated_fields: Vec<PivotCalcField>

Calculated fields, usable in the Values area by name.

§values_on_rows: bool

The Σ Values pseudo-field (it exists with two or more value fields) sits in Rows rather than Columns (Excel’s “values on rows”).

§values_position: Option<usize>

Position of Σ Values among the row fields (None = after the last). Only used with values_on_rows: in Columns Σ Values always comes after the last column field.
