§sheets: Vec<Arc<Sheet>>§names: Vec<DefinedName>§styles: StyleTable§theme: Theme§date_system: DateSystem§calc: CalcSettings§show_objects: ShowObjects§remove_personal_info: bool

Trust Center › Privacy Options › “Remove personal information from file properties on save” (<workbookPr filterPrivacy="1"/>): kept with the file, and while it is on the author and company are left out of the XLSX files GridCraft writes, as Excel leaves them empty. Other formats aren’t filtered: the workbook’s own serialization still holds them.

§active_sheet: ActiveSheet

Read and set with Workbook::active_sheet and Workbook::set_active_sheet.

§view: WorkbookView

The workbook window’s display settings (<workbookView>), kept across an open + save.

§props: DocProps§protected_structure: bool

Workbook structure protection.

§structure_password: Option<PasswordHash>

Password of the structure protection (XLSX workbookProtection), never the password.

§custom_lists: Vec<Vec<String>>

Custom fill lists (Options › Custom Lists) beyond the built-in ones.

§cell_styles: Vec<(String, Style)>

Named cell styles (Cell Styles gallery): name → style.

§phonetics: Vec<PhoneticString>

Phonetic (furigana) data of shared strings (xl/sharedStrings.xml), one entry per string text, so that an open + save keeps a Japanese workbook’s readings. Written back next to the <si> holding the same text.

Keyed by text because that is all a cell keeps of its shared string: the saved table holds each text once (the format’s uniqueCount), so two <si> items that share a base text can only keep one reading — the reader keeps the first and warns. Empty for workbooks without phonetic data; not present in older JSON. Modelled data (unlike Workbook::preserved, which holds unmodelled parts), so it is saved to JSON as well as to XLSX.

§vba_project: Option<Arc<Vec<u8>>>

VBA project (xl/vbaProject.bin) carried through unchanged. GridCraft does not run macros; the blob is preserved so that saving a macro-enabled workbook never destroys the macros it arrived with. base64 in JSON. None = the workbook has no macros. Shared, so a copy of the workbook (every edit’s undo step) doesn’t copy it.

§csv_delimiter: Option<u8>

Field separator of the CSV this workbook was read from, so saving it as CSV writes the same separator back (a ; file stays a ; file). None = not read from CSV: CSV saves use ,.

§macros: Macros

GridCraft macros (typed command lists, not VBA), in the order the macro list shows them. The JSON format keeps them as this field; xlsx keeps them in hidden defined names.

§macros_read: Vec<Value>

The macros entries of a JSON file as read, before the engine checks each one on its own and moves it into macros, so one damaged or newer macro doesn’t stop the file opening. Never written.

§macros_unread: Arc<Vec<Value>>

Macros in a newer format than this build reads, as the file held them. They are never read, listed or run; a save writes them back unchanged, so the newer build gets them back whole. Shared between snapshots, as nothing changes them.

§preserved: Option<Arc<Preserved>>

Unmodelled file content kept for saving (package root and workbook level). Not in JSON.

§source_dir: Option<PathBuf>

The folder the workbook was read from, which relative paths to linked workbooks in preserved are relative to. Saving into another folder rewrites them from there. Not in JSON.

§source_path: Option<PathBuf>

The file this workbook reports as its own, which is what CELL("filename") returns. None = no file yet, which Excel reports as an empty string until the workbook has been saved once. Deliberately separate from source_dir: that one names the folder relative links are relative to and must keep naming it after a Save As into another folder, since the links in memory are still written for the old one. Not in JSON.

pub fn refresh_equations(&mut self)

Rebuilds the cached layout of every equation whose source changed (or was never laid out, as after loading a file). One call lays out at most MAX_EQUATION_LAYOUT_BYTES of source: one equation can take a tenth of a second to lay out, so a file with thousands of them would otherwise hold the app for minutes. Equations past the budget get an error instead (they show their source; editing one lays it out).
