DxfStated
The parts a differential format states at a value its Style can’t tell from unset: a dxf’s default parts are unset, so a bold turned off, a face, a size or a protection that matches the defaults would otherwise read as nothing. The values are the style’s own; this records that the format states them, and only where they match the defaults, so a format built in the app and the same format read back from a file stay equal.
