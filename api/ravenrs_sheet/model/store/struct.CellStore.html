pub fn contiguous_value_run(&self, from: CellRef, cap: u32) -> Option<u32>

Last row (inclusive, capped at cap) of the maximal run of contiguous rows at or after from.row that store a cell in from.col with a non-empty value in from.col. None when from itself doesn’t qualify.

Deliberately narrower than has/get (which also count a formula with no cached value yet, for Ctrl+arrow navigation): this matches Sheet::value_ref, whose callers test the Value it returns with !v.is_empty() regardless of whether a formula produced it — a formula cell with an empty cached value (="", or not yet recalculated) is “empty” to them. A stored cell with no value and no formula (for example a formatted spill child) does fall through to spill in value_ref, so last_contiguous_nonempty asks value_ref about the row where this run stops.

Walks each band’s row map with BTreeMap::range (one in-order pass per band) instead of one get per row, so a long, densely-populated run costs roughly one tree-traversal step per row rather than one binary search per row.

pub fn retained_bytes_against(&self, newer: &CellStore) -> usize

Approximate heap storage kept alive by this snapshot’s bands that newer no longer shares. This is for bounding Undo history, not for reporting process memory: BTreeMap nodes and allocator overhead vary by platform. Shared formulas and values are counted only when the newer band no longer holds the same Arc.
