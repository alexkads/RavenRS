ravenrs_sheet::model

Module preserved 

Source
Expand description

File content GridCraft does not model, carried through unchanged so that saving a workbook never silently drops it (XLSX pass-through: custom XML, external links, connections, query tables, form controls, OLE objects…).

The data is opaque to everything except the file-format crate: the model only holds it, so a sheet’s kept content disappears with the sheet. It is not part of the JSON format.

A chart sheet (a sheet that holds one chart and no cells) kept as it was in the source file. Its part, drawing, chart, style and colour parts are in Preserved::parts; the workbook relationship to it is in Preserved::rels.

A raw XML element of an owning part that refers to kept parts, re-emitted on save with its relationship ids rewritten, or that Excel needs back unchanged (the workbook’s fileVersion).
