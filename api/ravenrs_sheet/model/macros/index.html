GridCraft macros: typed, declarative command lists that run as one undo step. They are not VBA: a VBA project in a file is carried through unchanged (Workbook::vba_project) and never run.

Structs§

Macro
A recorded or hand-made macro: a list of typed steps that runs as one undo step. Most steps run a GridCraft command; Repeat, If and Stop add bounded control flow. References in step parameters can be tokens ("Input.col(2)") that are resolved against the declared inputs when the macro runs, so a macro recorded on one block of data works on another.
Macros
The macros of a workbook. Workbook snapshots share the list until one of them changes it, so an undo entry or a copy made for a cell edit holds the same list rather than a copy of every step. Reads go through Deref to the list; a write through DerefMut first copies the list when another snapshot shares it.
NamedInput
A range the macro works on, with the shape and content it expects.
OutputRule
Where a macro’s results go.
Step
One macro step and its editor flags.
