ravenrs_sheet

Module model 

Source
Expand description

The GridCraft document model: workbooks, sheets, a copy-on-write cell store, interned styles, defined names, tables, conditional formats, validation, comments, charts and print settings. Pure data; calculation lives in gridcraft-calc.

Modules§

cell
Cells.
features
Sheet features beyond cells: tables, conditional formatting, data validation, comments, hyperlinks, charts, images, autofilter, print settings.
macros
GridCraft macros: typed, declarative command lists that run as one undo step. They are not VBA: a VBA project in a file is carried through unchanged (Workbook::vba_project) and never run.
password
Excel-compatible password hashes for protection (ECMA-376 Part 1 §18.2.29 and §18.3.1.66 attribute sets): the legacy 16-bit hash (password="CC1A") and the iterated, salted hash (algorithmName, hashValue, saltValue, spinCount). Protection is a convenience, not security, but verification really checks the password: an unsupported variant is refused, never accepted.
preserved
File content GridCraft does not model, carried through unchanged so that saving a workbook never silently drops it (XLSX pass-through: custom XML, external links, connections, query tables, form controls, OLE objects…).
python
Python cells: the code a cell holds, its last result, and the text forms around it (the PY("…",0|1) formula of the function’s syntax, and the xl("…") references inside it). An xlsx file keeps the code in its Python part instead (see the xlsx crate).
sheet
Worksheets.
store
Copy-on-write sparse cell storage.
style
Cell styles (font, fill, borders, alignment, number format, protection), interned per workbook.
workbook
Workbooks.
