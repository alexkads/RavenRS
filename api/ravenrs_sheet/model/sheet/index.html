SheetUid
A sheet’s identity while the app runs, for what must follow one sheet (an open cell draft): a sheet made new (added, inserted, copied, read from a file or from JSON) gets a fresh one, and it stays with the sheet through renames, moves and the copies undo keeps. Never saved. It is not content: any two compare equal, so comparing sheets compares what they hold; compare identities with SheetUid::get.
