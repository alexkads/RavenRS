pub fn clear_spill(&mut self, r: RangeRef)

Removes the spilled values inside r. The work is bounded by the values stored, not by the size of r, so a range from a file that claims the whole sheet costs no more than the values it holds.

pub fn settle_spill(&mut self, anchor: CellRef)

Turns the spill anchored at anchor into plain values, for a Python cell that keeps only its value: the range is forgotten, and each spilled value in it becomes its cell’s value, unless the cell holds content of its own (its format is kept either way). The work is bounded by the spilled values stored, not by the size of the range.

pub fn last_contiguous_nonempty(&self, col: u32, from_row: u32, cap: u32) -> u32

Last row (inclusive) of the maximal contiguous run of non-empty values in col, starting at from_row and capped at cap (inclusive). from_row - 1 when from_row itself is empty (or from_row > cap), same as a cell-by-cell value_ref scan would find, but without calling value_ref once per row: CellStore::contiguous_value_run walks each band’s row map directly for the common case (a run of stored cells), only falling back to a per-row value_ref check where the stored run stops short of cap. Used by the fill-handle double-click, where col can be densely populated for very long stretches.
