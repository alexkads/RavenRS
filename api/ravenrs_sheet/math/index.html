Module math 

Source
Expand description

GridCraft equations. LaTeX source is laid out by RaTeX (ratex-parser, ratex-layout; MIT) into a MathList: plain glyph, rule and path data that the UI and the PDF writer paint without calling RaTeX again.

RaTeX is young (0.1.x), so it only ever runs inside this crate’s entry points (layout, to_omml, check). Each one caps its input (4 KB, nesting 32) and runs under catch_unwind, so a stray panic becomes a MathError. See the RaTeX gate in docs/decisions.md and tests/gate.rs.

Units are em: one em is the equation’s font size. Coordinates run right and down from the top-left of the list’s box; the baseline is at y = height.
