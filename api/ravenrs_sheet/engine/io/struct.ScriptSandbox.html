Struct ScriptSandbox 

Source 
pub struct ScriptSandbox(/* private fields */);
Expand description

While one is alive, read_file and write_file on this thread refuse every path: a stored script’s steps run inside one (#2178), so no command reaches the file system from a script whatever its parameters are called. Dropping it (also on unwind) lifts the refusal.
