The GridCraft engine façade.

Every user-visible action is a command with a stable id (cell.set, home.bold, data.sortAscending…) and JSON parameters. The egui UI, the CLI, the control channel and MCP all go through Session::execute, so every action is scriptable and journaled.

Width in points of one line of text drawn in a cell font, measured by a front end that has the font the grid draws with. With exact false the front end may answer with a cheaper measure that is never narrower (AutoFit asks for it on columns with many distinct values).
