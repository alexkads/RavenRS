pub fn execute(&mut self, id: &str, params: Json) -> Result<Json>

Runs a command by id. Undoable commands record a history step when the workbook changed, unless an undo group is open on the document (the group then makes the step). Panics inside commands are caught and reported; the workbook is restored.

Source

pub fn grouped<R>( &mut self, label: &str, f: impl FnOnce(&mut Session) -> Result<R>, ) -> Result<R>

Runs f as one undo step labelled label on the active document: whatever commands f runs, one Undo brings back the workbook as it was before. If f fails, every change it made is rolled back and its error is returned. Groups nest; the outermost one makes the step.

Source

pub fn group_begin(&mut self, label: &str) -> Result<GroupToken>

Opens an undo group on the active document that can span several calls (for example a debugger that runs one step per call). Until Session::group_end or Session::group_rollback, undoable commands on that document add no undo steps of their own, and Undo and Redo are unavailable there.

Source

pub fn group_end(&mut self, token: GroupToken) -> Result<bool>

Ends an undo group. If the workbook changed, the group becomes one undo step, unless it is nested in another open group on the same document, which then owns the step. Groups opened inside it and still open end with it. Returns whether the workbook changed.

Source

pub fn abort_groups(&mut self, doc: u64) -> bool

Stops the running action on the document with uid doc: every undo group open on it is rolled back as Session::group_rollback does, putting back the workbook, selection, undo and redo history as they were when the outermost one began. Their tokens are then spent (ending or rolling one back reports that it has already ended). Returns whether a group was open. automate.stopAction runs it on the active document.

Source

pub fn group_rollback(&mut self, token: GroupToken) -> Result<()>

Ends an undo group by putting back the workbook, selection, undo and redo history as they were when it began.

Source

Starts recording top-level commands into an empty buffer, replacing any recording in progress. Queries, failed commands and commands run by other commands are not recorded.
