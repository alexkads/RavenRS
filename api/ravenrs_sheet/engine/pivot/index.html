Module pivot 

Source
Expand description

PivotTables: reading the source list, grouping and aggregating, laying out the report and writing it onto the sheet as static, styled cells.

Behaviour follows Excel’s documented PivotTable model (rows/columns/values/filters areas, Compact/Outline/Tabular layouts, subtotals, grand totals, show-values-as); the code and the look (our own palette) are original.
