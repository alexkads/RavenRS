Formulas › Recently Used: the functions most recently entered in a formula.

The list is crate::engine::Prefs::recent_functions, an application list like Excel’s, saved with the other preferences. crate::engine::Session::execute calls [note] for each cell.* and range.* command it journals, from any source (the interface, the control channel, MCP or a script), so the list never depends on the journal, which drops its oldest entries.

How many functions the list keeps.

The functions a formula calls, outermost first, known functions only. A formula is what a cell takes as one (=…, or +…/-… as Excel takes +SUM(1)).
