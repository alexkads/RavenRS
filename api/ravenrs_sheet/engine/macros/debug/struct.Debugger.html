Fields§

§name: String§doc: u64§breakpoints: BTreeSet<String>

Breakpoints set for this run (step paths), on top of the steps’ own.

§only_listed: bool

Only breakpoints stop the run; the steps’ own flags are ignored (an editor that shows its own breakpoints sends them all, so clearing one takes effect at once).
