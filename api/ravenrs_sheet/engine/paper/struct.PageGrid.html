Expand description

One sheet paginated for the Page Layout view.

Fields§

§page_w: f64

Page size in layout units.

§page_h: f64§margins: [f64; 6]

Left, right, top, bottom, header and footer margins in layout units.

§gap: f64

Gap between pages in layout units.

§scale: f32

Print scale (1.0 = 100%): screen sizes of cells are zoom × scale.

§hf_sides: [f64; 2]

Left and right margins of headers and footers in layout units (the side margins, or a fixed 0.7 inch, at most a quarter of the page width, with Align with Page Margins off).

§hf_text_k: f32

Layout units per sheet pixel of header and footer text: 1 with Scale with Document on, otherwise 1 / scale, so the text keeps its point size on paper.

§paper_pt: (f32, f32)

Paper size in points (after orientation), for the rulers.

§row_bands: Vec<(u32, u32)>§col_bands: Vec<(u32, u32)>§rows_complete: bool

The bands reach the sheet’s last row / column.

§cols_complete: bool§data_rows: (usize, usize)

Bands holding printed data: [first, last] row bands and column bands.

§data_cols: (usize, usize)§page_order: PageOrder

The sheet’s page order, which numbers the printed pages.
