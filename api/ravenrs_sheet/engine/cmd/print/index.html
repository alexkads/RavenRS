Expand description

Printing: Page Setup, pagination and PDF output (File › Print, File › Export › PDF).

Sheets are paginated like Excel: the print area (or the used range plus drawing objects) is split into bands of rows and columns that fit the printable area at the page scale, honouring manual breaks, repeated title rows/columns, headings, Fit To and centring, and the pages follow the sheet’s page order (“down, then over” by default, or “over, then down”). Each page is drawn into a PDF with gridcraft-pdf: fills, gridlines, borders, formatted text (fonts mapped to the standard 14 PDF fonts), merged cells, wrapping, overflow into empty neighbours, conditional formats, table styles, charts, images, shapes and sparklines. Headers and footers support &L/&C/&R sections and the &P &N &D &T &A &F &Z codes.
