Module equation 

Source
Expand description

Equations (Insert › Symbols › Equation): floating shapes holding LaTeX source, laid out by gridcraft-math and drawn from the cached layout.

An equation is drawn to fit its frame, so resizing the frame scales it. Inserting sizes the frame for the requested font size; editing keeps the current scale and resizes the frame to the new content.
