WordCraft reader for the Word 97-2003 binary file format (.doc, [MS-DOC]).

read turns the bytes of a .doc file into a crate::doc::Document. There is no writer: saving always goes through the other formats. The reader is written from the public specification ([MS-DOC], Word (.doc) Binary File Format, Microsoft Open Specifications) and, like every WordCraft parser, is lenient by design (unknown structures are skipped, bad numbers fall back to defaults) and bounded (stream sizes, piece counts and property counts are capped), so hostile input yields an error or a best-effort document, never a panic.

is_encrypted
Is this .doc password-protected (XOR obfuscation, RC4 or RC4 CryptoAPI)? False for anything that is not a readable Word 97-2003 file.
read
Read a .doc (Word 97-2003 binary) file into a Document. A password-protected file gives DocbinError::PasswordRequired; see read_with_password.
read_with_password
read for a file that may be password-protected: it is checked against the file’s stored verifier (DocbinError::WrongPassword when it does not match) and then decrypted. The password is ignored for an unprotected file.
