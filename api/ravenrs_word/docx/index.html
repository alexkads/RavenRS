Module docx 

Source
Expand description

WordCraft DOCX reader and writer (ECMA-376 / ISO/IEC 29500 WordprocessingML).

read turns a .docx package into a crate::doc::Document; write does the reverse. Both are written from the public specification. The reader is lenient (unknown markup is skipped, bad numbers fall back to defaults) and bounded (zip entry sizes, total decompressed size, XML depth and element counts are capped), so hostile input yields an error or a best-effort document, never a panic.

package_title
The title (dc:title) in a package’s core properties part (docProps/core.xml, ECMA-376 Part 2 §11), trimmed; None when the part can’t be read or has no title. Only the package’s directory and at most max_part bytes of that part are inflated: for listing templates by name without unpacking the whole package. A package over 64 MiB, or one declaring more entries than MAX_ENTRIES (20,000), has none (#3660).
protection_hash
Restrict Editing’s password (w:documentProtection, ECMA-376 Part 1 §17.15.1.29): the attributes that store its hash — SHA-512 of a random 16-byte salt and the password as UTF-16LE, hashed again spin_count times with the iteration number appended ([MS-OFFCRYPTO] §2.4.2.4, the ISO write-protection method). Protection isn’t encryption: the document stays readable, the password only guards turning protection off.
