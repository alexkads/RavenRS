§track_changes: bool§track_moves: bool

Record a tracked cut and paste of a sentence or paragraph as a move (Track moves); off when the file has w:doNotTrackMoves (ECMA-376 §17.15.1.29), and then it is an ordinary deletion and insertion.

§default_tab: f32

Default tab stop interval, points.

§even_odd_headers: bool§mirror_margins: bool§auto_hyphenation: bool§hyphenation_zone: f32

Hyphenation zone (w:hyphenationZone), points: a line is hyphenated only when breaking it at a word boundary would leave more than this empty at its end.

§hyphenate_caps: bool

Words in capitals may be hyphenated (w:doNotHyphenateCaps turns it off).

§consecutive_hyphen_limit: u32

Most consecutive lines that may end with a hyphen (w:consecutiveHyphenLimit); 0 = no limit.

§page_color: Option<Rgb>§page_picture: Option<PagePicture>

Picture or texture page background (Design › Page Color › Fill Effects), drawn over the colour.

§watermark: Option<Watermark>§major_font: String

Theme fonts (major = headings, minor = body).

§minor_font: String§theme_colors: Vec<Rgb>

Theme colours: dk1 lt1 dk2 lt2 accent1..6 hlink folHlink.

§theme_name: String§footnote_format: NumFormat§endnote_format: NumFormat§footnote_pr: NoteProps

The document’s footnote and endnote placement, start and restart (w:footnotePr / w:endnotePr in the settings); sections may override them.

§endnote_pr: NoteProps§protection: Option<String>

Restrict Editing, when enforced: readOnly, comments, trackedChanges, forms, or none when only formatting is restricted (w:documentProtection w:edit).

§protect_formatting: bool

Restrict Editing limits formatting to the styles that aren’t locked, and forbids direct formatting (w:formatting="1").

§protect_hash: Vec<(String, String)>

The protection password’s hash, as the file’s w:documentProtection attributes (w:algorithmName, w:hashValue, w:saltValue, w:spinCount, or the older w:cryptAlgorithmSid, w:hash, w:salt…). Empty: no password.

§compat_mode: u32

Word compatibility mode the document is laid out in (compatibilityMode): 15 for Word 2013 and later, which places a table’s border at the margin rather than its text and lets justified lines shrink their spaces to fit more text.

§roman_fonts: Vec<String>

Fonts the document’s font table classes as roman (serif, w:family w:val="roman"): Word draws one that isn’t installed in a serif face.

§sum_paragraph_spacing: bool

w:doNotUseHTMLParagraphAutoSpacing: the space between two paragraphs is the first’s space after plus the second’s space before, not the larger of the two.

§do_not_expand_shift_return: bool

w:doNotExpandShiftReturn: a justified line that ends in a manual line break keeps its natural spacing; by default Word stretches it to the margin like a wrapped line.

§allow_space_of_same_style_in_table: bool

Keep contextual paragraph spacing inside legacy table cells (allowSpaceOfSameStyleInTable). Word ignores the layout override in compatibility mode 15, but the flag still round-trips.

§grid_h: f32

Drawing grid spacing in points, across and down (View › Gridlines); ECMA-376’s default is 1/8 inch.

§grid_v: f32§math: Option<MathProps>

Equation options (m:mathPr), when the document has them.

§bib_style: Option<String>

Citation and bibliography style (References › Style) by name, when the document records one (OOXML’s b:Sources/@StyleName).

§attached_template: Option<String>

The template the document is attached to (Tools › Templates and Add-ins): the target of w:attachedTemplate’s relationship, a path or file: URL as the file gives it.

§link_styles: bool

Update the document’s styles from the attached template when it is opened (w:linkStyles).

§zoom: Option<Zoom>

The zoom the document was saved at (w:zoom), restored when it is opened; None for 100% without a fit mode.

§remove_personal_info: bool

Remove personal information when saving (w:removePersonalInformation, ECMA-376 §17.15.1.70): the saved file names comment and revision authors “Author” and leaves out the document’s creator and last-modified-by. The open document keeps its real values.

§remove_date_time: bool

Remove date and time from annotations when saving (w:removeDateAndTime, §17.15.1.69): comments and tracked changes are saved without w:date.

§odf: Option<OdfLayout>

The document was opened from ODF: the standard’s rules that differ from Word’s apply as it is laid out.
