Expand description

The kind of a content control and its settings.

Variants§

§

RichText

Formatted text, paragraphs, anything (also controls of a type we don’t model, whose type element is kept in ContentControl::extra).

§

Text

Unformatted text (w:text), on one line unless multi_line.

Fields

§multi_line: bool
§

CheckBox

A check box (w14:checkbox): the content is the state’s symbol.

Fields

§checked: bool
§checked_char: char
§checked_font: String
§unchecked_char: char
§unchecked_font: String
§

ComboBox

A list to choose from, or type into (w:comboBox).

Fields

§items: Vec<ListItem>
§last_value: String
§

DropDown

A list to choose from (w:dropDownList).

Fields

§items: Vec<ListItem>
§last_value: String
§

Date

A date (w:date): full_date is ISO 8601, format a date picture (M/d/yyyy).

Fields

§full_date: String
§format: String
§lid: String
§calendar: String
§store_as: String
§

Picture

A picture (w:picture).

§

Gallery

A building block gallery (w:docPartList) or a building block placed from one (w:docPartObj: tables of contents, cover pages, bibliographies).

Fields

§list: bool

w:docPartList rather than w:docPartObj.

§gallery: String
§category: String
§unique: bool
§

RepeatingSection

A repeating section (w15:repeatingSection), whose items are repeated.

Fields

§title: String
§no_insert_delete: bool
§

RepeatingSectionItem

One item of a repeating section (w15:repeatingSectionItem).
