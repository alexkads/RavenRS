What a reader kept.

Fields§

§format: String

The format it came from ("odt"): only that format’s writer uses it.

§paras: HashMap<u64, Arc<str>>

Paragraph fingerprint → the paragraph’s markup, in the order read (identical paragraphs keep the first’s).

§tables: HashMap<u64, Arc<str>>

The same for the body’s tables (table_fingerprint).

§pending_tables: Vec<(usize, Arc<str>)>

While reading: the markup of the body’s nth table, until Kept::seal.

§wraps: HashMap<u64, (Vec<Arc<str>>, u32)>

Wrappers kept as read around paragraphs (sections): for a paragraph’s fingerprint, the start tags opening before it and how many close after it. Only paragraphs that were the only one of their kind have them (a copy can’t open a section twice).

§pending_wraps: HashMap<u64, (Vec<Arc<str>>, u32)>

While reading: the same by paragraph rev, until Kept::seal.

§twin_wraps: HashMap<(u64, u64), (Vec<Arc<str>>, u32)>

The same for paragraphs with twins (an empty paragraph has many): by fingerprint and Paragraph::rev, which stays while the paragraph does (a writer opens each once).

§table_wraps: HashMap<u64, (Vec<Arc<str>>, u32)>

The same wrappers around the body’s tables, by table_fingerprint (tables that are the only one of their kind).

§pending_table_wraps: Vec<(usize, (Vec<Arc<str>>, u32))>

While reading: those of the body’s nth table, until seal_kept.

§indexes: HashMap<u64, (usize, u64, Arc<str>)>

Indexes kept as read: by their first paragraph’s fingerprint, how many top-level paragraphs they take, those paragraphs’ fingerprint together (run_fingerprint), and the index’s markup. Written as read while those paragraphs are all as read.

§pending_indexes: HashMap<u64, (usize, Arc<str>)>

While reading: by the first paragraph’s rev, how many paragraphs, and the markup.

§groups: HashMap<u64, (u32, u32)>

The group of paragraphs written as read together (see crate::formats::model::Group) each paragraph kept belongs to, by its fingerprint: the group’s id and size.

§pending_groups: HashMap<u64, (u32, u32)>

While reading: the same by paragraph rev, until seal_kept.

§story_fps: HashMap<u32, u64>

Each text box’s, shape’s or note’s story’s story_fingerprint when read: a paragraph showing one is written as read only while it is as read.

§comment_fps: HashMap<u32, u64>

Each top-level comment’s comments_fingerprint when read (it and its replies): a paragraph holding comments is written as read only while they are as read.

§defs: BTreeMap<String, Arc<str>>

Named definitions the kept markup refers to (styles, font faces…), by a key the format chooses ("auto:P12", "style:Heading_20_1"), as read.

§pending: HashMap<u64, Arc<str>>

While reading: paragraph Paragraph::rev → its markup, until Kept::seal turns them into fingerprints.

§bytes: usize

Bytes kept so far.

§order: Vec<String>

The keys of KeptXml::defs in the order the file had them.

§files: BTreeMap<String, Arc<Vec<u8>>>

Files of the package kept definitions refer to (a style’s fill picture), by path.

§styles_fp: Option<u64>

The document’s style definitions’ styles_fingerprint when read: while it is the same, the file’s own style definitions can be written as they were.

§pages_fp: Option<u64>

The document’s page setup’s pages_fingerprint when read: while it is the same, the file’s own page layouts and master pages can be written as they were.

§section_masters: Vec<Option<String>>

Each section’s master page, as the file named it where its section starts (None: the file’s default), for a writer naming the file’s own master pages.
