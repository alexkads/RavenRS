ravenrs_word::doc

Module kept 

Source
Expand description

Markup kept from the file a document was opened from, so that what isn’t edited is written back as it was: a paragraph keeps its source XML, which a writer uses as long as the paragraph still is what the reader made of it (its fingerprint unchanged). Anything the model has no place for (an unknown element, an attribute nobody reads) survives a save that way. Never saved with the document (WordCraft’s own format), and not part of its content (== ignores it).
