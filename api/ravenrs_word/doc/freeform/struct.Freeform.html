Expand description

A freeform shape’s geometry: paths in a w × h coordinate space that is stretched over the shape’s frame (DrawingML’s a:path w and h). Drawn with the shape’s outline colour and width (and its fill, for closed paths that aren’t ink).

Fields§

§w: f32§h: f32§paths: Vec<FreePath>§alpha: f32

Opacity of the outline, 0–1.

§ink: Option<InkTool>

Set when this is ink: drawn with a pen (Draw tab), hidden by Review › Hide Ink and removed by the eraser.

§order: Option<u32>

Ink: its place in the order the strokes were drawn (1, 2, 3…), for Draw › Ink Replay. None for ink from files that don’t record it (replayed first, in document order).
