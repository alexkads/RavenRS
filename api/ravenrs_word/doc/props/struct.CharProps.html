Expand description

Character formatting (direct or in a style). None = inherit.

Fields§

§style: Option<String>

Character style id.

§font: Option<String>§sym_font: Option<String>

The symbol’s own font (OOXML w:sym/@w:font, ECMA-376 §17.3.3.30), set on a symbol character from a w:sym or Insert › Symbol: it is shown in this font whatever font is, so changing the text’s font keeps the symbol. None = the run’s font.

§size: Option<f32>

Points.

§bold: Option<bool>§italic: Option<bool>§underline: Option<Underline>§underline_color: Option<Rgb>§strike: Option<bool>§double_strike: Option<bool>§color: Option<TextColor>§highlight: Option<Highlight>§shading: Option<Rgb>

Character shading (background fill).

§border: Option<Border>

Character border (w:bdr); style: None = explicitly no border.

§vert_align: Option<VertAlign>§caps: Option<bool>§small_caps: Option<bool>§hidden: Option<bool>§web_hidden: Option<bool>

Hidden in Web Layout (w:webHidden); distinct from w:vanish (hidden).

§snap_to_grid: Option<bool>

Snap characters to the document grid (w:snapToGrid). Unset inherits; Word’s default is on.

§spacing: Option<f32>

Character spacing (expanded/condensed), points.

§scale: Option<f32>

Horizontal scale, percent (100 = normal).

§position: Option<f32>

Raised (+) / lowered (−) position, points.

§kern: Option<f32>

Kerning for fonts at or above this size (points); 0 = off.

§emphasis: Option<EmphasisMark>

A mark over (or under) each character (w:em, Font › Emphasis mark), as East Asian text stresses words; Some(EmphasisMark::None) turns off one a style sets.

§ligatures: Option<Ligatures>

OpenType ligatures (w14:ligatures). None leaves WordCraft’s default: standard and contextual ligatures.

§outline: Option<bool>§shadow: Option<bool>§emboss: Option<bool>§engrave: Option<bool>§text_effects: Option<Box<TextEffects>>

WordArt text effects: fill, outline, shadow, glow, reflection ([MS-DOCX] w14: run properties). Overlaid effect by effect.

§lang: Option<String>

BCP 47 language tag (proofing).

§no_proof: Option<bool>§rtl: Option<bool>

Right-to-left run (OOXML w:rtl): its characters are complex script and read right to left.

§cs: Option<bool>

Format the whole run with the complex-script properties below (OOXML w:cs).

§font_cs: Option<String>

Complex-script font (Arabic, Persian, Hebrew…; OOXML w:rFonts/@w:cs). None = font.

§font_ea: Option<String>

East Asian font (Chinese, Japanese and Korean text; OOXML w:rFonts/@w:eastAsia). None = inherit, then font.

§size_cs: Option<f32>

Complex-script size, points (w:szCs). None leaves the inherited value unchanged.

§bold_cs: Option<bool>

Complex-script bold / italic (w:bCs, w:iCs). None leaves the inherited value unchanged.

§italic_cs: Option<bool>§lang_bidi: Option<String>

BCP 47 language of complex-script text (w:lang/@w:bidi, e.g. fa-IR).

§lang_ea: Option<String>

BCP 47 language of East Asian text (w:lang/@w:eastAsia, e.g. zh-CN, ja-JP, ko-KR).

§east_asian_layout: Option<EastAsianLayout>

East Asian typography: two lines in one and horizontal in vertical (w:eastAsianLayout). Kept for round trip; layout doesn’t apply it yet.

§link: Option<String>

Hyperlink target: a URL, or #bookmark for an internal link.

§ins: Option<u32>

Tracked insertion: index into Document::revisions.

§del: Option<u32>

Tracked deletion: index into Document::revisions.

§fmt_change: Option<Box<PropChange<CharProps>>>

Tracked formatting change (w:rPrChange): the formatting before it.
