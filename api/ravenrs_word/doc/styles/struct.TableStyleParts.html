Expand description

Table style conditional formats (shading + character formatting per region).

Fields§

§borders: Option<Borders>§fill: Option<Rgb>

Shading of every cell (w:tblPr/w:shd, or the wholeTable region’s cell shading).

§cell_margins: Option<[f32; 4]>

Cell margins, points: [top, left, bottom, right] (w:tblCellMar).

§header_fill: Option<Rgb>§header_chr: CharProps§header_borders: Option<Borders>

Cell borders of the header row (firstRow region’s w:tcBorders): between is the border between header rows, inside_v between its cells.

§band_fill: Option<Rgb>§band_chr: CharProps

Character formatting of the odd row bands (band1Horz region).

§band_borders: Option<Borders>

Cell borders of the odd row bands (band1Horz region’s w:tcBorders).

§band_size: Option<u32>

Rows per band (w:tblStyleRowBandSize). Unset (in the whole based-on chain) or zero, the row bands are off: Word reads a missing size as zero, where ECMA-376 says one (MS-OE376 §2.7.5.7, #3415). Our own banded styles set one.

§col_band_size: Option<u32>

Columns per band (w:tblStyleColBandSize); unset or zero, the column bands are off, as in Word (MS-OI29500 §17.7.6.5).

§first_col_chr: CharProps§total_chr: CharProps§total_border_top: Option<Border>§first_col_fill: Option<Rgb>

Shading and cell borders of the first column (firstCol region).

§first_col_borders: Option<Borders>§last_col_fill: Option<Rgb>

The last column (lastCol region).

§last_col_chr: CharProps§last_col_borders: Option<Borders>§total_fill: Option<Rgb>

Shading and cell borders of the total (last) row (lastRow region); a top edge left unset falls back to total_border_top.

§total_borders: Option<Borders>§col_band_fill: Option<Rgb>

The odd column bands (band1Vert region).

§col_band_chr: CharProps§col_band_borders: Option<Borders>§regions: BTreeMap<TablePart, PartFormat>

Per-part formatting the named fields above don’t carry: every field of the parts without one (even bands, corner cells), and the cell text alignment of every part. Read and write parts through TableStyleParts::part / TableStyleParts::set_part.

impl TableStyleParts

Source

pub fn overlay(&mut self, patch: &TableStyleParts)

Apply patch (a style further down a based-on chain) over these parts: what it sets wins, the rest is inherited; borders merge edge by edge.

Source

pub fn part(&self, p: TablePart) -> PartFormat

Part p’s formatting. The whole table’s text formatting is the style’s own (Style::table_part adds it); its borders are the table borders.

Source

pub fn set_part(&mut self, p: TablePart, f: PartFormat)

Replace part p’s formatting (for the whole table only its fill, borders and vertical alignment: Style::set_table_part stores the rest).
