Fields§

§id: String

Stable id (Heading1), referenced by ParaProps::style / CharProps::style.

§name: String

Display name (Heading 1).

§kind: StyleKind§based_on: Option<String>§next: Option<String>

Style for the paragraph after this one (Enter at the end).

§linked: Option<String>

Linked character/paragraph style id.

§para: ParaProps§chr: CharProps§priority: Option<u32>

Gallery order (lower first).

§quick: bool

Shown in the Styles gallery on the Home tab.

§hidden: bool§builtin: bool

Built in (cannot be deleted).

§locked: bool

Can’t be applied while Restrict Editing limits formatting to a selection of styles (w:locked).

§para_change: Option<Box<PropChange<ParaProps>>>

A tracked change of the style’s paragraph properties (w:pPrChange).

§chr_change: Option<Box<PropChange<CharProps>>>

A tracked change of the style’s run properties (w:rPrChange). Kept separate because a foreign DOCX can attribute the two property changes to different revisions.

§default: bool

The default style of its kind (w:default), whatever its id: localized documents call the default character, table and list styles something other than the English ids.

§table: Option<TableStyleParts>

Table style: conditional formatting for header row, banding etc.
