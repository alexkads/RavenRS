Module math_latex

Expand description

LaTeX ↔ math tree (Word’s LaTeX equation input and conversion).

Input covers the commands people type in equations: \frac, \sqrt[n]{}, scripts, big operators with limits, \left…\middle…\right, matrix and cases/aligned environments, accents, \overbrace/\underbrace, \text/\mathrm/\mathbf/\mathbb…, function names, spacing and every named symbol in crate::doc::math_symbols. Unknown commands stay as text.
