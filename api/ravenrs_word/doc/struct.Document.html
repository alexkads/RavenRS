pub fn ime_delete_surrounding( &self, cursor: &Pos, anchor: &Pos, before: usize, after: usize, unit: DeleteUnit, ) -> Option<ImeDelete>

Delete-surrounding ranges in the stored paragraph text.

Counts exclude the selection, tracked deletions and any pre-edit (which never lives in the model here). Byte counts that end inside a scalar leave it whole: a start rounds forward and an end rounds backward; a byte count beyond the visible text is refused. Character counts clamp at the paragraph’s ends, as the web text agent’s do. A range that cannot be represented in stored text returns None instead of guessing; so does a request with nothing to erase (0 on both sides).

pub fn same_content(&self, other: &Document) -> bool

Whether the document holds the same content as other: the same blocks, the same styles, lists, settings, comments and the rest.

The blocks are compared by address first: the document is copy-on-write, so a block that changed was copied and has another address. Comparing them by value would walk the whole document, and this is asked after every command.

Every field is listed, so a new one does not build until someone decides whether a change to it counts (the same rule the session’s edit snapshot follows).
