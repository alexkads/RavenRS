Expand description

An inline object anchored at a U+FFFC in the paragraph text.

§

Group

Pictures, shapes and text boxes grouped into one object (Layout › Arrange › Group): it moves, wraps and resizes as one. Its members are laid out in the group’s own coordinate space, ch_w × ch_h, which is stretched over the group’s w × h (DrawingML’s a:chExt and a:ext), so resizing the group scales them.

Fields

§w: f32
§h: f32
§float: Float
§ch_w: f32

Size of the members’ coordinate space (their offsets and sizes are in it).

§ch_h: f32
§children: Vec<GroupChild>
§canvas: Option<CanvasStyle>

A Drawing Canvas (Insert › Shapes › New Drawing Canvas, DrawingML’s wpc:wpc) rather than a group: it has its own background and outline, and its frame is independent of its members: resizing it doesn’t scale them (ch_w × ch_h follow w × h), and what lies outside the frame is clipped.

§

Field

A field: instr is the field code (PAGE, NUMPAGES, DATE \@ "M/d/yyyy", TOC \o "1-3"…); result the cached display text. A locked field keeps its result when fields update.

Fields

§instr: String
§result: String
§locked: bool
§dirty: bool

w:dirty (ECMA-376 §17.16.5.35): the cached result is stale — another program that couldn’t compute it set the flag so Word refreshes the field on open. Kept through saves; cleared when WordCraft computes a result, like Word’s F9.

§code: bool

Shows its code ({ PAGE }) instead of its result, the other way round from the document-wide View › Field Codes setting (fields.toggleCode, Shift+F9). A view toggle: never written to files.

§form: String

A legacy form field’s definition (FORMCHECKBOX, FORMTEXT, FORMDROPDOWN): the source’s w:ffData, raw OOXML kept for round trip. Empty for other fields.

§

FieldStart

The start of a field whose result is ordinary content — formatted, possibly spanning paragraphs — up to the matching InlineObject::FieldEnd. Imported TOCs and citation managers’ ADDIN fields are kept this way; instr is the field code. See crate::doc::fields.

Fields

§instr: String
§locked: bool
§dirty: bool

w:dirty on the begin marker, as InlineObject::Field::dirty.

§

FieldEnd

The end of the innermost open InlineObject::FieldStart.

§

ControlStart

PermStart

Equation

An equation: its linear format (x=(-b±√(b^2-4ac))/2a, for plain text) and structure. A display equation sits on a line of its own.

Fields

§linear: String
§display: bool
§math: Math

The structure; empty = parse linear.

§

Ruby

Ruby (Phonetic Guide): small ruby text (furigana, pinyin…) set over base text. The base text takes the formatting of the object’s run; it reads as the paragraph’s text.

Fields

§base: String
§ruby: String
§align: RubyAlign
§size: f32

Ruby text size, points (w:hps).

§raise: f32

From the base text’s baseline up to the ruby text’s baseline, points (w:hpsRaise).

§base_size: f32

The base text size the ruby was set for, points (w:hpsBaseText).

§lang: String

Language of the ruby (w:lid, e.g. ja-JP); empty = unspecified.

§props: Box<CharProps>

Formatting of the ruby text over the run’s (font, colour…); its size is size.

§

PositionalTab

A positional tab (Word’s alignment tab, w:ptab): it goes to the left edge, centre or right edge of the margins or of the indents, whatever the paragraph’s tab stops, and the text after it lines up there. Text already past that place sends it to the next line.

Fields

§align: PTabAlign
§relative_to: PTabBase
§leader: TabLeader
§

Opaque

Something we don’t model, kept for round-trip (raw XML of the source format).

Fields

§xml: String
§text: String
