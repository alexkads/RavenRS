Paragraphs: text with formatting runs and inline objects.

A paragraph’s text is one String. Formatting is a list of Runs whose byte lengths sum to the text length. Inline objects (pictures, fields, note references, bookmarks, comment anchors…) sit in the text as U+FFFC; the k-th U+FFFC is objects[k]. Special characters: \t tab, \n manual line break, U+000C page break, U+000E column break.
