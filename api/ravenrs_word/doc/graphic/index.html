Charts, SmartArt diagrams and native ink: drawings kept as neutral items ready to draw. Charts and SmartArt WordCraft can edit also keep their model (crate::doc::chart::ChartSpec, crate::doc::smart_art::SmartArtSpec); the rest are shown, not edited.

Embedded
What an object read from a file needs to be written back as it was: its own markup in the source format and the package parts that markup refers to. Never edited; WordCraft only moves and resizes the object around it. The parts themselves (bytes, content type and their own relationships) are kept in crate::doc::Document::passthrough under their part names.
