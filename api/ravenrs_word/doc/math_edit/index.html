Module math_edit 

Source
Expand description

Editing inside an equation: caret positions, typing, inserting structures, deleting, moving the caret, and Word-style build-up (typing a/b then a space makes a fraction) and Math AutoCorrect (\alpha then a space makes α).

A caret position is an argument — a path of (node index, child argument) from the equation’s top-level argument — and an offset in units: each character of a run is one unit, every other node is one unit. All operations take any position and clamp it; none panics.
