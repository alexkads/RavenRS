Module ime_text

Visible logical text for IME surrounding-text queries.

The platform input method works on what the reader sees, not on the stored run text: tracked deletions are hidden, and an inline object stands for its plain-text result. The helpers here build a bounded window around a selection without cloning the paragraph or the document, and map both ends in both directions so a query and a delete use exactly the same text.
