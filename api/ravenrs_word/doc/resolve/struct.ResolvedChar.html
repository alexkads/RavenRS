impl ResolvedChar

Source

pub fn complex(&self) -> ResolvedChar

The formatting complex-script text in this run is drawn with: the complex-script font, size, bold and italic in place of the others (Word formats Arabic, Persian and Hebrew characters, and every character of an rtl/cs run, this way).

Source

pub fn kerned(&self) -> bool

Whether the text is kerned: Word kerns only a run with Kerning for fonts set (w:kern) at a size of at least that many points, never by default (measured in Word for Windows).

Source

pub fn uses_complex(&self, c: char) -> bool

Does a character of this run use the complex-script properties?

Source

pub fn draw_size(&self) -> f32

The size glyphs are drawn and measured at. Word sets superscript and subscript text at 0.65 of the run’s size rounded to the half point, a font size the format can store (measured in Word for Mac from digit advances: 8 pt → 5, 9 → 6, 11 → 7, 12 → 8, 16 → 10.5, 24 → 15.5, 36 → 23.5).
