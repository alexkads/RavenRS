Automatically adjust the right indent for the document grid when enabled; keep the specified right indent when disabled.

Padding on the sides without a line (top, left, bottom, right), points. ODF’s box model (XSL’s) keeps it for documents opened from ODF (Settings::odf); Word drops it.

impl ResolvedPara

Source

pub fn visual_indents(&self) -> (f32, f32)

Visual (left, right) indents. Indents, like alignment, are logical: indent_left is the start (leading) edge, which is the right edge of a right-to-left paragraph (ISO 29500 w:ind/@w:start, read from w:left too).

Source

pub fn set_char_unit(&mut self, size: f32)

Turn the indents given in characters into points, one character being size points: the size of the paragraph mark’s font (as Word measures w:firstLineChars and friends).
