ravenrs_word::doc

Module encoding 

Source
Expand description

Windows-1252 (the byte encoding legacy Word text pieces use) and the other single-byte Windows code pages RTF files name with \ansicpg or a font’s \fcharset (Cyrillic 1251, Central European 1250, Greek, Turkish, Hebrew, Arabic, Baltic, Vietnamese, Thai), Mac OS Roman (10000, RTF \mac), and the East Asian multibyte code pages (932 Shift-JIS, 936 GBK, 949 UHC, 950 Big5), whose bytes decode as runs rather than one at a time.

Constants§

MAC_ROMAN_CODE_PAGE
Mac OS Roman, RTF’s \mac character set.
MULTIBYTE_CODE_PAGES
The East Asian multibyte code pages a document format names with \ansicpg or a font’s \cpg: 932 Shift-JIS (Japanese), 936 GBK (Simplified Chinese), 949 UHC (Korean) and 950 Big5 (Traditional Chinese).
OEM_CODE_PAGES
The OEM code pages oem_byte decodes.
SINGLE_BYTE_CODE_PAGES
The single-byte Windows code pages windows_byte decodes (1252 included).

Functions§

charset_code_page
The code page of an RTF or Word font charset (\fcharset): 204 Russian → 1251, 238 Eastern European → 1250, 77 Mac → 10000, 254 PC / 255 OEM → 437, 128 Japanese → 932, 129 Korean → 949, 134 Simplified Chinese → 936, 136 Traditional Chinese → 950… None for the ANSI and default charsets (the document’s code page applies) and symbol fonts.
code_page_byte
A byte of 8-bit document text in code_page (see is_byte_code_page) as a char. Below 0x80 it is ASCII in every code page (text, so an OEM page’s glyphs for control codes don’t apply).
cp1252
One Windows-1252 byte as a char.
is_byte_code_page
Whether code_page_byte decodes code_page: a Windows one (SINGLE_BYTE_CODE_PAGES), an OEM (DOS) one (OEM_CODE_PAGES) or Mac OS Roman. Document formats (RTF) name all three.
is_multibyte_code_page
Whether code_page is one of the East Asian multibyte code pages (MULTIBYTE_CODE_PAGES): its bytes decode as a run, a lead byte together with its trail byte.
is_text_code_page
Whether a document format can name code_page for its text: a single-byte Windows, DOS or Mac one (is_byte_code_page) or an East Asian multibyte one (is_multibyte_code_page).
multibyte_encoding_name
The WHATWG encoding name of an East Asian multibyte code page (see MULTIBYTE_CODE_PAGES), for encoding_rs::Encoding::for_label; None for the single-byte code pages, whose bytes decode one at a time, and anything else.
oem_byte
One byte of an OEM code page in OEM_CODE_PAGES (any other code page reads as 437) as a char, with the graphic glyphs for 0x01..=0x1F and 0x7F (⌂); 0x00 stays NUL.
windows_byte
One byte of a single-byte code page as a char: a Windows one in SINGLE_BYTE_CODE_PAGES or Mac OS Roman (MAC_ROMAN_CODE_PAGE); any other code page reads as Windows-1252.
