Expand description

Page setup and section-level settings.

Fields§

§start: SectionStart§page_w: f32

Page width/height, points (already swapped for landscape).

§page_h: f32§landscape: bool§margin_top: f32§margin_bottom: f32§margin_left: f32§margin_right: f32§header: f32

Distance from the page edge to the header / footer.

§footer: f32§header_gap: f32

The space kept between a header and the body, and between the body and a footer, points (ODF’s header and footer spacing; Word keeps none). The margin already holds the band and its spacing, so it only moves the body once content and spacing reach past the margin.

§footer_gap: f32§gutter: f32§columns: Columns

Mirror margins (inside/outside) — set from the document settings.

§headers: HeaderSet§footers: HeaderSet§title_page: bool

Different first page header/footer.

§page_num_start: Option<u32>§page_num_format: NumFormat§chapter_style: Option<u8>

Chapter heading level and separator in w:pgNumType.

§chapter_sep: Option<ChapterSep>§page_num_set: bool

The file carries a w:pgNumType element that sets nothing else (no start, decimal format), so saving writes it back rather than dropping it.

§line_numbers: Option<LineNumbering>§valign: PageVAlign§form_prot: Option<bool>

Form protection of the section (w:formProt, ECMA-376 §17.6.6): Some when the file states it. Kept so saving writes it back; editing does not act on it.

§page_borders: Option<Borders>§rtl: bool

Text direction / bidi section.

§text_direction: TextDirection

Which way the section’s text runs (w:textDirection, ECMA-376 §17.6.20): vertical sections turn the page’s text area (headers and footers stay horizontal).

§text_direction_set: bool

The file states the horizontal direction (lrTb) outright; saving writes it back.

§fmt_change: Option<Box<PropChange<SectionProps>>>

Tracked change of the section’s properties (w:sectPrChange).

§doc_grid: Option<DocGrid>

Document grid (w:docGrid); None when the file has none (no grid).

§footnote_pr: NoteProps

The section’s own footnote and endnote options (unset: the document’s).

§endnote_pr: NoteProps§paper_src_first: Option<u16>

First-page and other-page printer trays (w:paperSrc).

§paper_src_other: Option<u16>§no_endnote: Option<bool>

Section-specific suppression of endnotes (w:noEndnote).

§footnote_columns: Option<u32>

Independent footnote column count (w15:footnoteColumns).

§balance_columns: Option<bool>

Whether its columns end balanced (an ODF section’s text:dont-balance-text-columns): None is Word’s rule, balanced when a continuous section follows; Some(true) also at the end of the document, Some(false) never.

pub fn absorb(&mut self, before: &SectionProps)

Join the section before this one into it, as when the break between them is deleted: this section’s setup stays, as in Word, and the headers and footers it leaves out (linked to the previous section) are taken from before, so its text keeps showing them.

pub fn column_boxes(&self) -> Vec<(f32, f32)>

Column (x offset from the text area’s left, width) for each column, in reading order: in a right-to-left section (rtl, w:bidi) the first column stands at the right edge and the columns (with the space after each) run leftwards.
