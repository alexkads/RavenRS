Expand description

A number format (ECMA-376 §17.18.59 ST_NumberFormat). Every value the format defines is kept, so a document saves back the format it was opened with even where WordCraft draws it as plain decimal (see NumFormat::format).

impl NumFormat

Source

pub const ALL: [NumFormat; 62]

Every format, in the order ST_NumberFormat lists them (which is also the order of the binary .doc number format codes up to 0x27).

Source

pub fn ooxml(self) -> &'static str

Source

pub fn from_ooxml(s: &str) -> NumFormat

The format an ST_NumberFormat value names; a value the format doesn’t define is decimal (as Word shows it). So is custom (a Word 2010 format string, always written with a decimal fallback).

Source

pub fn format(self, n: u32) -> String

Format n (1-based). Formats WordCraft doesn’t draw yet (Hebrew, Hindi, Thai letters and counting, Vietnamese, text amounts) show decimal, as do values past a sequence’s end (the 21st item of ①…⑳). Thai numbers are the decimal number in Thai digits (๑, ๒ … ๑๐).
