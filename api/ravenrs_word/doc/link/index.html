Hyperlink targets: where a HYPERLINK field code points, and which targets may leave the document: followed by the OS, or written into an exported HTML/Markdown file where a browser would run them.

Functions§

hyperlink_target
Where a HYPERLINK field code points, as a w:hyperlink reads: url, url#bookmark (\l) or #bookmark. None for any other field, or one with no target.
is_safe_href
Whether a hyperlink may be written as an href (or Markdown destination, RTF HYPERLINK field, ODT xlink:href, LaTeX \href) in an exported file: a web or email link, a bookmark (#name) or a relative path. Scripts (javascript:, vbscript:), data:, file: and every other scheme are refused, read the way a browser reads a URL: ASCII control characters and spaces are dropped first, so java\nscript: is a script. A protocol-relative reference (//host/…) or a UNC path (\\host\…, or //host once backslashes are read as separators) names another machine — following it on Windows leaks the user’s NTLM credentials — so it is refused too.
is_web_or_mail_link
Whether Ctrl/⌘+click may hand a document’s hyperlink to the system: web and email links only, so a document can’t launch file: paths, programs or custom-scheme handlers. Exact: a leading space or a control character makes it not a link.
