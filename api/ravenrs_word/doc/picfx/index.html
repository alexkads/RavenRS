Module picfx 

Source
Expand description

Picture colour corrections read from a file: brightness, contrast and transparency (DrawingML a:lum and a:alphaModFix inside a:blip, ECMA-376 §20.1.8.42 and §20.1.8.4; VML v:imagedata gain and blacklevel, which Word’s picture watermark “Washout” sets).

Values are kept in OOXML units: thousandths of a percent, so 100 000 is 100 %. All zero is the picture as it is.

The pixel formula was measured on Word (#1711, #1766): Word bakes the corrected pixels into the picture it embeds in a PDF export, so a synthetic grey and colour ramp exported with 20 a:lum combinations and 6 VML gain/blacklevel pairs gives the curve. Every channel is mapped on its own (no hue or luminance coupling) by one straight line, clamped to 0..=255 only at the end:

y = s·(x − 127.5) + 127.5 + 127.5·b·(1 + s), with b = bright / 100 000, c = contrast / 100 000, s = 1 + c when c ≤ 0 and s = 1 / (1 − c) when c > 0

(as if half the brightness shift were applied before the contrast and half after). Measured slope and intercept of Word’s output for grey input x (PNG pictures, exact to ±1 level): bright 20 000 → 1.00, +51; bright −40 000 → 1.00, −103; contrast 80 000 → 5.00, −510; contrast −80 000 → 0.20, +101.4; (40 000, −40 000) → 0.60, +132.2; (80 000, −80 000) → 0.20, +223.8 (also the #1766 header picture: fitted 0.197..0.201, +223.6..224.0); (−40 000, 40 000) → 1.667, −221.7; (30 000, 60 000) → 2.50, −57.8.

VML: gain is the slope itself and blacklevel half the brightness — Word draws gain 0.3, blacklevel 0.35 (Washout) as 0.30, +205.3, the same as a:lum (70 000, −70 000), and gain 1, blacklevel 0.2 as the very same picture as bright="40000".
