pub fn split_off(&mut self, at: usize) -> Table

Split the table before row at: the rows from at on move to the returned table, which has this table’s properties and grid. A vertical merge that the split cuts ends in this table’s last row and starts again in the new table’s first row. A row content control around rows on both sides closes after this table’s last row and opens again (without its w:id) before the new table’s first row. Content controls that close after this table close after the new one.

pub fn split_cell(&mut self, r: usize, c: usize, n: usize) -> Vec<usize>

Split cell c of row r into n cells horizontally. Where the cell’s grid lines don’t fall on the equal parts, the grid is refined inside the cell only: the new borders divide it into equal parts, and the cells of other rows widen over the new grid columns, so their extent and the table’s width stay as they were. Returns the parts’ spans, left to right.

pub fn vertical_extent(&self, r: usize, c: usize) -> Option<(usize, usize)>

The rows cell c of row r covers: (first row, count). A vertically merged cell runs from its Restart cell down through the Continue cells that start at the same grid column.

Source

pub fn split_cell_grid( &mut self, r: usize, c: usize, cols: usize, rows: usize, ) -> bool

Split Cells: cut cell c of row r into cols × rows cells. A cell one row high gets rows - 1 new rows under it, over which the row’s other cells merge down; a vertically merged cell is regrouped instead, so rows must divide its height. The content stays in the first part. Returns false (with the table unchanged) when the split can’t be made.
