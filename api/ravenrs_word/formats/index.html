Module formats 

Source
Expand description

WordCraft import/export for the “other” text formats: plain text, Markdown (CommonMark subset plus GFM tables and strikethrough), HTML (and MHT web archives, read-only), RTF, OpenDocument Text and LaTeX — and, read-only, spreadsheet cells for mail-merge recipient lists (sheet: .xlsx/.xlsm/.xls/.ods).

Every format maps to a small flow model (model::Flow: paragraphs with a kind, list membership, alignment and formatted spans; tables of cells), which model::to_doc and model::from_doc convert to and from the full Document. All parsers are written from the public specifications, are lenient by design and never panic on hostile input: nesting is depth-limited and sizes are capped.

mathml
Equations as MathML (W3C MathML Core / Presentation MathML): written into HTML export and the HTML a copy puts on the system clipboard, so programs that read MathML can get a formatted equation instead of its linear text (#816); for a copy of one equation alone, the text of the platform’s MathML clipboard formats, which Word reads first when it pastes math (#1297; pasting into Word and LibreOffice not yet verified); and read back from pasted or opened HTML.
mht
MHT / MHTML (Single File Web Page): a web page and its pictures in one MIME message (RFC 2557 multipart/related, RFC 2045 transfer encodings). The page is the part the message’s start parameter names, else its first HTML part; it is read by crate::formats::html, with img sources found among the other parts by Content-Location (also relative to the page’s) or cid: Content-ID, and the page opens as Word opens one (crate::formats::html::import_page). Word keeps HTML w:altChunks in this form too.
model
A small “flow” model every text format maps to and from: paragraphs with a kind (heading, quote, code…), list membership, alignment and formatted inline spans; tables of cells holding blocks. to_doc and from_doc convert between it and the full Document.
odt
OpenDocument Text (.odt, ODF 1.3).
rtf
Rich Text Format.
sheet
Spreadsheets as mail-merge recipient lists (#334): the sheet names of an Excel workbook (.xlsx / .xlsm, ECMA-376 Part 1 §18 SpreadsheetML; legacy .xls BIFF8 in [xls], #778) or an OpenDocument spreadsheet (.ods, OASIS ODF 1.3 §9.1), and one sheet’s cells as rows of display strings.
txt
Plain text: UTF-8 (with or without BOM), UTF-16 LE/BE (BOM or sniffed), else the legacy encoding the bytes look like (GBK/GB18030, Big5, Shift_JIS, EUC-KR, Windows code pages…; #778), Windows-1252 when nothing fits better. Export writes UTF-8 with CRLF line ends; list paragraphs get their label and a tab, table cells are separated by tabs.
