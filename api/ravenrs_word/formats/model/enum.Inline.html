§

Anchor(String)

A bookmark (link target).

§

AnchorEnd(String)

Where bookmark name, started by an Inline::Anchor before it, ends: the bookmark covers the text between. Only flows asked for fields (FlowOpts::fields) hold them; an anchor without one is a point.

§

Figure(String)

A chart or diagram known here only by its alt text: written where alt text has a place (an HTML or Markdown image), left out of editable formats so it never turns into body text.

§

Chart(Chart)

A chart WordCraft can edit, w × h points: only in flows asked for boxes (FlowOpts::boxes); others get its alt text as an Inline::Figure.

§

Control

A content control holding plain text (a form control in ODT): only in flows asked for boxes (FlowOpts::boxes); others get its text.

Fields

§control: Box<ContentControl>
§text: String
§fmt: Fmt
§

Equation

An equation in the linear format WordCraft keeps them in (x=(-b±√(b^2-4ac))/2a). Formats without equations write linear as text.

Fields

§linear: String
§display: bool
§

Ruby

Ruby (phonetic guide): ruby text (furigana, pinyin…) over base text, in the formatting of the run it sits in (#1681). Formats without ruby write the base text (ruby_as_text).

Fields

§base: String
§ruby: String
§fmt: Fmt
§

Field

A field (page number, date, document property, cross-reference): its Word field code (PAGE, REF name \h…) and the result it last showed, in its run’s formatting. Only flows asked for fields (FlowOpts::fields) hold them; formats without fields write the result as text.

Fields

§instr: String
§result: String
§fmt: Fmt
§locked: bool

Its result is kept, not worked out again (Word’s locked field, ODF’s text:fixed).

§

Note

A footnote or endnote: its custom mark (empty: numbered) and its content, without the note’s own mark. Only flows asked for notes (FlowOpts::notes) hold them; formats without notes leave them out.

Fields

§endnote: bool
§custom: String
§blocks: Vec<FBlock>
§fmt: Fmt

The reference’s own formatting (beyond the note reference style).

§

Comment

Where comment id (the flow’s own number for it) starts, and the comment. A reply (FComment::parent) has no range: it only follows its comment. Only flows asked for comments (FlowOpts::comments) hold them.

Fields

§id: u32
§comment: Box<FComment>
§

CommentEnd(u32)

Where comment id’s range ends.

§

Shape

A drawing shape or text box: its kind, its size in points, its placement when it floats, its text (none for a shape without), and its look. Only flows asked for them (FlowOpts::boxes) hold them.

Fields

§kind: ShapeKind
§w: f32
§h: f32
§float: Option<Box<Float>>
§blocks: Vec<FBlock>
§look: BoxLook
§path: Option<Arc<Freeform>>

A freeform’s paths (crate::doc::para::ShapeKind::Freeform).

§

FieldStart(String)

The start of a field whose result is the content after it, up to the matching Inline::FieldEnd (a table of contents around its entries); its field code. Only flows asked for fields (FlowOpts::fields) hold them.

§

FieldEnd

The end of the innermost Inline::FieldStart.

§

Group

Drawing shapes, text boxes and pictures grouped into one object: its size in points, its placement when it floats, and its members, each at its offset in the group. Only flows asked for shapes (FlowOpts::boxes) hold them.

Fields

§w: f32
§h: f32
§float: Option<Box<Float>>
§members: Vec<Member>
