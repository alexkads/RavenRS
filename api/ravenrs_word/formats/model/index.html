ravenrs_word::formats

Module model 

Source
Expand description

A small “flow” model every text format maps to and from: paragraphs with a kind (heading, quote, code…), list membership, alignment and formatted inline spans; tables of cells holding blocks. to_doc and from_doc convert between it and the full Document.

Modules§

odf_object
ODF embedded objects (OdfObject) in a document: their files in Document::passthrough under odf-object/<n>/, linked from the picture showing them by an Embedded whose markup only names the object’s media type, and taken back out for the ODT writer. Other formats see the picture alone.
