Module txt

Expand description

Plain text: UTF-8 (with or without BOM), UTF-16 LE/BE (BOM or sniffed), else the legacy encoding the bytes look like (GBK/GB18030, Big5, Shift_JIS, EUC-KR, Windows code pages…; #778), Windows-1252 when nothing fits better. Export writes UTF-8 with CRLF line ends; list paragraphs get their label and a tab, table cells are separated by tabs.

Decode text bytes: BOMs first, then UTF-16 without BOM (by its zero bytes), UTF-8, and the legacy encoding the bytes look like (legacy) as the last resort.

Decode bytes in a named encoding (a WHATWG label such as gbk, gb18030, big5, shift_jis, euc-kr, utf-16le, windows-1251); None when the label isn’t known.

is_text
Does b look like plain text, so a file with an extension WordCraft doesn’t know (a playlist, a log, a config file…) can open as text the way Word’s text import opens it?
legacy
Bytes that aren’t UTF-8 in the legacy encoding they look like (chardetng, the detector Firefox uses for unlabelled pages): GBK/GB18030 for Simplified Chinese, Big5, Shift_JIS or EUC-JP, EUC-KR, or a single-byte Windows / ISO code page; Windows-1252 as before when the guess is a single-byte Western one.
