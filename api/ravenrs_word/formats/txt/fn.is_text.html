pub fn is_text(b: &[u8]) -> bool
Expand description

Does b look like plain text, so a file with an extension WordCraft doesn’t know (a playlist, a log, a config file…) can open as text the way Word’s text import opens it?

Text has a BOM, or reads as UTF-16 by its zero bytes, or has no NUL byte and next to no other control characters in its first 64 KB. PDFs are refused by their signature (they start as text). An empty file is text.
