Module markdown 

Source
Expand description

Markdown: a CommonMark subset plus GitHub tables and strikethrough.

Import: ATX and setext headings, paragraphs with soft/hard breaks, block quotes (→ Quote style), fenced and indented code (→ one Code paragraph per line), thematic breaks (→ a bottom-border paragraph), bullet and ordered lists (nested by indentation), GFM pipe tables, and inlines: emphasis/strong (the CommonMark delimiter algorithm), ~~strike~~, code spans, inline links, autolinks, images (data: URIs become pictures, others their alt text), backslash escapes, entities, HTML comments (<!-- ... -->), <br> and <a id> anchors.

Export writes the same constructs; pictures become ![alt](media-name) placeholders.
