Headless word-processing engine for RavenRS.

The layers, from the bottom up:

  • geom: lengths, points, rectangles and colours shared by the others.
  • doc: the document model: stories of paragraphs and tables, runs, styles, lists, sections, fields, notes, comments and tracked changes, with cheap Arc-shared clones.
  • metafile: WMF and EMF pictures read into vector paths.
  • docx: DOCX (WordprocessingML) reading and writing, including password-protected files.
  • docbin: the binary Word 97-2003 .doc format, read-only.
  • formats: plain text, Markdown, HTML and MHT, RTF, OpenDocument Text and LaTeX, and spreadsheet cells for mail-merge recipients.
// Markdown in, DOCX out, and back again.
let document = ravenrs_word::formats::import("md", b"# Letter\n\nDear *reader*,").unwrap().unwrap();
let docx = ravenrs_word::docx::write(&document).unwrap();
let again = ravenrs_word::docx::read(&docx).unwrap();
let markdown = ravenrs_word::formats::export("md", &again).unwrap().unwrap();
assert!(String::from_utf8(markdown).unwrap().contains("Letter"));

Nothing here lays out pages, draws or depends on a window, so it also runs on servers and in WebAssembly. The engine comes from WordCraft (MIT OR Apache-2.0); see NOTICE.

WordCraft document model.

WordCraft reader for the Word 97-2003 binary file format (.doc, [MS-DOC]).

WordCraft DOCX reader and writer (ECMA-376 / ISO/IEC 29500 WordprocessingML).
formats
WordCraft import/export for the “other” text formats: plain text, Markdown (CommonMark subset plus GFM tables and strikethrough), HTML (and MHT web archives, read-only), RTF, OpenDocument Text and LaTeX — and, read-only, spreadsheet cells for mail-merge recipient lists (sheet: .xlsx/.xlsm/.xls/.ods).
geom
WordCraft geometry and units.
metafile
WordCraft metafiles: reads Windows Metafiles (WMF) and Enhanced Metafiles (EMF) into a neutral vector model of filled and stroked paths, RGBA bitmaps and text runs, in a picture frame with y down.
