Expand description

A region: a language and a territory, read from a locale tag like pl-PL, de_AT.UTF-8 or en-US. The default is en-US (Letter, inches, decimal point).

Fields§

§language: String

Lower-case language subtag (pl); empty when the tag has none.

§territory: String

Upper-case territory (PL, or a UN M.49 number like 419); empty when the tag has none.

§letter: Option<bool>

US Letter or not, when a separate paper locale says so (Unix LC_PAPER); otherwise the territory decides.

§inches: Option<bool>

Inches or not, when a separate measurement locale says so (Unix LC_MEASUREMENT); otherwise the territory decides.

impl Region

pub fn from_tag(tag: &str) -> Region

The region a BCP 47 or POSIX locale tag names (pl-PL, pl_PL.UTF-8@euro, zh-Hans-CN, en-US-u-ms-metric). An empty or unreadable tag, C and POSIX are en-US; a bare en is the United States, any other bare language has no territory.

Source

pub fn with_territory(self, territory: &str) -> Region

This region with another territory (from a platform setting that names only the territory, like Windows’ home location). A value that isn’t a territory code is ignored.

Source

pub fn with_paper_and_measurement( self, paper: Option<&str>, measurement: Option<&str>, ) -> Region

This region with the paper and the measurement system taken from their own locale tags, when the platform sets them apart (Unix LC_PAPER, LC_MEASUREMENT): LANG=pl_PL.UTF-8 with LC_PAPER=en_US.UTF-8 writes 2,54 cm on Letter.

Source

pub fn from_locale_vars( var: impl Fn(&str) -> Option<String>, platform: impl FnOnce() -> Option<String>, ) -> Region

The system region from the locale variables var reads (the process environment) and, when none is set, the platform’s first preferred locale platform gives. One tag for everything first (WORDCRAFT_REGION, then LC_ALL); otherwise Unix sets each convention on its own: numbers (LC_NUMERIC, else LANG), paper (LC_PAPER) and measurement (LC_MEASUREMENT). Empty, C and POSIX values count as unset.

Source

pub fn uses_letter(&self) -> bool

Does a new document start on US Letter here (otherwise A4)?

pub fn paper(&self) -> (&'static str, f32, f32)

The default paper’s name and portrait size in points: Letter (612 × 792) or A4.

Source

pub fn units(&self) -> Unit

The unit lengths are shown in by default: inches in the US, centimetres elsewhere.

The decimal separator numbers are written with here (, or .).

pt in unit written the way this region writes numbers (2,54 cm in Poland).
