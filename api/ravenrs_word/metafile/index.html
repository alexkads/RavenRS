Module metafile 

Source
Expand description

WordCraft metafiles: reads Windows Metafiles (WMF) and Enhanced Metafiles (EMF) into a neutral vector model of filled and stroked paths, RGBA bitmaps and text runs, in a picture frame with y down.

The reader is pure Rust over byte slices (no file system), so it builds for wasm. Every read is bounds-checked and every count is capped; hostile input yields a shorter picture or an Error, never a panic.

Records follow MS-WMF and MS-EMF. Records outside the supported set are skipped silently.

crop_window
The part of a picture’s source that crop (left, top, right, bottom fractions of the source) keeps, as fractions of the source: [left, top, width, height], bitmap or metafile alike. Each side is taken as 0–1 (junk as 0). When the two sides of an axis leave less than 0.5% of it, the left (top) side stands and 0.5% shows.
