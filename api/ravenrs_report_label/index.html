Crate ravenrs_report_label 

Source
Expand description

From a report to a label printer. A Document becomes a 1-bit bitmap at the printer’s resolution, and the bitmap travels inside the printer’s language. The layout is the one made in the designer, so it comes out the same on every brand, accents included.

Barcode bars are laid on whole dots, never scaled. A code that cannot keep its minimum module on the label gives a LabelError instead of a label no scanner reads.
