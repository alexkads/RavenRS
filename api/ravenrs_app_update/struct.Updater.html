Struct Updater 

Source 
pub struct Updater { /* private fields */ }
Expand description

Checks for updates and runs the installer on background threads. When one finishes it wakes the UI, whose next build calls Updater::poll.

Implementations§

impl Updater

Source

pub fn tray_entries(&self) -> Vec<TrayEntry>

The entries for the menu beside the clock: the version to install, the one installing with its step, the one ready (“Reiniciar para atualizar / Versão X pronta”), and its news. Empty when there is nothing to say. Put them in the app’s TrayMenu on each build.

Source

pub fn tray_select(&self, id: &str) -> Option<TrayChoice>

Does what an entry of Self::tray_entries says, as the status bar’s buttons do, and says whether id was one of them. TRAY_NEWS only opens the window (its id starts with open:) and returns TrayChoice::News, for the app to show the news there.

impl Updater

Source

pub fn idle(app: &'static InstalledApp) -> Self

An updater for app that does nothing until asked; tests use this one, and the app calls Self::watch on it once its window is open.

Source

pub fn connect(&self, rebuild: impl Fn() + Send + Sync + 'static)

Gives it what asks the screen to build again, from any thread (with RavenRS, cx.ui_waker() and its wake), and runs a check that was waiting for it. Only the first one given is kept.

Source

pub fn watch(&self)

Looks now and every hour from now on, silently unless there is a version.

Source

pub fn ask(&self)

Someone asked: says it is looking, and answers even when there is nothing new. Asking again brings back a version hidden with “Depois”. An update under way already is the answer, so it stays.

Source

pub fn stage(&self) -> Option<String>

The step the installer was on, as it last said.

Source

pub fn dismiss(&self)

Hides the notice. A version stays hidden for this session; an answer is just gone.

Source

pub fn timeline(&self) -> Vec<News>

Every version known, newest first: the announced one, the repository’s and this copy’s.
