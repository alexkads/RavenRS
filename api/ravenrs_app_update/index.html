Installing, updating and versioning a RavenRS app by compiling it on the user’s machine.

The app reads novidades.json from the main branch. When that version is newer than the running one, it says what changed and runs the installer, which downloads the code and compiles it. Nothing that works gets touched:

StepIf it fails
download the installer to a file and check it is wholenothing was touched
compile in a folder of its ownnothing was touched
run the new binary with --versao before swappingnothing was touched
the installed app becomes .anterior, the new one moves inthe installer puts the old one back
the app checks the version of the installed binarythe status bar says so; the open app goes on

Releasing is one commit: the version in Cargo.toml, novidades.json and the same entry on top of historico-de-novidades.json, with contribuidores naming who made it and issues the issues it closes. assert_release_files_agree holds the three together.

The installer is saved to a file and never piped into a shell: a failed curl | sh hands sh an empty script, which exits successfully having done nothing.

The app looks when it opens and every hour after that, silently: notice only speaks when there is a version, or when someone asked and is waiting for an answer.

Who the app is, its folders and its addresses, is an InstalledApp; nothing here knows any app. The README says how an app adopts it. The crate draws nothing: the app shows Notice and News with its own components.
