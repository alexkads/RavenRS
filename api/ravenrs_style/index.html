Design tokens and themes.

Every value here mirrors docs/design-system/tokens.json, the source of truth that is also published as the RavenRS design system. Components never hard-code colors or sizes: they ask the Theme for a semantic token.

Shadow tokens (shadow-*).

Motion tokens: how long things take and how they move.
Palette
The color tokens of one theme.
Radii
Corner radii (radius-* tokens).
Spacing
The 4px spacing grid (space-* tokens).
Theme
A complete theme: palette plus the shared scales.

One step of the type scale.
Typography
The type scale: one TypeStyle per TextStyle.
Weight
Font weight on the CSS 1–1000 scale.

Enums§

Material
What surfaces are made of. Glass surfaces are translucent and ask the renderer for a backdrop blur where available.
Semantic
Semantic color roles. Widgets refer to roles, never to raw colors, so every component follows the active theme.
TextStyle
Named steps of the type scale.
