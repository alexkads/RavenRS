Synthetic data for testing a reusable ravenrs-app module, as docs/APP-CONTRACTS.md describes it: two organizations, T1 and T2, that use the same local keys on purpose, so that mixing one with the other shows; units and people in each; example roles; and a clock that moves only when a test says so; and a destination for events that answers as the test asks.

Each organization keeps its records apart, in memory or in a SQLite file of its own. Nothing here belongs to a sector: the module under test brings its own entities, and the roles are an example policy of the test, not profiles built into RavenRS.

use ravenrs_app::{Identity, ObjectSpace, Query};
use ravenrs_app_testkit::{Fixture, PERSON, roles};

let fixture = Fixture::memory(Vec::new()).unwrap();
let registrar = Identity::new("op", "op", vec![roles::registrar("U1")]);
let space = fixture.t1.space_as(registrar);
let people = space.query(PERSON, &Query::all()).unwrap();
assert_eq!(people.len(), 1); // only the person of U1
