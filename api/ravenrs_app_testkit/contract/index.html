Expand description

The contract every ObjectSpace adapter keeps, as a battery any adapter runs with one call: SQLite, PostgreSQL, PostgREST and the ones to come behave the same before they are called supported.

An adapter says how to make fresh storage for a case, and how to reach the same storage a second time, as another program would. Each case makes its own entities and storage and does not depend on the order of the others. What an adapter does not guarantee is declared in its Capabilities, and the case then checks that it fails the declared way, never that it passed.

use ravenrs_app::{EntityInfo, MemoryDatabase, ObjectSpace, SpaceMaker};
use ravenrs_app_testkit::contract::{self, Adapter, Capabilities, Store};
use std::rc::Rc;

struct Memory;
impl Adapter for Memory {
    fn name(&self) -> &str {
        "memory"
    }
    fn capabilities(&self) -> Capabilities {
        Capabilities::MEMORY
    }
    fn open(&self, _case: &str, entities: &[EntityInfo]) -> Result<Store, String> {
        let database = MemoryDatabase::new(entities.to_vec()).map_err(|e| e.to_string())?;
        let space: SpaceMaker = Rc::new(move || Box::new(database.space()) as Box<dyn ObjectSpace>);
        Ok(Store { space: space.clone(), again: space })
    }
}

let report = contract::run(&Memory);
assert!(report.passed.len() > 10);
