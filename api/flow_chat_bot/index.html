Crate flow_chat_bot 

Source
Expand description

An automation builder for chat conversations, made only with FlowCanvas, FlowToolbox and FlowInspector: a trigger starts the conversation, messages offer buttons, each button leads somewhere, conditions split the way and actions reach other systems.

It validates the component as a builder of this kind: everything here is the library’s, and what it could not do is written in the README.
