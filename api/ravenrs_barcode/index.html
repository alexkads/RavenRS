Barcodes: turns text into the modules a scanner reads, and checks GTIN numbers. Pure logic and nothing about drawing, so screens, reports, label printers and fiscal documents all agree on what a code is.

Constants§

QUIET_LINEAR
Empty modules on each side of a linear code, which scanners need. An EAN-13 asks for the most, 11 on its left, and the same on every side and format keeps them all readable.
QUIET_MATRIX
Empty modules around a QR Code, as its standard asks.
