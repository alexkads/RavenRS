Nodes of a flow that call the coding agents installed on the computer, the Codex CLI and the Claude CLI, through ravenrs-process.

The app never holds the login: the CLI keeps it. A node reads only by default, and every limit it is given (only reading, the tools it may use, a budget) is checked against what the installed CLI says it can do (its --help), so a limit the CLI does not keep is refused before anything runs, never ignored. The events the CLI writes (JSON lines) are read into AgentEvents, with the values of secret variables taken out, and kept with the node’s answer.
