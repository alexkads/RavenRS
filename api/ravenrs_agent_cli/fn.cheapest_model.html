The cheapest model of an agent, for work that does not need its best one, such as running a test and reading its report.

For Codex it is read from the list of models the installed CLI keeps ($CODEX_HOME/models_cache.json, ~/.codex by default; see cheapest_codex_model_in), so a new generation is picked up without a new build; None when there is no list. For Claude it is haiku, the alias the CLI resolves to its smallest model.
