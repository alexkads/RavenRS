Peripherals as data. A driver is a signed JSON manifest that says exactly which device model it is for, how it is connected, what protocol it speaks and which few bytes differ on that model. It never carries code, so an update can only change values this crate has checked.

Registro holds the installed versions and which one is active. A Catalogo offers newer ones. Nothing updates by itself: a person accepts an Atualizacao and can go back.

No driver here was tested on a real device. Situacao says so for each one.
