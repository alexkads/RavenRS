Crate channel_video 

Source
Expand description

The videos of the project’s channel, recorded from the real apps.

cargo run --release -p channel-video -- record OUT
FF_AI_MODELS=~/.raven-financas/modelos cargo run --release -p channel-video -- narrate OUT --voz pm_santa
cargo run --release -p channel-video -- export OUT

record writes the films, narrate records what their boxes say with the local Kokoro voice (--voz chooses pf_dora, pm_alex or pm_santa, the default), and export writes the wide and the vertical video, the subtitles, the chapters for the description and a cover. frames OUT 0:6000 draws single moments (film:ms) as pictures, to look at before exporting.
