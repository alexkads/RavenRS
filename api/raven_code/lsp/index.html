Module lsp 

Source
Expand description

Talking to a language server (rust-analyzer) over the Language Server Protocol: what is wrong while typing, suggestions, tips and where things are defined. It speaks JSON-RPC over any pair of streams, so tests talk to a fake server through pipes, with no rust-analyzer.

Requests go out at once and answers come on a thread of their own; the screen reads the last answer of each kind, and wake is called when one arrives.
