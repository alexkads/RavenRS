Module intpos 

Source
Expand description

PayGo Windows and the standard manager, through files. Only files: no unsafe, no library.

The steps are always these: write req/intpos.tmp, rename it to req/intpos.001, wait for resp/intpos.sts, which says the manager took it, then wait for resp/intpos.001. The manager talks to the operator and the pinpad on its own window, which is why no question reaches ours.

Never run against a real manager, and those are Windows programs. Only GerenciadorSimulado was run. Field numbers come from the public PayGo pages and from reading the behavior of an LGPL implementation; see docs/PAGAMENTOS.md.
