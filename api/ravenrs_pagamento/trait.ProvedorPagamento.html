Expand description

A payment provider, in the terms that serve all of them.

The flow never blocks on the customer: iniciar and continuar return a Passo saying what the screen does next. That covers the iterative questions of CliSiTef, the polling of an HTTP order and the wait for an IntPos file with the same two calls. estornar may block up to the provider’s limit.

Providers with no third leg treat confirmar as a no-op that is never called, and answer ErroProvedor::SemSuporte to desfazer.
