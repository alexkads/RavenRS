The contract of the helper process: how a library with unsafe stays out of this workspace.

The workspace forbids unsafe, and CliSiTef and Stone TEF only exist as native libraries. So a separate binary, outside this workspace, loads the library. It speaks one JSON per line: it reads a PedidoAuxiliar from stdin and writes one RespostaAuxiliar to stdout, with logs on stderr. A crash there does not take the point of sale down, and it may be 32-bit if the library is.

ProvedorAuxiliar is the side of the workspace. atender is the side of the helper, for any ProvedorPagamento: the real helper only implements that trait over the library, using crate::sitef::CicloSiTef. The helper with FFI does not exist yet; docs/PAGAMENTOS.md describes it. Only a simulated helper was run.

The answer of the operator crosses the pipe, and neither side may log it.
