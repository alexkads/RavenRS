Struct Pagamentos 

Source 
pub struct Pagamentos<P, D> { /* private fields */ }
Expand description

Payments through one provider and one journal.

Each line goes to the journal before its effect. An intention is written before the provider is called, and a transition before the state changes in memory. If the journal fails, the call stops there with an error. Use one journal per provider.

Ends an approved payment: confirms if the sale finished, and otherwise undoes it.

pub fn recuperar(&mut self) -> Result<Vec<Recuperacao>, ErroPagamento>

Settles everything left open by a power loss, a crash or an earlier session.

The rule: a written decision is carried out, and without one an approval whose sale did not finish is undone. With no third leg nothing can be undone, so it is reported as Desfecho::CobradoSemConclusao for the application to decide. It is safe to call this again at any moment, also after a new power loss halfway through it.
