The iterative loop of CliSiTef as a pure translation, with no library in sight.

The real helper process calls IniciaFuncaoSiTefInterativo and then ContinuaFuncaoSiTefInterativo while it returns 10000. Each round gives a command, a field type, limits and a buffer. CicloSiTef turns one round into what the screen must do, and collects the fields of the answer. The helper only has to move bytes between this and the library.

Field and command numbers were checked against the behavior of the LGPL unit ACBrTEFCliSiTefComum and the public Fiserv pages; see docs/PAGAMENTOS.md. Never run against a real CliSiTef or against SitDemo. What field 951 holds in practice is not confirmed.
