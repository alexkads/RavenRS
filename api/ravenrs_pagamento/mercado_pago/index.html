Mercado Pago Point through the Orders API.

Never run against the real service: we have no account. Written from the public documentation and tested against fixtures of ours that follow its examples. The documentation says the access token must stay on a backend, and webhooks need a public address, so a real deployment needs a server of its own in front of this (see docs/PAGAMENTOS.md). Point machines are not pinpads.

The documented order has no authorization code. So cAut comes out empty, with AlertaFiscal::CAutAusente, and reference_id is not used in its place: nothing says it is the number printed on the receipt.
