Stone: the fiscal data of Connect 2.0, and AutoTEF over local HTTP.

Stone has more than one product and they work differently:

  • Connect 2.0: an order in the Pagar.me API goes to an Android machine, not a pinpad. It has no sandbox, a webhook is mandatory, and there is no refund route. Only dados_de_charge_paid exists here, for the server that receives the webhook.
  • TEF Stone: a native library, reached through crate::auxiliar.
  • AutoTEF: AutoTef. NOT CONFIRMED: its documentation answered 403. Everything here comes from third-party code that integrates with it, so even the existence of the product today is unknown. Field names and units may differ. Nothing has run against the real one.
