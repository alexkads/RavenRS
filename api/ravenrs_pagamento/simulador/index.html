Module simulador 

Source
Expand description

A provider in the style of MSW: the application does not know it was intercepted.

With no handler of yours, it behaves as a small real provider with a ledger: it approves, holds the approval until the third leg, undoes, refunds and answers queries about all that. It is fully deterministic: no clock, no randomness, numbers from counters.
