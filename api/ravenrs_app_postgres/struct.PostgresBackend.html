Struct PostgresBackend

pub struct PostgresBackend { /* private fields */ }
Expand description

A connection to PostgreSQL.

Made from a [Client] you opened, or with PostgresBackend::connect from the address a database’s panel gives. One made from an address is opened again by itself when it dropped while no transaction was open, as a database that went to sleep leaves it. A statement already sent is never sent again, unless it only reads.
