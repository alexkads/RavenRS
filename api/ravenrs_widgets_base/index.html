Crate ravenrs_widgets_base 

Source
Expand description

The base of the RavenRS widgets: the runtime (Ui, BuildCx, View), motion, the services the platform provides, and the basic controls every other component is made of.

Applications depend on ravenrs-widgets (or ravenrs), which re-exports all of this by the same names. The modules are public only so the crates of the components can reach the parts they share; they are hidden from the documentation and are not a stable API.
