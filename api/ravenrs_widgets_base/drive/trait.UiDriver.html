Expand description

Drives a window’s Ui from outside, on the platform’s thread. See the module.

Required Methods§

Source

fn start(&mut self, wake: Box<dyn Fn() + Send + Sync>)

Called once, when the window is on screen: wake asks the platform for a turn, from any thread, and a turn follows at once, so the driver may answer that it is ready here.

Source

fn drive(&mut self, ui: &mut Ui, now: f64) -> Driving

A turn: runs what the driver has waiting on ui, whose clock reads now seconds, and says who is in control next. The platform draws the frame after it.

Provided Methods§

Source

fn time(&mut self, now: f64) -> f64

The interface’s clock while the driver is in control, given the real one (now, seconds since the app started): the real one by default. A test tool holds it between its steps, so a pause to watch the test does not let a notice expire that the next step checks.

Source

fn window_closed(&mut self)

The person closed the window while the driver was in control; the app ends after this returns. A test tool says so to whoever is waiting for a step.
