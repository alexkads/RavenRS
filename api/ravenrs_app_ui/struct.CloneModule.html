Struct CloneModule 

Source 
pub struct CloneModule { /* private fields */ }
Expand description

Clones what its entity says can be: what a record holds comes along, a reference points to the same record, and only a list marked as belonging to the record is cloned with it. Everything else is left out, so it does not copy a whole graph by accident.
