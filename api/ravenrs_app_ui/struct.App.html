Struct App

pub struct App { /* private fields */ }
Expand description

An application from its records: the module with the actions every application needs, the screens, and records in memory unless told otherwise.

use ravenrs_app::{BusinessObject, ObjectSpaceExt};
use ravenrs_app_ui::{App, Language};

#[derive(BusinessObject)]
#[object(caption = "Contas", navigation = "Cadastros")]
struct Account {
    #[field(key)]
    id: i64,
    #[field(caption = "Nome")]
    name: String,
}

let window = App::new("Raven Contas")
    .language(Language::BrazilianPortuguese)
    .entity::<Account>()
    .seed(|space| {
        space.add(&Account { id: 0, name: "Carteira".into() }).map_err(|e| e.to_string())
    })
    .build()?;

pub fn action(self, make: impl Fn() -> Action + 'static) -> Self

Adds an action of its own, with no module to write. It is made again for each window, so each one turns it on and off by itself; its target entity or view says where it shows.

use ravenrs_app::{Action, BusinessObject, Selection};
use ravenrs_app_ui::App;

#[derive(BusinessObject)]
struct Bill {
    #[field(key)]
    id: i64,
    paid: bool,
}

let app = App::new("Contas").entity::<Bill>().action(|| {
    Action::background("Pay", "Pagar", |job| {
        for bill in job.selected() {
            let mut bill = bill.clone();
            bill.set("paid", true);
            job.save(bill);
        }
        Ok(())
    })
    .target_entity("Bill")
    .selection(Selection::RequireMultiple)
});

pub fn keep_in(self, storage: impl Storage + 'static) -> Self

Keeps the records and the person’s own settings in storage between runs: a FileStorage folder on the desktop, the browser’s IndexedDB on the web. The records stay in memory while the app runs and are written after every commit, under records; the settings go under settings. The seed runs only the first time, while nothing was kept yet.
