Expand description

Arranges a window. Replacing it changes the whole look of an application, and nothing else.

Required Methods§

Source

fn arrange(&self, parts: TemplateParts) -> AnyView

Puts the pieces where they go.

Provided Methods§

Source

fn shows_keys(&self) -> bool

Whether it shows TemplateParts::keys. Then the commands above leave their keys to that bar, so no key answers twice.

Source

fn shows_navigation(&self) -> bool

Whether it shows TemplateParts::navigation. Without it, there is no ⌘K palette of places either: going elsewhere is up to the view, and an application shown inside another leaves that key to the outer one.
