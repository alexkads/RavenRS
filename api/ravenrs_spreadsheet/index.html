Crate ravenrs_spreadsheet 

Source
Expand description

A spreadsheet component for RavenRS: opens, edits and saves .xlsx workbooks, with formulas that recalculate, on the desktop and on the web.

use ravenrs_spreadsheet::{Spreadsheet, SpreadsheetState};

let sheet = SpreadsheetState::new();
sheet.set_cell("A1", "Total").unwrap();
sheet.set_cell("B1", "=SUM(B2:B10)").unwrap();
let view = Spreadsheet::new(&sheet);

SpreadsheetState holds the workbook and is shared with the application; Spreadsheet shows it with a toolbar, a formula bar, the grid and the sheet tabs. The engine underneath is ravenrs-sheet, where every change is a command with undo.
