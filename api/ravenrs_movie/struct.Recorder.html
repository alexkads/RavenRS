Struct Recorder

pub struct Recorder { /* private fields */ }
Expand description

Runs an app from a script and films it: the steps are the ones a person would take, found by the names screen readers see. See the crate documentation.

pub fn guide( &mut self, name: &str, title: &str, text: &str, ) -> Result<&mut Self, RecordError>

The film stops here, with what is called name marked and text saying what to do, until someone clicks the mark. Follow it with the step itself, such as Self::click, which is what the film shows next. When the player is not stopping at steps, the box stays for as long as it takes to read or hear; when it is, that time is skipped.
