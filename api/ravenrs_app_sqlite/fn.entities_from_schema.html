pub fn entities_from_schema(
    connection: &Connection,
) -> Result<Vec<(EntityInfo, TableMap)>, ModelError>
Expand description

Entities from the tables a database already has, for an application over a database that came first: a field per column, a reference per foreign key, and a required field per column that asks for it. A table with no single key is left out, since a record could not be found. What comes out is a start: captions and rules are for the application to give.
