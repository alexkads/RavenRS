# ravenrs-app-ui

The screens of a [RavenRS](https://github.com/alexkads/RavenRS) business application, generated from the model in `ravenrs-app`: navigation, a list and a form for each entity, commands, and a module with the actions every application needs.

Nothing here draws by itself. Lists are `DataGrid`, forms are `FormLayout`, commands are `Toolbar`. What is missing goes into `ravenrs-widgets` first.
