# ravenrs-graphics

Drawing logic shared across [RavenRS](https://github.com/alexkads/RavenRS): vector shapes with a software rasterizer, chart layout and barcodes. It knows nothing about reports or widgets, so every engine draws the same chart and the same barcode: reports use it directly, and `Chart` and `Barcode` in `ravenrs-widgets` show it in the UI.
