# ravenrs-barcode

What a barcode is, for [RavenRS](https://github.com/alexkads/RavenRS): turns text into the modules a scanner reads and checks GTIN numbers. It knows nothing about drawing, so the screen, reports, label printers and fiscal documents agree on every code.

`ravenrs-graphics` adds the vector shape; a label printer lays the same modules on whole dots.
